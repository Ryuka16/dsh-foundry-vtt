# **概述**

日志条目为GM提供了一种组织和维护玩家 材料的方法，它通过提供独立的、单个的"页面"，这些页面可以单独展示给用户。日志条目页面使用富文本编辑器进行编辑（通过编辑器中便捷的"源代码"按钮支持原始 HTML）。

本文将帮助你熟悉创建和编辑日志条目、更改其视图、调整其权限级别以及创建指向文档的动态链接。

## **使用日志条目**

在思考日志条目时，最好将每个条目想象成更大信息量中的一个小子集。就像文件夹存储文档（包括日志条目）一样，日志条目存储页面，每个页面都作为一个独立的相关信息单元。日志条目页面可以是多种类型中的一种：

### **文本**

    文本页面是最常见的日志条目页面类型，用于存储和显示基于文本的信息。文本页面的编辑主要通过富文本编辑器完成，并为高级用户提供编辑原始 HTML 的支持。

### **图像**

    图像页面用于提供特定的图像，使你能够以一种便捷的方式向一个或多个玩家展示特定的图片。图像页面可以上传并存储在 Foundry VTT 的用户数据文件夹中，也可以链接到外部图像 URL（如果远程图像的主机支持外部链接）。

### **视频**

    视频页面可用于为一个或多个用户播放特定视频。可以从你的计算机上传视频文件，或者页面也可以链接到外部视频 URL。默认支持 YouTube 等流行的流媒体服务。

### **PDF**

    PDF 页面允许显示完全独立的 PDF 文档。PDF 文档可以从你的计算机上传，或链接到外部 PDF URL。但请注意：PDF 页面的设计并未考虑可填写的 PDF 表单，尝试使用和编辑 PDF 表单可能会产生意想不到或不可预测的结果。

## **创建日志条目**

创建一个新的日志条目很简单，只需按几下按钮：

1. 导航到日志侧边栏选项卡。

2.  点击日志目录右上角的 **创建日志条目** 按钮。

1. 在出现的对话框中为你的日志条目输入一个名称。

4.  点击 **创建新日志条目** 按钮来创建你的日志条目。

创建完成后，你的新日志条目将打开，允许你添加页面、更改日志条目的名称或向其他人展示该条目。

## **创建页面**

创建日志条目后，你可以在该条目内创建上述任何类型的页面。页面的设计目的是将你的内容分解成逻辑清晰且易于使用的部分。要创建页面：

1.  在打开的日志条目中，点击 **添加页面** 按钮。

1. 在出现的对话框中，为你的页面命名。
2. 从下拉菜单中选择你想要创建的页面类型。

4.  点击 **创建新页面** 按钮。

创建完成后，你的新页面将以编辑模式打开，允许你根据需要编辑内容，或为该页面定义链接和设置。

## **日志条目应用程序**

日志条目应用程序提供了一种组织你世界故事的便捷方式。

### **其他日志条目功能**

日志条目还支持一些值得了解的关键功能：

\*   **地图笔记**

    日志条目及其页面可以"固定"到任何场景，生成一个地图笔记。点击该笔记将显示关联的页面或整个条目。

\*   **多页视图**

    日志条目支持在单个视图中显示条目可能包含的所有页面，以便于方便地阅读跨多种类型的多个页面。要切换此视图，只需点击日志侧边栏中的 ，显示将在多页视图和单页视图之间切换。

### **向玩家展示日志条目和页面**

日志条目及其页面可以展示给特定玩家或所有玩家。如果你想向一个或多个玩家展示一个页面，只需点击任何日志条目标题菜单中的"展示给玩家"。默认情况下，"展示给玩家"假定你想将日志条目展示给所有玩家，但你可以有选择地挑选将接收它的个别玩家。选择好要展示的玩家后，点击"展示给玩家"按钮将确认并为所选玩家显示该页面，并将其置于他们屏幕的最前端。如果你处于多页视图，可以通过在日志侧边栏中右键点击特定页面并选择"展示给玩家"来展示单个页面。

# **页面编辑器**

## **日志页面文本编辑器**

文本模式下的日志条目页面编辑器。

文本页面有多种编辑选项，可以通过点击编辑器窗口中的 **工作表** 进行配置。这将为你提供一个对话框，允许你在以下任何编辑器选项之间切换：

\*   **默认文本页面工作表**

    默认编辑器使用 Prosemirror，这是一个多功能的编辑器，提供了强大的可视化编辑体验，同时提供协作编辑和条目自动保存等功能。

\*   **Markdown**

    对于熟悉 Markdown 的用户，Markdown 编辑工作表允许使用与 Markdown 兼容的简写代码，例如使用 `#` 表示标题，`**` 表示粗体。

\*   **TinyMCE**

    Foundry VTT 版本 9 下使用的先前编辑器。虽然此编辑器仍受支持，但正在逐步淘汰，不应再依赖它。

## **标题控制**

日志条目提供了两个特定的控制选项，影响它们如何展示给用户。每个页面编辑器的右上角提供了一个切换开关，用于决定该页面的标题是否在日志条目的单页视图中显示。此外，"级别"下拉菜单用于配置该页面在日志侧边栏目录列表中的缩进程度。

## **文本页面功能**

文本页面支持许多用户期望从普通文本编辑器中获得的各种功能，包括标题、粗体、斜体、下划线、删除线等格式选项。Foundry VTT 还支持一些特殊功能：

\*   **协作编辑**

    Prosemirror 文本编辑器允许多个用户同时编辑同一个文本页面。所有用户所做的更改将实时更新给同一页面内的其他用户，任何一个用户执行保存命令都会保存所有用户的当前工作。

\*   **自动保存**

    日志条目页面会按设定的时间间隔（默认每 60 秒）自动保存。自动保存数据的频率可以在设置菜单中调整，通过点击设置侧边栏选项卡中的 **配置设置** 进入。

\*   **秘密文本**

    Foundry VTT 添加了一种名为"秘密"的自定义格式，用于文本条目，该格式仅对 GM 或日志条目的所有者可见。你可以通过从段落格式菜单中选择"块"，然后选择"秘密"来创建秘密文本。如果在选择"秘密"时已选中了文本，则会将选中的文本更改为秘密文本。秘密文本块可以通过点击"揭示"按钮切换为对玩家可见，允许玩家在查看页面时看到文本内容。

\*   **日志源代码**

    除了通过 Prosemirror 可用的格式选项外，使用格式菜单中的"源代码 HTML"选项将允许你直接编辑页面的 HTML，从而可以使用 HTML 标签和大量的自定义样式。

## **链接文档**

页面编辑器允许你在富文本编辑器中链接到其他类型的文档。有关更多信息，请参阅本文后面的动态文档链接部分。

## **表格**

**表格下拉菜单**

下拉菜单提供了一系列与创建和编辑表格相关的有用操作。

- 选择表格单元格：按住 Shift 并点击其他单元格来选择多个单元格。

使用 ProseMirror 时，可以通过点击 **图标** 并从下拉菜单中选择一个选项来添加和编辑表格：

\*   **插入表格**

    提示你选择表格应包含的列数和行数，然后创建你的表格。

\*   **删除表格**

    删除选中的表格。

\*   **在后面添加列**

    在当前选中列的右侧添加一个新列。

\*   **在前面添加列**

    在当前选中列的左侧添加一个新列。

    删除当前选中的列及其中的任何内容。

\*   **在后面添加行**

    在当前选中行的下方添加一行。

\*   **在前面添加行**

    在当前选中行的上方添加一行。

\*   **删除行**

    删除当前选中的行及其中的任何内容。

\*   **合并单元格**

    将所有选中的单元格合并为一个单元格。

\*   **拆分单元格**

    如果单元格已被合并，此选项将使它们恢复到原始状态。

## **日志上下文菜单选项**

你可以在日志目录中右键点击任何日志条目以打开上下文菜单。此菜单提供了一系列有用的操作，允许你以各种方式操作所选条目。

**日志条目上下文菜单选项**

\*   **清除文件夹**

    将日志条目从所有文件夹中移除，将其置于日志目录的顶层。

\*   **删除**

    在接受确认提示后，删除日志条目。

\*   **复制**

    在目录中创建日志条目的副本。

\*   **配置权限**

    配置日志条目的权限级别，允许你选择的玩家在目录中查看或修改日志条目。

# **日志权限级别**

与所有其他文档一样，日志条目具有不同级别的权限，分配后允许用户以不同级别查看和编辑这些条目。权限级别如下：



\*   **无**（非创建者的默认值）

    用户默认无权查看或编辑日志条目。

\*   **受限**

    用户可以看到此日志条目的地图图钉，但不会在侧边栏中看到它。双击地图笔记图钉将允许显示日志条目图像，但不能显示文本。

\*   **查看**

    用户可以看到此日志条目的地图图钉以及侧边栏中的日志条目，并且可以通过点击图钉或侧边栏中的条目来打开实际的日志。此外，用户可以在该日志条目的图像视图和文本视图之间切换。

\*   **所有者**（创建者的默认值）

    用户可以看到此日志的地图图钉和侧边栏条目，并且当窗口打开时，可以编辑和更改该日志条目的任何功能。

# **日志 - 上下文菜单**

上下文菜单提供了一系列与操作现有日志相关的有用操作。

**动态文档链接**

虽然不是日志条目独有的功能，但 Foundry VTT 支持从其富文本编辑器系统内链接到其他类型的文档。可以通过将文档从侧边栏拖放到打开的编辑器中来动态链接角色、物品、日志条目、随机表等。如果在将文档放入编辑器时选中了文本，则选中的文本将用作链接的标签。

**手动创建动态链接**

除了通过将内容拖放到打开的编辑器中来创建动态链接外，如果你知道文档的 ID 或名称，也可以手动创建指向特定文档的链接。在可能的情况下，最好使用文档的 ID 而不是名称，因为 ID 是更可靠的引用点。

获取文档的 ID：

1. 打开你想要引用的文档（例如一个角色）。

2.  点击标题栏中位于文档名称旁边的 **图标**，将 ID 复制到你的剪贴板。

1. 现在可以使用 `Ctrl+V`（macOS 上为 `CMD+V`）将此 ID 粘贴到你想要的任何地方。

创建动态链接的语法如下：

`@DocumentType[Document Name]`

`@DocumentType[Document ID]{Custom Text Label}`

例如：

`@Actor[Locke]`

`@Actor[Pt1jPTgVWdJ6QYIA]{Locke}`

**UUID**

可以通过使用 UUID 格式创建更强大的链接，这种格式在拖放条目时常用。可以使用以下格式，提供更可靠的链接。

`@UUID[DocumentType.ID]{Custom Text Label}`

例如：

`@UUID[Actor.VXbvLWzJkGYkMc63]{Akra (Dragonborn Cleric)}`

这允许 GM 快速地将众多日志条目相互链接，并且，如果查看日志条目的用户有权查看链接的文档，点击链接将在另一个窗口中打开该链接文档。

**链接到标题**

日志条目页面的一项特定功能是能够提供指向日志条目中特定标题的链接。这些链接只能通过将特定页面的标题从日志条目侧边栏拖放到另一个富文本字段中来创建。这样做会生成一个动态链接，点击该链接将自动打开该日志条目并定位到指定的标题。此功能在你有较长的日志条目（例如会话笔记）并希望链接到特定子部分以便让用户滚动到该位置查看时特别有用。
