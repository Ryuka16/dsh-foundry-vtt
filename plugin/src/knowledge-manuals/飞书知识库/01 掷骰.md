# Simple Roll 简单掷骰

我们已经了解了类（译者注：我不知道他在哪里教了类，但是这边给个菜鸟链接。[菜鸟教程-JavaScript-类](https://www.runoob.com/js/js-class-intro.html)），以及它们如何作为创建对象的“蓝图”。在这个例子中，我们将创建 `Roll` 类的一个新实例，并用它来掷一个简单的公式。

```JavaScript
const roll = new Roll("1d6"); // 创建一个新的Roll实例，将掷骰公式指定为字符串输入
await roll.evaluate(); // 执行掷骰，注意我们如何使用 await 关键字来等待掷骰完成
console.log(roll.total); // Output: 5 (样例输出)
```

当你以这种方式处理掷骰时，其结果不会发布到聊天中。你可以自由操作掷骰对象，对其执行各种操作。

## 示例：创建用于掷属性的宏

假设我们想创建一个宏，用于生成角色的一组属性值，但我们只想保留最高的 4 个结果。

通常，我们无法通过简单的聊天 `/roll` 命令来实现这一点。

```JavaScript
const results = []; // 创建一个空数组来存储结果
for (let i = 0; i < 6; i++) { // 循环六次   
    const roll = new Roll("3d6");    
    await roll.evaluate();    
    results.push(roll.total); // 在数组中存储结果
} 
const sortedResults = results.sort((a, b) => b - a); // 按降序排序
const topResults = sortedResults.slice(0, 4); // 获取四个最高结果 
ChatMessage.create({ content: `${topResults.join(", ")}` }); // 你可以在聊天信息章节学习ChatMessage
```

## JavaScript 数组方法

（译者注：可以参考[菜鸟教程-JavaScript-数组](https://www.runoob.com/js/js-obj-array.html)，拉到最下面，更多实例对数组方法做了一些教学）

我们知道什么是数组以及如何使用 `push` 方法添加元素，但我们不知道如何对它们进行排序或获取最高的 4 个结果。

### sort 排序

在 JavaScript 中，你可以使用 `sort` 方法对数组进行排序。 `sort` 方法接受一个回调函数（译者注：这里的回调函数可以参考[菜鸟教程-JavaScript-函数](https://www.runoob.com/js/js-function-definition.html)，其实就是作为参数的函数）作为参数，该函数会为数组中的每个元素调用。排序方法的每次迭代都会比较当前元素与下一个元素，并返回一个数字，指示这两个元素的顺序。（译者注：和很多语言不一样，js Array.sort只接受数字返回，而不是布尔返回）

```JavaScript
const results = [3, 1, 2, 4, 5, 6]; 

results.sort((a, b) => b - a); // 降序排序
console.log(results); // Output: [6, 5, 4, 3, 2, 1] (example output)
```

让我们来看一个扩展版本的排序方法，以便更清晰地理解。

```JavaScript
const results = [3, 1, 2, 4, 5, 6]; 

results.sort((a, b) => {
    if (a > b) {        
        return 1;    
    } else if (a < b) {        
        return -1;    
    } else {        
        return 0;    
    }
}); 
console.log(results); // Output: [6, 5, 4, 3, 2, 1] (example output)
```

这段代码实现了与之前完全相同的结果，但更具可读性且更易于理解。

- 如果返回一个负数， `a` 将被放置在 `b` 之前。
- 如果返回一个正数， `b` 将被放置在 `a` 之前。
- 如果返回 `0` ，则位置不变。

### Slice 切片

`slice` 方法用于提取数组的一部分。它接受两个参数：起始索引和结束索引。起始索引包含在内，而结束索引不包含在内。（译者注：如果只有一个参数，则结束索引默认为末尾）

```JavaScript
const results = [3, 1, 2, 4, 5, 6]; 

const firstFourResults = results.slice(0, 4); // 获取前四个结果
console.log(firstFourResults); // Output: [3, 1, 2, 4] (example output)
```

```JavaScript
const results = [3, 1, 2, 4, 5, 6]; 

const lastTwoResults = results.slice(-2); // 获取最后两个结果
console.log(lastTwoResults); // Output: [5, 6] (example output)
```

这与以下相同：

```JavaScript
const results = [3, 1, 2, 4, 5, 6]; 

const secondToLastResult = results.slice(4, 6); // 获取最后两个结果
console.log(secondToLastResult); // Output: [5, 6] (example output)
```

### Join 连接

`join` 方法用于使用参数作为分隔符将数组连接成字符串。

```JavaScript
const results = [3, 1, 2, 4, 5, 6]; 

const joinedResults = results.join(", "); // 将结果合并为一个字符串
console.log(joinedResults); // Output: "3, 1, 2, 4, 5, 6" (example output) 

const joinedResultsWithSpaces = results.join(" "); // 以空格为分隔符将结果整合成字符串
console.log(joinedResultsWithSpaces); // Output: "3 1 2 4 5 6" (example output)
```

# 发送掷骰结果至聊天

如果你愿意，可以使用 `toMessage` 方法将掷骰结果发送到聊天中。

```JavaScript
const roll = new Roll("1d6");
await roll.evaluate(); 
roll.toMessage(); // 将掷骰结果发送到聊天信息中
```

## 示例：从列表中获取结果

在这个示例中，我们将创建一个类似于随机表的功能，但不会使用 FVTT 随机表，而是创建一个从列表中选取结果的宏。

```JavaScript
const names = ["Alice", "Bob", "Charlie", "David", "Eve", "Frank"];
 
const ages = ["12d6", "13d6", "14d6", "15d6", "16d6", "17d6"];
 
const nameRoll = new Roll("1d6");
await nameRoll.evaluate();
const name = names[nameRoll.total - 1];
 
const ageRoll = new Roll("1d6");
await ageRoll.evaluate();
const age = ages[ageRoll.total - 1];
 
const ageRolled = new Roll(age);
await ageRolled.evaluate();
const ageRolledResult = ageRolled.total;
 
ChatMessage.create({ content: `${name} is ${ageRolledResult} years old.` });
```

如你所见，我们使用一个骰子来获取随机点数，然后掷出它。相比固定随机表，根据你的需求，可能性是无限的。

# 随机数

值得注意的是，您不一定需要使用掷骰来获取随机数。您可以使用 `Math.random()` 方法获取 0 到 1 之间的随机数。

```JavaScript
const randomNumber = Math.random(); 
console.log(randomNumber); // Output: 0.123456789 (example output)
```

您可以利用此方法结合一些简单的数学运算，来获取两个数值之间的随机整数。

```JavaScript
const min = 1;
const max = 6; 
const randomNumber = Math.floor(Math.random() * (max - min + 1)) + min; // Math.floor() 方法被用于向下取整乘法的结果。
console.log(randomNumber); // Output: 3 (example output)
```

使用掷骰和随机数非常有用，但结合聊天消息功能时将会强大，因此建议查阅聊天消息部分教程。
