# 固定回环宏

**FVTT版本V12,DND3.X系统已验证。高版本可能需要自行调整api。**

适合类似固定的回环效果。



```JavaScript
// 配置参数
const SPELL_LEVEL = 1;          // 要操作的环位（1-9）
const FIXED_AMOUNT = -1;        // 正值消耗/负值恢复法术位
// 获取当前角色
const actor = canvas.tokens.controlled[0]?.actor;
if (!actor) return ui.notifications.warn("请先选择一个角色！");
// 构建法术位路径
const spellSlotPath = system.spells.spell${SPELL_LEVEL}.value;
// 获取当前法术位值
const currentValue = getProperty(actor, spellSlotPath);
if (currentValue === undefined) return ui.notifications.error(角色没有${SPELL_LEVEL}环法术位数据！);
// 计算操作值
const consumption = Math.abs(FIXED_AMOUNT);
const isRecovery = FIXED_AMOUNT < 0;
// 执行操作
if (isRecovery) {
    // 恢复法术位
    const newValue = currentValue + consumption;
    await actor.update({[spellSlotPath]: newValue});
} else {
    // 消耗法术位
    if (currentValue < consumption) {
        return ui.notifications.warn(法术位不足！需要 ${consumption} 点，但只有 ${currentValue} 点可用);
    }
    const newValue = currentValue - consumption;
    await actor.update({[spellSlotPath]: newValue});
}
return true;
```
