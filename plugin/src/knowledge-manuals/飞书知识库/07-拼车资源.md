# 什么是拼车？
简单来说，拼车就是一群人去购买一个资源，其中发车的人便是车头（也即购买资源的人）。
比如官方的FVTT PHB手册需要 30 刀，发车人发起了拼车，并在截止时间/人数内凑够了 20 个人，那么人均只需要支付 1.5 刀，就能让这 20 个人都获得资源。
需要明确的是，拼车并非一个合理甚至道德的事情，它触害了作者的收益和权益。
# 为什么要拼车？
跑团本身太小众化，资源并未就区域进行不同的定价（如steam国区为低价区），购买的大部分资源都是用美刀进行交易，对于大部分跑团用户来说是不可承担的价格。
因此，为了能有效降低成本，故而选择了拼车这种手段。
# 什么是补票？
拼车有截止时间，而一些用户并未赶在这个截止时间上车，但他们确实很希望要这个资源，这个时候如果开车人允许他们加入到拼车群，就称为补票。
补票需要给开车人支付之前拼车的分摊价格，这可能会导致出现一种坏现象：即发车人短时间内停止拼车，然后利用大量人补票来赚取额外的金额。
# 我希望很多人参与，但如何避免以此牟利？
你可以延长拼车的截止时间或人数，让更多人加入到拼车之中，但这样也会导致发车人很难收齐全部的资金；
如果存在大量补票情况，可以将额外资金保存，然后用这个额外资金于购买其他资源分享到这个拼车群之中。

# 我能否随意分享拼车资源？
不能，但没人可以限制的行为。
需要明确的一点，拼车是大伙一起出钱购买的资源，你随意分享相当于在借大家的钱成全自己那可怜的虚荣心。
