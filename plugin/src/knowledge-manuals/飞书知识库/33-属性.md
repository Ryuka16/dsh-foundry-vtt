> 💡 
注：DAE会允许一部分原本不接受掷骰数据的键值接受掷骰数据，你可以使用[[公式]]来强制引用rolldata和掷骰公式（如[[1d8]]）。
本文档仅涵盖核心 dnd5e 系统可用的主动效果。
[数字] - 这些方括号表示"用括号内类型的你的值替换此处"。例如：[数字] 意味着你输入 3。如果允许使用掷骰数据，你可以输入任何能*计算*为数字的掷骰数据（不允许使用骰子）。
[公式] - 当本文档中提到 公式 时，意味着此值可以用任何骰子公式填充。例如，祝福术添加了几个效果值为 1d4 的效果。这些字段始终允许使用掷骰数据。
[掷骰数据](https://xcnplziulnma.feishu.cn/wiki/PxmxwHtBniay5LkIH7nce8LunGh)有关可用作掷骰数据的内容，请参阅 。
有用的示例：
| @属性 | 描述 |
|---|---|
| @abilities.dex.mod | 角色的敏捷调整值 |
| @prof | 角色的熟练加值 |
| @details.level | 角色的总等级 |
| @details.cr | 角色的挑战等级 |
| @classes.barbarian.levels | 角色的野蛮人职业等级 |
[!注意]
在主动效果值中使用公式时，角色卡上对应于更改值的显示并不总是显示计算后的公式结果，但在掷骰时会应用该结果。
例如，当将 @abilities.cha.mod 添加到 system.bonuses.abilities.save 来模拟圣武士的守护灵光时，角色卡上不会显示该豁免加值，但在进行豁免检定时，该加值会生效。
| 变更模式 | 描述 |
|---|---|
| 加 | 将提供的值添加到指定的属性。对于数值属性，可以通过指定要加的值为 +1 或 -1 来增加或减少特定值。对于集合（例如物品属性或角色的伤害抗性），这可用于添加或删除条目（例如，mgc 添加魔法属性，或 -mgc 移除它）。 |
| 乘 | 将定义的属性乘以效果值字段中的数值，例如输入5代表乘以5。 |
| 覆盖 | 将定义的属性替换为效果值字段中提供的值。如果应用于文本值（如名称或描述），可以使用一对花括号 {} 来在最终输出中包含被覆盖的值。因此，用 Arcane Propulsive {} 覆盖胸甲的名称将导致最终名称为Arcane Propulsive胸甲。 |
| 降级 | 对应属性的值不能超过设定的值。例如设定@abilities.dex.value降级为20，代表敏捷属性值不能超过20。 |
| 升级 | 对应属性的值不能低于设定的值。例如设定@attributes.ac.value升级为16，代表AC不能低于16。 |
| 自定义 | 自定义变更模式应用由游戏系统或附加模组定义的逻辑。dnd5e 系统不使用自定义变更模式。 |
# 属性
```
system.abilities.[缩写].value
                       .bonuses.check
                       .save
                       .check.roll.min
                       .max
                       .mode
                       .save.roll.min
                       .max
                       .mode
```
### 属性缩写
| 属性 | 缩写 |
|---|---|
| 力量 | str |
| 敏捷 | dex |
| 体质 | con |
| 感知 | wis |
| 智力 | int |
| 魅力 | cha |
来源：CONFIG.DND5E.abilities
## 覆盖属性值
例如，一个在使用时将属性值设置为固定值的物品或药水。
| 属性键 | 变更模式 | 效果值 | 使用掷骰数据？ |
|---|---|---|---|
| system.abilities.[缩写].value | 覆盖 | [数字] | 否 |
## 升级属性值
例如，一个将属性值设置为固定值（如果该值尚未超过该值）的物品或药水，例如食人魔力量护手。
| 属性键 | 变更模式 | 效果值 | 使用掷骰数据？ |
|---|---|---|---|
| system.abilities.[缩写].value | 升级 | [数字] | 否 |
