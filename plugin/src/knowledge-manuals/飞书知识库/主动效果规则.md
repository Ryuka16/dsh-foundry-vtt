# 主动效果规则

规则是系统提供的一种特殊主动效果变更。这些规则不会直接应用到角色或物品的数据上，而是在掷骰时求值，并且只修改某一特定掷骰。

## **类别**

规则会归入若干类别，以控制它们影响哪些类型的掷骰。这些类别会填入变更配置窗口的“属性键”字段中。

| 类别 | 说明 | 可用规则类型 |
|-|-|-|
| `attack` | 影响攻击的 d20 掷骰。 | 全部 |
| `check` | 影响属性检定的 d20 掷骰。 | 全部 |
| `d20` | 影响任意攻击、检定或豁免的 d20 掷骰。 | 全部 |
| `damage` | 影响第一个匹配的伤害部分。 | 加值 |
| `save` | 影响属性豁免、死亡豁免和专注豁免的 d20 掷骰。 | 全部 |
| `healing` | 与伤害相同，但作用于治疗。 | 加值 |

## **类型**

目前有四种不同的规则：加值、优势模式，以及范围规则（最小值和最大值）。所有这些规则都可用于 d20 掷骰，但伤害和治疗目前仅支持加值规则。

### **优势模式***（仅适用于 d20 掷骰）*

该模式可用于对特定 d20 掷骰施加优势或劣势。“值”字段接受有限数量的可能值，用于指示应如何影响该掷骰的优势模式：

| 值 | 说明 |
|-|-|
| +1 | 为该掷骰添加一个优势来源。 |
| -1 | 为该掷骰添加一个劣势来源。 |
| =+1 | 强制该掷骰具有优势（忽略劣势）。 |
| =-1 | 强制该掷骰具有劣势（忽略优势）。 |
| >=0 | 忽略任何劣势来源，但仍允许优势。 |
| <=0 | 忽略任何优势来源，但仍允许劣势。 |

### **加值**

加值模式只是为掷骰添加新部分。这可以是固定值（例如 `3` 变为 `1d20 + 3`）、骰子值（例如 `1d4` 变为 `1d20 + 1d4`），或属性（例如 `@prof` 变为 `1d10 + @prof`，可能结算为 `1d20 + 2`）。

对于伤害掷骰，还可以包含伤害类型标注。通常，伤害加值会变成其被应用到的伤害类型（因此将 `1d4` 添加到刺剑伤害中，它会是穿刺伤害），但标注可以将其改为其他伤害类型（例如 `1d4[fire]` 表示该额外伤害现在为火焰伤害）。



### **掷骰最大值与掷骰最小值***（仅适用于 d20 掷骰）*



最大值和最小值规则会影响 d20 掷骰的范围。这严格影响应用任何调整值之前的骰子点数。例如，将最小值设为 `10` 会导致掷出 `1d20min10`，骰子上任何低于该值的结果都会变成 `10`。



这也接受确定性公式，因此你可以输入最小值 `@prof`，它会结算为掷骰者的熟练加值。





## **条件**



规则默认范围非常宽泛。添加一条伤害加值规则意味着该加值会应用到所有伤害，无论伤害来自法术还是武器、近战还是远程，也无论伤害类型是什么。要缩小规则的适用范围，可以使用效果条件和变更条件。



\[主动效果条件页面\](Active-Effects#Conditions)详细介绍了如何定义条件以及通常可以筛选哪些数据。对规则来说特别重要的是掷骰描述字段，它们提供了可用于缩小规则适用范围的额外信息（例如，使用 `roll.damage.type` 仅在角色造成火焰伤害时应用加值，或使用 `roll.attack.mode` 仅将加值应用到投掷武器攻击）。任何 `roll.` 键都只能在变更条件中引用，不能在效果条件中引用。



| 键 | 说明 | 示例 |
|-|-|-|
| roll.ability | 与 d20 掷骰关联的属性。 | `dex`、`str` 等 |
| roll.attack.classification | 攻击的来源。 | `weapon`、`spell` 或 `unarmed` |
| roll.attack.mode | 所选的武器攻击模式。 | `oneHanded`、`thrown`、`offhand` 等 |
| roll.attack.type | 这是近战攻击还是远程攻击。 | `melee` 或 `ranged` |
| roll.damage.type | 单个伤害部分所应用的伤害类型。 | `cold`、`fire` 等 |
| roll.item | 进行攻击的物品的掷骰数据（而顶层的 `item` 包含提供该规则主动效果的物品数据）。 |  |
| roll.proficient | 该掷骰是否加入了熟练加值。 | `true` 或 `false` |
| roll.scaling | 用于该掷骰的物品所应用的任何缩放。 |  |
| roll.skill | 与该掷骰关联的技能 ID。 | `acr`、`ath` 等 |
| roll.tool | 与该掷骰关联的工具 ID。 | `thief`、`carpenter` 等 |
| roll.type | 正在进行的掷骰类型。 | `attack`、`skill`、`tool` 等 |



### **远程攻击的掷骰最小值**



\- **键**：attack

\- **类型**：Minimum

\- **值**：10

\- **条件**：



```JSON
{
  "k": "roll.attack.type",
  "v": "ranged"
}
```



### **投掷武器攻击的伤害加值**



\- **键**：damage

\- **类型**：Bonus

\- **值**：1d4

\- **条件**：



```JSON
{
  "k": "roll.attack.mode",
  "o": "startswith",
  "v": "thrown"
}
```



### **所有火焰伤害的伤害加值**



\- **键**：damage

\- **类型**：Bonus

\- **值**：@prof

\- **条件**：



```JSON
{
  "k": "roll.damage.type",
  "v": "fire"
}
```



### **基于力量的 d20 检定劣势**



\- **键**：d20

\- **类型**：Advantage Mode

\- **值**：-1

\- **条件**：



```JSON
{
  "k": "roll.ability",
  "v": "str"
}
```



### **智力（历史）与感知（医药）检定加值**



\- **键**：check

\- **类型**：Bonus

\- **值**：1d4

\- **条件**：



```JSON
{
  "o": "OR",
  "v": [{
    "o": "AND",
    "v": [{
      "k": "roll.ability",
      "v": "int"
    },{
      "k": "roll.skill",
      "v": "his"
    }]
  },{
    "o": "AND",
    "v": [{
      "k": "roll.ability",
      "v": "wis"
    },{
      "k": "roll.skill",
      "v": "med"
    }]
  }]
}
```



### **魅力（欺瞒、威吓或游说）检定加值**



\- **键**：check

\- **类型**：Bonus

\- **值**：1d4

\- **条件**：



```JSON
[{
  "k": "roll.skill",
  "o": "in",
  "v": ["dec", "itm", "per"]
},{
  "k": "roll.ability",
  "v": "cha"
}]
```
