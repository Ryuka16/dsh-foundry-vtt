# **为什么我的xxx没有自动化？xxx的自动化似乎有问题？**

**自动化不会自己从地里长出来。**dnd系统的自动化预制菜由主要由以下几个来源提供：

- **Classpack(5e)/官方三宝书及其他mod(5r)：**他们会提供简单的自动化，但是不一定满足你的要求，除此之外，classpack的自动化可能会有bug或是未做完的自动化，如果遇到请直接在FVTT社群中反馈。
- **plu+plu addon：**5e tools提供的模组，plu addon会在你导入物品时内置简单的自动化并自动匹配CPR。
- **CPR/GPS/MISC/DDBI：**CPR和其他几个模组提供了大量不那么常规的自动化预制菜，请先自行阅读<cite doc-id="QRDAwvmuhitZ8RkFyB5cwoHWnJx" file-type="wiki" title="CPR宇宙使用指南" type="doc"></cite>。
- **自己搓：**你说得对，但是 FVTT 是一款.....总之，自己动手，丰衣足食。

# 为什么我没有启用dnd2024规则，武器却有专精？为什么我启用了dnd2014规则，武器却有专精？

在合集包浏览器中可以查看物品/职业/特性的来源，其中classpack，srd5.1，职业包之类的描述均为dnd2014物品。srd5.2/千菓为2024（大概如此）。

规则和物品并不冲突，实际跑团时请使用正确的物品。
