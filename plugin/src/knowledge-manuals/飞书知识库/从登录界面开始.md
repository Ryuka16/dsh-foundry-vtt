# 从登录界面开始

![图片展示了FVTT游戏登录界面，背景为战斗场景。界面中“欢迎入侵”标题下方有三个选项，分别是“创建新游戏”“加入游戏”“返回主页”，其中“加入游戏”选项被红色框 addCriterion图片 addCriterion addCriterion](https://feishu.cn/file/TRhmblzSOoPRSbxMYVsczE2BnGh)

选择角色后直接点击加入游戏即可，一般而言不会设置密码。如有问题请询问你的GM。

加入游戏后，经过十几秒的黑屏后…你就正式登陆FVTT了。

## 初次进入游戏的第一步？

![图片展示的是FVTT游戏平台中玩家设置界面。界面上方显示“玩家设置：测试”，下方有“核心”和“Pathfinder”选项卡。玩家信息部分，玩家名称为“测试”，玩家形象为“path/to/file.ext”，玩家颜色为#57cc28，玩家代词为空。玩家角色下拉栏提示从至少有查看权限的角色中选择主要角色。界面底部有“保存玩家配置”按钮。该图片与上下文紧密相关，是对初次进入游戏时玩家设置窗口的直观呈现，帮助玩家了解设置内容。](https://feishu.cn/file/RvLbbJsS7oDuE1xxEAPcyQgxnPb)

首次进入游戏时，玩家设置窗口会弹出。你一般无需修改其中绝大多数设置。  
点击玩家角色下拉栏，选择你的主要角色，然后保存设置即可。

## 车卡前需要了解的基础设置

作为玩家，你仍旧可以通过右侧边栏的游戏设定，为自己做一些个性化的设置。

![图片展示了Foundry Virtual Tabletop游戏界面中“游戏设定”板块的内容。左侧边栏有多个图标，其中“游戏设定”图标被红色框突出显示。右侧主界面“游戏设定”板块中，“配置设定”和“操控设置”两个选项被红色框重点标注。该图片与上下文紧密相关，上下文提到作为玩家可通过右侧边栏的游戏设定为自己做一些个性化的设置，此图](https://feishu.cn/file/ZAv8blkltobxvCxnJmcc8axenRb)

重点便是头两个按钮，**配置设定**与**操控设置**。我们通过两个案例讲解一下具体配置的逻辑。

---

### 案例1：在配置设定修改你喜欢的3D骰子。

<callout emoji="📍">
此案例使用了Dice So Nice模组。
</callout>

此时我们点击配置设定，在侧边下拉栏中找到那个你要配置设定的模组。

点击进去，直接找到3D骰子配置。

![图片展示了游戏设定界面中3D骰子配置的设置项。左侧为模组列表，其中“Dice So Nice!”被红框标出。右侧是3D骰子设置区域，包含“3D骰子设置”按钮，以及“掷骰区域设置”按钮。该图片与上下文紧密相关，上下文提到在配置设定中找到3D骰子配置，此图直观呈现了3D骰子配置界面，帮助用户了解设置项位置，为修改颜色等设置提供指引。](https://feishu.cn/file/JorabTcpvokfPExyMMzcEsCFnHh)

对应的设置项很多，详细的配置教程可以参考本项目的其他攻略。但如果你只是想换个喜欢的颜色，那修改红框标出的设置项即可，想要什么好看的骰子可以自己试试。

另外修改完设置后，记得点击保存。

![图片展示了《战锤40K：行商浪人》中3D骰子设置界面。界面中有多个不同颜色和材质的骰子模型，下方有“启用3D骰子”开关。重点突出部分为“主题” 、 “贴图”和“材质”三个下拉选项，分别对应“ - 自定义 - ”“无/自动（主要）”“自动（主题/贴图）”等选项。图片与上下文关系紧密，上下文提到可通过修改红框标出的设置项来更换喜欢的颜色，且修改完设置后需点击保存。](https://feishu.cn/file/B9zObqji6o3gzdxK5fncTfNenpd)

### 案例2：在操控设置修改全局搜索呼出的快捷键

<callout emoji="📍">
该案例使用了Quick Insert - Search Widget模组。
</callout>

配置的界面与逻辑与配置设定想通，找到下拉找到对应的模组。点击进入配置页面。

![图片展示了《D&D 5E》模组“Quick Insert - Search Widget”的控制配置界面。左侧为模组列表，右侧是配置区域，显示“启用Quick Insert”已启用，快捷键为“Control +”，下方有“配置区域设置”和“搜索区域设置”选项。该图片与文档中介绍“Quick Insert - Search Widget”模组配置的内容相关，直观呈现了模组配置界面及快捷键设置情况，帮助用户了解如何进行配置。](https://feishu.cn/file/UpMObSOUvoFDT5xFcYsce24knEh)

配置的方法简洁明了，点击编辑后按出自己想要的键位然后保存即可。

首个按钮是添加快捷键位，第二个则是编辑当前的快捷键位，第三个则是删除。

![图片展示的是《暗黑破坏神4》中一个界面弹窗，背景为红色液体池塘。弹窗内文字提示“按名称搜索。类型?获得更多的选择。”下方有“Quick Insert”选项。该图片与文档中介绍“全局搜索”配置相关，用于说明配置结束后测试时，会在构筑、购物、选取法术等地方用到全局搜索，其搜索能力便捷，可按名称搜索并获得类型选择，比系统合集包检索更强大。](https://feishu.cn/file/G6vVbft76oLZA6xcPwTcwQSGnbf)

配置结束后记得自己测试一下，这个全局搜索非常强大。你会在构筑，购物，选取法术等地方用到它。个人认为当你明确自己要找到什么资源时，该模组的搜索能力远比系统本体自带的合集包检索便捷。

（合集包检索的另一个问题是，有时候它只会响应英文。所以需要这个模组救场。）
