# FVTT 一定需要服务器吗？

绝大多数情况下推荐购买服务器。哪怕你具有公网 IPV4 地址，在国内的网络环境下，很难有较好的 P2P 体验（参照 steam、主机联机游戏）。如果你执意采用 P2P 方式，可以自行上网寻找 Zerotier 、 Hamachi 之类的内网联机工具进行部署。



# 部署服务器应该选择什么系统？

绝大部分云服务器商均可以选择的 Windows 系统，且系统版本不能低于 Win 2016。

如果没有 Linux 的操作基础，请不要选择此类系统，包含 ubuntu、麒麟、Red Het、CentOS等。

当然如果你想要使用Linux系统也是没问题的，本教程中也提供了关于Linux系统的搭建过程<cite doc-id="Ilt9w5ufYi6UiFkeJoJcvQAjn5e" file-type="wiki" title="Linux（Ubuntu）安装FVTT" type="doc"></cite>，由于Linux的划分众多，为了便于小白理解，教程中仅示范ubuntu，如果使用Linux系统，考虑到node.js的版本需求，推荐使用ubuntu22.x以上版本。

# 服务器无法访问？不知道服务器密码？

建议直接和购买服务器厂商的客服对线，你是顾客，他会处理好你的需求。



# 我在服务器上打开 FVTT 的时候提示[不支持硬件加速]是怎么回事？

FVTT 的设计是你在服务器内安装好以后，接下来的操作都只在你自己电脑上进行，服务器上不支持硬件加速对于 FVTT 使用没有任何关系。

一般来说只需要服务器保持 FVTT 程序软件窗口打开，然后本地用`IP:端口号`访问即可。



# 为什么我上传文件到服务器的时候速度很慢，而且会中断？

是否文件过大，一般来说服务器的上行带宽（约为 10 - 30 Mbps），这个上行带宽同你家庭网络的上行带宽（一般为 20 Mbps）取最小值，为实际上传速度。

是否文件数量过多，不建议直接上传文件夹的方式，若需要上传文件夹的内容，建议创建压缩包后再上传，然后在服务器上解压。

如果还是不能上传，那么考虑服务器安装**`百度网盘`**等软件，通过云盘进行资源转移。



# COS 桶 / OSS 桶是什么？

简单理解就是一个外置的硬盘，可以从这里访问你的资源（如地图、token 图、音频或动画资源等）。

你可以参考<cite doc-id="SZj7wArUmidSnKkDJnJcZVlgnTe" file-type="wiki" title="对象存储——COS桶/OSS桶" type="doc"></cite>教程来配置对象存储。



# **服务器流量计费怎么计算？**

阿里云和腾讯云计费为 1GB / 0.8 元，其中阿里云每个月免费送 20 GB 流量（等效 16 块钱）。

客户端每次访问 FVTT 就会产生流量加载，比如登录 FVTT 时便会访问服务端下载进入的首个场景。

激活地图、播放音频或是播放动画等，本质上就是从服务端下载对应的文件。举例来说，1 个 DM 和 4 个 PL 在线的 FVTT，此时 DM 激活一个场景大小为 100 MB 的地图，那么包括 DM 在内的每个用户都会加载这 100 MB 的地图资源，总计消耗流量 500 MB。



# 如何降低流量消耗？

1. FVTT 加载页面和首个加载场景避免使用大文件地图资源；
2. 图片使用 webp 格式，音频使用 ogg 格式，有效降低文件大小；
3. 使用 COS / OSS 桶，流量费用比服务器更便宜；
4. 避免多次刷新，FVTT 并无缓存机制，每次刷新都相当于重新下载文件资源。



# 登录 FVTT 的时候，提示管理员密码相关错误？

管理员密码在`主界面`-`设置`-`管理员密码`中设置。

未设置过管理员密码或者输错管理员密码，则无法再世界登录页使用`返回设置`功能，出错提示统一为`管理员密码错误`。这个时候直接去删除 FVTT 文件夹内`Config`下的`admin.txt`文件，若未设置过则不会有此文件。

如果没有此密码，则自己在 FVTT 界面右上角打开`设置`，输入自己的密码。



# 登录世界的时候，提示为xxx（用户）输入的密码错误？

回到 FVTT 主界面，找到要启用的世界，右键世界点击`编辑`，选择`重置用户密码`再启动世界。



# FVTT 之前还好好的，什么都没动，突然就 xxx 样了

这种情况一般可能是服务器内存满了/本地内存爆了，重启你的云服务器/刷新你的fvtt即可。



# 有一个玩家突然访问不了 FVTT 了？或是有一个玩家访问 FVTT 有问题？

若是只有一个玩家访问不了 FVTT，一般是网络或者浏览器问题，网络只能自行解决，而浏览器建议使用 FVTT 专用浏览器 FLC。
