# mod列表

> 开mod前至少也要大概知道它是干嘛的吧……

- **5e_chn**

DnD5 系统的汉化

- **about-time**

 DAE、Times Up 等模块的时间计算依赖

- **ActiveAuras**

光环mod

- **adv-reminder**

优势/劣势掷骰提示

- **advanced-drawing-tools**

增强绘图工具

- **always-hp**

增加一个常驻窗口，随时方便地调整 Token 的 HP

- **arcane-warding**

自动结算 D&D5e 防护学派法师的「奥术护盾」特性

- **ATL**

支持在动态效果中更改指示物数据。这意味着任何指示物数据都可以通过动态效果进行控制：例如大小、光照、视觉效果、图像等。

- **auraeffects**

用动态效果定义光环半径，自动为进入范围的单位添加/移除效果。

- **autoanimations**

动画自动化匹配mod

- **autocomplete-inline-properties**

在支持内联属性的输入框中提供自动补全。

- **automated-conditions-5e**

AC5E自动化mod，详情请见<cite doc-id="Sl6QwVxRqi6SUrkKe8wc0yoJnuh" file-type="wiki" title="Automated conditions 5e的使用方法" type="doc"></cite>

- **automated-evocations**

管理召唤物/随从，支持召唤动画与法术自动召唤。

- **babele**

合集包汉化框架，巴别塔中文的依赖。

- **bg3-hud-core**

BG3 风格 HUD 的核心，需搭配对应系统的适配模块使用。

- **bg3-hud-dnd5e**

BG3 风格 HUD 的 D&D5e 适配，为 Token 提供技能、法术与效果的快捷操作面板。

- **bugs**

D&D5e 实用脚本合集。

- **canvas3d-premium**

3D 画布地图制作的附加高级工具集。

- **chris-premades**

自动化预制菜，详情请见<cite doc-id="QRDAwvmuhitZ8RkFyB5cwoHWnJx" file-type="wiki" title="CPR宇宙使用指南" type="doc"></cite>

- **combat-enhancements**

在战斗追踪器中增加血量显示与拖拽排序。

- **combatbooster**

加速战斗流程：回合标记、最近行动记录等便捷功能。

- **custom-dnd5e**

用于自定义 D&D 5e 系统的工具。

- **dae**

用 Active Effects 实现复杂持续效果，是 Midi-QOL 等自动化模块的依赖。

- **data-inspector**

检查 Actor 与 Item 文档数据的调试工具。

- **dfreds-chat-pins**

可将聊天消息置顶固定，方便随时回看。

- **dice-calculator**

在聊天框下方添加骰子托盘，把骰子按钮变成计算器。

- **dice-so-nice**

掷骰时显示高度可自定义的 3D 骰子动画。

- **dnd-simplified-chinese-babele-patch**

DND5合集包汉化 Babele 翻译补丁。

- **dnd5e-animations**

为 D&D5系统提供华丽的技能与法术动画特效。

- **dnd5e_classpack**

5e不全包

- **dnd5e_DMTools**

城主工具包：物品随机表与常用物品材料等（部分依赖 Better Roll Tables）。

- **effectmacro**

给 D&D5e 动态效果附加宏，在效果生效/失效时执行自定义脚本。

- **filepicker-memory**

记住每种文件选择器上次打开的路径（含 S3 源与桶）。

- **filepicker-plus**

增强版文件选择器：功能更多、更好用。

- **find-the-culprit**

二分法自动排查

- **forien-copy-environment**

复制系统和mod设置，并可导出/导入游戏。

- **foundry-quick-upload**

快速上传图片，支持剪贴板粘贴、拖拽、URL 导入并自动转 WebP。

- **foundry-summons**

全能召唤模块：无需导入 Actor 即可把生物直接放到地图上。

- **foundry-vtt-mirror-image**

自动处理 D&D / 开拓者的「镜影术」法术。

- **foundry_chn**

fvtt核心系统的汉化。

- **fvtt-perf-optim**

提供一系列非官方性能优化，减少卡顿。

- **gambits-premades**

自制的法术、物品与专长合集。

- **healthEstimate**

玩家只能看到 Token 的大致健康状况，而不是精确 HP。

- **item-piles**

让物品可以掉落到地上再被拾起，支持金币、物资堆等玩法。

- **itempilesdnd5e**

Item Piles 的 D&D5e 系统支持适配。

- **karma**

「业力骰」：通过运气补偿机制减少极端好坏骰运。

- **less-chat**

限制聊天日志同时渲染的消息数量，减轻卡顿。

- **media-optimizer**

上传时自动压缩优化图片、音频和视频。

- **midi-item-showcase-community**

Midi 自动化社区分享的自动化配置收藏集。

- **midi-qol**

D&D5e自动化核心，详情请见<cite doc-id="KDwnwXPcnimDXKk9VNgcQQAOnic" file-type="wiki" title="必看：midi入门指南" type="doc"></cite>

- **mkah-compendium-importer**

导入与导出压缩包（Compendium）内容。

- **monks-active-tiles**

踩上指定图块即触发传送、开门、隐藏角色、播放声音等效果。

- **monks-combat-marker**

在当前行动者脚下显示可自定义的动画圆盘标记。

- **monks-enhanced-journal**

增强日志功能：遭遇总览、人物地点摘要、常用页书签等。

- **monks-scene-navigation**

重整场景导航栏：单行显示并遵循文件夹结构。

- **monks-tokenbar**

显示所有玩家 Token 的条栏：限制移动、掷豁免、分配 XP。

- **monks-wall-enhancement**

增强墙体工具：拖拽合并节点、自由手绘墙体等。

- **more-activities**

为 D&D5e 系统扩展更多活动（Activity）类型。

- **multiple-chat-tabs**

把聊天记录拆分为多个标签页。

- **multiple-document-selection**

在侧边栏目录中多选文档并批量移动或删除。

- **notebook**

创建便签、提醒、计数器等规划工具，可与其他玩家共享。

- **plutonium-addon-automation**

为 Midi-QOL、DAE 等提供 5etools 数据的自动化。

- **plutonium-cn**

plu的中文版，详情请见<cite doc-id="VYZRwQUhHiZfYAk57spc8cdqnbg" file-type="wiki" title="Plutonium-CN中文版" type="doc"></cite>

- **portal-lib**

库模块：生成生物、传送 Token、选取地点，供脚本调用。

- **quick-insert**

快速搜索并插入 Actor、物品、法术等到地图、人物卡等任意位置（Ctrl+Space）。

- **quickscale**

快速调整物件大小的轻量模块。

- **region-attacher**

创建模板时自动把场景区域（Region）附加到模板上。

- **rest-recovery**

实现长休/短休机制与变体规则

- **Rideable**

处理骑乘/乘坐，让骑手随坐骑一起移动。

- **routinglib**

计算两点间路径的库，供寻路类模块调用。

- **sequencer**

在画布上播放特效并编排复杂动作序列的动画库。

- **smarttarget**

增强目标选定功能，如自动加入目标、HUD 操作等。

- **socketlib**

简化模块间 socket 通信的库。

- **soundfxlibrary**

可在音板（Soundboard）中使用的音效库。

- **sync-token-actor**

同步名称、头像与原型 Token 设置。

- **tcal**

临时压缩包 Actor 库：无需导入即可按需引用压缩包中的 Actor。

- **tidy5e-sheet**

界面整洁的 D&D5e 人物卡，注重易用性与可扩展性。

- **times-up**

动态效果到期后自动移除（与 DAE 搭配使用）。

- **token-action-hud-core**

简洁的Token 动作 HUD 核心框架，需搭配系统适配模块。

- **token-action-hud-dnd5e**

Token 动作 HUD 的 D&D5e 适配。

- **token-attacher**

把任意物件（甚至 Token）附加到 Token 上，随其移动和旋转，支持预制件。

- **tokenmagic**

为 Token、图块、绘图、模板与区域添加特效与动画。

- **translate-all**

一键调用 ChatGPT 翻译物品、法术与日志描述。

- **vision-5e**

按规则 光照与视野规则自动计算 Token 的视觉范围。

- **visual-active-effects**

以图标直观显示当前生效的动态效果。

- **wild-magic-surge-5e**

拥有「野性魔法涌动」专长的玩家施法时提醒并掷 d20。

- **wm5e**

自动化 5e 武器精通（Weapon Mastery）规则（需 Automated Conditions 5e）。

- **zzz_mod_chn**

为 FVTT  mod 提供中文汉化。

- **lib-wrapper**

巴别塔依赖
