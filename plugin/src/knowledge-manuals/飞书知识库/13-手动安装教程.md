# 如何判断一个包的类型是系统，mod，还是世界？
取决于包的json，module.json是mod，world.json是世界，system.json是系统，他们在用户数据文件夹中（即Data）分别处于modules/systens/worlds文件夹下。这会直接影响到你在本篇教程中最终的解压路径。
# 安装教程
> 💡 
成功地手动安装之后，module.json所在路径应当是如下形式：...\FoundryVTT\Data\modules\<mod ID>\module.json
[FVTT 下载加速代理](https://xcnplziulnma.feishu.cn/wiki/GBLNw30Biiq6iKk8DF8cx4oMnAb)如果这篇教程对你来说实在是无法理解，请使用 
[mod 相关](https://xcnplziulnma.feishu.cn/wiki/N9ZuwyOkqiHCmCkID9WcU32qnec)1.找到你希望下载 mod 的 FVTT 官网链接。对于如何找到mod的官网链接，请参见： 。
![图片](images/S4OHb2Usyo6fwyxv66jcH5OrnRd.png)
2.下滑找到你希望下载 mod 的版本（大多数情况选最新就好，但有一些mod限制了版本）
![图片](images/YHZ9bwlJAoJtP5x1JnXcXNY8nwg.png)
3.点击右边的Manifest URL，会下载文件module.json（也可能是浏览器跳转到页面，但都是一个意思）
![图片](images/OXNkbdjGioMKPrxoZ1VcTRdIn5e.png)
4.打开文件（或在浏览器页面）找到download字段，复制后面""内的链接，如这里复制的链接为：https://dragonflagon.cafe/mods/pak/df-curvy-walls
![图片](images/Y8qobNCWeopHZfxSoWAcaENFngb.png)
5.将复制的链接粘贴到浏览器地址栏，之后就会下载对应的 mod 文件
![图片](images/SIbrb5ge5oTJWuxm3d3cJeiWnpe.png)
6.解压下载的文件（不要问我怎么解压），然后打开解压后的文件夹，找到module.json文件
![图片](images/GLrNbyshpooVYzxvE4ZcIKjwnNb.png)
[mod 相关](https://xcnplziulnma.feishu.cn/wiki/N9ZuwyOkqiHCmCkID9WcU32qnec)7.打开module.json文件，找到id字段（如果没有，那就自己新增一个id字段，具体查阅 页面）
![图片](images/LMtmbLQqxopHapx8BGPcaevfn4c.png)
8.将文件夹名称更改为id字段后的内容，这里为：df-curvy-walls
![图片](images/JsQ0bcHstoRTUhxI7yRc0YiKnvd.png)
9.找到你 FVTT 的Data目录，这里是自己设置的，可以在 FVTT 设置查看具体位置
![图片](images/PJffbVFhgomrPvx3qNScveV7nsc.png)
![图片](images/DZ1hbOSI0oa2Isx0UMwcQoYgnLg.png)
10.复制下载的 mod 文件夹（确保已经根据id字段更改名称），将其粘贴到对应Data文件夹目录下的module文件夹中
![图片](images/BZZDb5sg1oJlqUxgUMocqrennQf.png)
11.重启你的 FVTT，此时 mod 列表出现该 mod，mod 安装完毕。
# github下载注意事项
1.github下载时，不要直接点打包下载，而是点一旁的release（作者发布的包）
![图片](images/GDaBb6vIyocXotxHcxWcQoennvf.png)
![图片](images/FhZFbYT6iop79exsLw1c2TN8nLe.png)
2.来到对应的releases页面，可以找到自己希望下载的 mod 版本。一般情况在对应版本下会有module.json和module.zip（或是其他压缩格式）文件
![图片](images/DXY6bc348oTgbZxbIN1cdIVqnpg.png)
3.这里我们点击module.zip（或是其他压缩格式）即可下载对应的mod文件，然后续接上文的步骤6，开始安装 mod
4.点击module.json下载就按照上文下载方式，需要找到download字段下载，续接上文步骤4。
5.如果没有module.json和module.zip，那么则直接参照上文的下载方式，直接下载 mod 即可。
# gitlab下载注意事项
1.与github下载时类似，需要找到作者发布的包，这里点击tag或releases页面（Dice so Nice!的页面是tag）
![图片](images/Ri0DbK5R9on40lxEcbKcWNZGnfb.png)
2.找到你希望下载的版本，然后点击右边的下载，在点击build，即可下载对应的 mod 文件，然后续接上文的步骤6，开始安装 mod
![图片](images/T91dbQj80o4pD8xSg5YcPtSfnsb.png)
3.关于midi、dae之类的下载方式，这里以midi为例。先点击左上角的版本找到你希望下载的midi适配版本。
在下拉框选择适配的版本。
![图片](images/VudybmcZjovqYaxxdBQcGPMxn3l.png)
4.无论你选择哪个版本，都可以在根目录找到package文件夹
![图片](images/NWPObMwcyoxqWWx3XfPcEWlXnQh.png)
![图片](images/HBMXbgwQ9o0u7txj2Y4chYNdnwg.png)
5.进去之后可以发现作者打包好的文件，找到你希望下载的版本，然后下载，续接上文的步骤6
![图片](images/LXjGblDYIo9v8xxKzPjcTEThnpg.png)
