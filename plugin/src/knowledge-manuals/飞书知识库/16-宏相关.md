# 关于宏的用法
FVTT中宏属于进阶使用方法，请确保学习自动化的基础操作和使用。使用宏并非使用FVTT的必修课，没有高度定制化或简洁化的需求，完全可以跳过本章节。
编写宏和调试需要的是JavaScript的使用技巧和熟练，并且熟知FVTT的各种接口和触发条件，若你不熟知代码相关知识，完全可以从学习基础JavaScript代码开始熟悉宏（从FVTT到JS熟练）。
[宏基础入门教程](https://xcnplziulnma.feishu.cn/wiki/Xkbuwjn2DiBpYakBWJZc6mVSntb) 
# 宏的应用场景
宏可以实现诸如自定义动画，更多的自动化等效果。但也会因为过多代码拖慢工作流，出现服务器卡顿，或是严重的bug影响工作流结算，请使用前在应用环境（服务器中）进行充分的测试以免出现影响体验的问题。
此外，由于DND系统（其它系统API调整较少）经常更换或删除API接口，应用宏时请务必确认版本，包括FVTT版本和规则系统版本。更新VTT系统或是规则系统时，请一并更新宏（这也就是为什么宏写多了版本就会难以更新的原因），宏的便捷程度和数量多少因不同规则和不同使用者而异。
# 添加一个宏
在FVTT中使用宏需要创建一个宏来执行，可以是使用物品，添加dae效果或是特殊效果。
![图片](images/XTEpbnln4oH8LbxgytbcpWxmnqe.png)
以V12版本，DND3.31为例（高版本类似），点击下方快捷栏可以创建一个宏，在这里输入你想要执行的宏效果，记得保存。
![图片](images/CPk9bcnlpoWA6qxbBUMcnttFnzf.png)
在角色卡的此处（不同UI和版本有所区别）可以添加角色执行的宏。
![图片](images/QAojbAa1ZoW6xAxncDKc2eupn1d.png)
在物品的此处（不同UI和版本有所区别）可以添加物品的宏。
此外，还可以使用hook来绑定全局宏，使用图块或区域来触发宏，或是使用dae效果来执行一个宏。不同情况触发的方式不同，以具体宏为准。
- 从快捷栏添加的宏只有点击执行时才会执行，适合全局效果，或是单次效果，例如清除测量版等。
- 从人物身上添加的宏会在所有人物相应动作时触发，适合绑定人物的效果，例如重击动画。
- 从物品中添加的宏只会在物品使用时触发，适合诸如饮血剑，奥术回想等自动化。
如果一个宏需要让玩家来执行，请在核心设置的权限管理中，打开玩家的宏权限。
![图片](images/UQZLbhh6ZoScEkx2GAccUXPXnVg.png)
# 写一个宏
首先要明确你的宏需要实现的效果，并且保证JS代码可以实现；确定你需要的功能是需要放在人物身上，物品身上，或是一个全局宏；最后，使用你储备的JS知识来写代码吧！
你可以在FVTT的官网查找所需的API（注意FVTT版本）。

# 使用AI辅助写宏
在没有任何JavaScript基础的情况下，依旧想要使用宏的话，完全可以使用AI辅助你写一个宏。
使用AI写宏需要你更加明确你的需求，不要模糊式提出所需的功能，在提出需求是明确你的FVTT版本和游戏系统版本，在宏执行时可以按F12看当前报错，在宏功能无法实现或者向群友提问时，务必附上报错原因。
![图片](images/KR3sbG1bFoipjoxRX3LcQJOVnSX.png)
例如我想实现一个功能：检测武器是否有多用词条，若有最终伤害计算为1.5倍。
向AI提问式，可以用以下句式：我现在需要一个FVTT宏，在V13版本，DND5.2.1版本下运行，这个宏在执行时检测攻击所用的武器是否有“两用”词条，若有将最终伤害计算为1.5倍。可以使用midi，dae等mod的API，这个宏将会放在物品中执行。
由于AI会无中生有，胡写八写，所以每次写完后都要进行测试，随后打开F12将报错重新提供给AI，再次完善，直到可以完整的实现功能；当然，也会有完全无法实现的功能，此时无论如何调整都无法实现的话，请果断放弃写宏加入手动大军。
