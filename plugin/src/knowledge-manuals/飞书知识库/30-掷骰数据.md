# Docs

> 来源: https://xcnplziulnma.feishu.cn/wiki/PxmxwHtBniay5LkIH7nce8LunGh

要在 FVTT 内探索数据模型以找到下面详述的属性，有几种方法：
• 选择一个Token，然后打开开发者工具（Win 系统按 F12；Mac 系统按 ⌥⌘I），并将此代码粘贴到控制台中（或将其保存为快捷栏中的脚本宏）：
console.log(canvas.tokens.controlled[0].actor.getRollData());
• 或者：安装 "Autocomplete Inline Properties" 模组，以便能够在支持的字段中开始输入并弹出可用属性（并非所有系统都支持）。
• 或者：安装 "Data Inspector" 模组，从物品卡上打开掷骰数据，进行查询复制。
• 或者：在侧边栏中右键单击一个角色并选择"导出数据"，这将获得一个你可以浏览的 JSON 文件。（这不包含任何在掷骰时派生的值。）
## 角色属性
### 属性
@abilities.str - 力量
@abilities.dex - 敏捷
@abilities.con - 体质
@abilities.int - 智力
@abilities.wis - 感知
@abilities.cha - 魅力
注意： 在以下公式中将 * 替换为上面的最后三个字母，如wis代表感知。
@abilities.*.value - 属性值
@abilities.*.mod - 基础属性调整值
@abilities.*.dc - 基于此属性的特性 DC，等于 8 + 熟练加值 + 调整值
@abilities.*.checkBonus - 固定属性检定加值，结合了特定属性加值和全局检定加值
@abilities.*.checkProf - 属性检定[熟练度]
@abilities.*.save.value - 固定属性豁免调整值（不含任何骰子加值）
@abilities.*.saveBonus - 固定属性豁免加值，结合了特定属性加值和全局豁免加值
@abilities.*.saveProf - 属性豁免[熟练度]
### 属性值
#### 护甲等级
@attributes.ac.flat - 需要AC计算方式system.attributes.ac.calc设置为固定值(AC=此值)或天生护甲(AC=基础值+任何其他加值)。如果为固定值则为最终AC值，如果为天生护甲则作为基础值。
@attributes.ac.armor - 已装备护甲的基础值，如果未穿着护甲则为10
@attributes.ac.dex - 角色的敏捷调整值，受已装备护甲允许的最大敏捷值限制
@attributes.ac.base - 基础 AC，所选 AC 公式的结果
@attributes.ac.shield - 由已装备盾牌提供的 AC 加值
@attributes.ac.bonus - 由法术或魔法物品提供的 AC 额外加值
@attributes.ac.cover - 角色的任何掩护效果，必须通过主动效果或模组设置
@attributes.ac.value - 最终 AC 值，ac.base + ac.shield + ac.bonus + ac.cover 相加的结果
@attributes.ac.label - 护甲计算的本地化名称。
#### 同调
@attributes.attunement.value - 当前同调物品数量
@attributes.attunement.max - 同调槽位最大数量
#### 专注
@attributes.concentration.limit - 角色可以维持专注的效果的最大数量。
@attributes.concentration.save - 角色维持专注而进行的豁免检定加值。
#### 死亡豁免
@attributes.death.success - 死亡豁免成功次数
@attributes.death.failure - 死亡豁免失败次数
#### 负重
@attributes.encumbrance.value - 角色的当前负重能力
@attributes.encumbrance.max - 角色的最大负重能力
@attributes.encumbrance.pct - 负重百分比（一个介于 0 和 100 之间的数字，带小数）
#### 力竭
@attributes.exhaustion - 当前力竭等级（一个介于 0 和 6 之间的整数）
#### 生命骰
@attributes.hd.value - 角色当前剩余的的生命骰数量
@attributes.hd.max - 角色的生命骰总数
@attributes.hd.largest - 角色最大生命骰的面数（例如d8）
@attributes.hd.smallest - 角色最小生命骰的面数（例如d8）
@attributes.hd.largestFace - 角色最大生命骰的面数数值（例如d8中的8）
@attributes.hd.smallestFace - 角色最小生命骰的面数数值（例如d8中的8）
@attributes.hd.bySize.[面数] - 角色特定面数的剩余生命骰数量，例如，@attributes.hd.bySize.d6 表示剩余的d6生命骰数量
@attributes.hd.pct - 剩余生命骰的百分比（当前值除以最大值）
#### 生命值
@attributes.hp.max - 最大生命值（不包括任何来自临时最大值的更改）
@attributes.hp.value - 当前生命值（不包括临时生命值）
@attributes.hp.temp - 临时生命值
@attributes.hp.tempmax - 对最大生命值的临时更改
@attributes.hp.pct - 生命值百分比（当前值除以最大值）
#### 先攻
@attributes.init.mod - 角色基于其敏捷的基础先攻调整值。
@attributes.init.prof - 先攻[熟练度]
@attributes.init.total - 最终先攻调整值
#### 移动
@attributes.movement.burrow - 角色的掘穴速度
@attributes.movement.climb - 角色的攀爬速度
@attributes.movement.fly - 角色的飞行速度
@attributes.movement.swim - 角色的游泳速度
@attributes.movement.walk 或 @attributes.movement.speed - 角色的步行速度
#### 感官
@attributes.senses.blindsight - 角色的盲视范围
@attributes.senses.darkvision - 角色的黑暗视觉范围
@attributes.senses.tremorsense - 角色的震颤感知范围
@attributes.senses.truesight - 角色的真实视觉范围
#### 其他属性值
@attributes.prof - 基础的、数值化的熟练加值（不反映熟练骰等选项）
@attributes.spell.dc - 基于所选施法属性的法术豁免 DC
@attributes.spell.mod - 角色所选施法属性的基础属性调整值
@attributes.spell.attack - 角色所选施法属性的法术攻击加值
@attributes.spell.abilityLabel - 角色所选施法属性的本地化标签
### 职业
注意： 在以下公式中将 * 替换为职业项上指定的 identifier识别符
@classes.*.levels - 该职业的当前等级
@classes.*.hd.denomination - 该职业的生命骰面数，例如d8
@classes.*.hd.spent - 该职业已消耗的生命骰数量
@subclasses.*.levels - 某个子类所属职业的当前等级
### 货币
@currency.pp, .gp, .sp, .ep, .cp - 角色持有的每种货币的数量
### 详情
@details.level - 总角色等级
@details.cr - 挑战等级
@details.xp.value - 角色获得的总 XP（或怪物价值的 XP）
@details.xp.min 和 .max - 角色当前等级的 XP 范围
@details.xp.pct - 升至下一等级的进度
### 熟练
@prof - 角色熟练加值。值得注意的是，如果角色在相关掷骰上有专精，此时熟练加值会自动加倍。你可以用@attributes.prof来规避这种情况
@prof.term - 根据系统设置中是否设置了熟练骰，可以是固定熟练值或骰子。
@prof.flat - 固定熟练值，不考虑设置
@prof.dice - 基于骰子的熟练值，不考虑设置
@prof.multiplier - 根据熟练度的上下文乘数（0、0.5、1 或 2）
### 资源(最新版本已弃用)
@resources.primary, .secondary, .tertiary - 三个资源槽位
注意： 在以下公式中将 * 替换为上述槽位之一
@resources.*.value - 剩余的资源值
@resources.*.max - 此资源的最大值
### 比例值
来自 SRD 的示例：
种族物品 - 龙裔的喷吐武器：@scale.dragonborn.breath-weapon
职业物品 - 游荡者的偷袭：@scale.rogue.sneak-attack
子职业物品 - 生命领域的神圣打击：@scale.life-domain.divine-strike
注意： 在以下公式中将 * 替换为创建快捷栏的父物品的标识符。
注意： 在以下公式中将 ** 替换为在快捷栏本身内定义的标识符。
@scale.*.** - 引用的比例值的值
@scale.*.**.number - 仅限比例值类型：骰子 - 比例值中定义的骰子数量（例如3d8中的3）
@scale.*.**.die - 仅限比例值类型：骰子 - 比例值中定义的骰子（例如3d8中的d8）
@scale.*.**.faces - 仅限比例值类型：骰子 - 比例值中定义的骰子的面数（例如3d8中的8）

### 法术
@spells.spell1, .spell2, .spell3, 等 - 普通法术位环阶
@spells.pact - 契约法术位
注意： 在以下公式中将 * 替换为上述法术位之一

@spells.*.max - 此环阶法术位的最大数量
@spells.*.override - 覆盖计算得出的max法术位的值

@statuses.exhaustion - 角色身上的力竭等级
## 物品属性
物品拥有与角色相同的掷骰数据，但仅当所述物品被角色拥有时（即，放置在其角色卡上）。物品的掷骰数据是角色掷骰数据的扩展，添加了 @activity、@mod、@scaling、@item 作为附加属性
@mod - 影响行动使用的当前属性调整值
@scaling - 行动使用时的当前比例等级（因此，一个3环法术以3环施放时，比例等级为1，当3环法术以5环释放时，比例等级为5-3+1=3，你可以使用@scaling来处理与升环有关的法术效应，当启用midi与dae时，也可使用@spellLevel直接引用法术环阶）
@scaling.increase - 超出基准线的比例等级（因此，一个3环法术以3环施放时，比例等级增量为0）
@consumed.hd - 行动消耗的任何生命骰的公式（因此，如果一个行动消耗了2个d6生命骰和1个d10，则公式为2d6 + 1d10）
最常见的 @item 属性是：
@item.uses.value - 物品上当前可用的有限使用次数
@item.uses.max - 此物品的最大有限使用次数
@item.level - 此物品的法术环阶（仅限法术）
@item.levels - 此物品的职业等级（仅限职业）
### 标志
@flags.* - 为方便起见添加到掷骰数据对象的任意对象。对于此处持有的属性没有规则，因为它们是根据系统、模组或宏的需要添加的。
