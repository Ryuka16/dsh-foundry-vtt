# Docs

> 来源: https://xcnplziulnma.feishu.cn/wiki/DwZGwP0y8iO7vbkMqGucObfknGg

在v13.0.43更新中midi终于支持了多属性豁免/检定（如一个法术允许受影响目标进行敏捷豁免或者力量豁免），其工作流程如下
例如，一项豁免/检定行动可以指定进行敏捷/体质豁免，或者运动/特技检定。
- 若你使用第三方模组进行豁免掷骰（如 Monks/Flash Rolls/Rippers Epic Rolls），此功能不被支持，系统将默认选择列表中的第一个掷骰。
- 若在工作流设置中通过掷骰对话框向玩家/GM提示，则会出现一个新的下拉菜单，允许选择所需的掷骰类型。
- 系统将自动选择具有最高调整值（计入优劣势，按 +/-3.325 计算）的掷骰，因此玩家通常只需点击高亮的按钮即可，优、劣、正常状态将按要求高亮显示。
- 若豁免为自动快进掷骰（无对话框），Midi 将选择调整值最高（包括按 +/-3.325 计算的优劣势）的掷骰。
- 仅支持相同类型的D20检定，因此你不能在同一个检定中包含技能与工具检定。多个技能、多个工具或多种豁免类型都可以，但如果混合类型，则只选择列表中的第一个。
