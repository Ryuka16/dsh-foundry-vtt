# 批量配置金币宏

**FVTT版本V12,DND3.X系统已验证。高版本可能需要自行调整api。**

支持批量配置金币，正值为当前所选所有选中的演员添加金币，负值为当前所有选中的演员扣除金币。

![图片展示的是FVTT系统中货币调整器界面。界面上方有“货币调整器”标题，右上角有“关闭”按钮。左侧有PP、GP、EP、SP、CP等货币类型调整量输入框，当前值均为0。下方有“应用”和“取消”两个操作按钮。该界面与文档中批量配置金币功能相关，用于在FVTT系统中对选中演员的金币进行批量调整，正值为添加金币，负值为扣除金币。](https://feishu.cn/file/AdewbJaylou5jDxU08ycMZ2nnBs)

```TypeScript
const currencyTypes = ["pp", "gp", "ep", "sp", "cp"]; // 按铂金、金、金银、银、铜顺序

// 创建对话框内容
const dialogContent = `
  <form>
    ${currencyTypes.map(type => `
      <div class="form-group">
        <label>${type.toUpperCase()} 调整量：</label>
        <input type="number" id="${type}" value="0" style="width: 100px">
      </div>
    `).join('')}
  </form>
`;

// 创建对话框
new Dialog({
  title: "货币调整器",
  content: dialogContent,
  buttons: {
    apply: {
      label: "应用",
      callback: (html) => {
        // 获取所有调整值
        const adjustments = currencyTypes.reduce((acc, type) => {
          acc[type] = parseInt(html.find(`#${type}`).val()) || 0;
          return acc;
        }, {});

        // 处理选中的token
        canvas.tokens.controlled.forEach(token => {
          if (!token.actor) return;

          const updates = currencyTypes.reduce((acc, type) => {
            const current = token.actor.system.currency[type] || 0; // 获取当前货币值
            const newValue = Math.max(0, current + adjustments[type]); // 计算新值，确保不为负数
            acc[`system.currency.${type}`] = newValue; // 更新路径
            return acc;
          }, {});

          token.actor.update(updates); // 应用更新
        });

        ui.notifications.info(`${canvas.tokens.controlled.length}个生物的货币已更新！`);
      }
    },
    cancel: {
      label: "取消"
    }
  }
}).render(true);
```
