> 区域是 Foundry V12 中一项强大的新功能，允许您根据事件触发各种效果。本文将介绍如何使用触发宏或脚本的区域。

# 执行脚本与执行宏

从本质上讲，执行脚本或宏之间并无区别。唯一的区别在于脚本是嵌入在区域本身之中的。

## 执行脚本

- 它嵌入在区域中
- 导出场景时，脚本会随之携带
- 它不能在多个区域中重复使用，你必须将脚本复制到每个区域

## 执行宏

- 它没有嵌入到区域中
- 导出场景时不会携带宏
- 可在多个区域重复使用

本文将以执行脚本行为为例进行说明。但请注意，您也可以使用执行宏行为。

（译者注：大概区别是你用宏，就是填uuid，如果你用脚本，就是把整个脚本丢进去，脚本能直接导出，宏不行，因为宏是存在游戏世界里的。）

# 设置步骤

- 创建新区域
- 前往"行为"选项卡
- 点击"添加行为"按钮
- 选择"执行脚本"行为
- 选择至少一个事件，在这些示例中我们将使用 `指示物进入` 事件

# 使用区域脚本

区域脚本包含一些变量，我们可以利用这些变量执行各种逻辑。区域脚本的第一步是解构变量，以便我们能够使用它们。



```JavaScript
const { data, name, region, user } = event;
const token = data.token;
```

## JavaScript：解构变量

在上面的示例中，我们使用了一种称为解构的新语法。这使我们能够将变量解包到它们自己的名称中。这是一种使代码更易读、更易于理解的好方法。

此：

```JavaScript
const { data, name, region, user } = event;
```

与此相同：

```JavaScript
const data = event.data;const name = event.name;const region = event.region;const user = event.user;
```

## 处理执行的用户

脚本对所有用户运行，例如，如果玩家 1 进入区域，脚本不会仅针对玩家 1 运行，而是针对所有已连接的用户。大多数情况下，这不是我们想要的，通常我们希望脚本要么为进入区域的玩家运行，要么为 GM 运行。

### 为 GM 运行脚本

要为 GM 运行脚本，在运行脚本内容前，如果用户不是当前 GM，我们可以提前退出脚本。

```JavaScript
const { data, name, region, user } = event;
const token = data.token;
if (game.user !== game.users.activeGM) return;// 如果用户是 GM，继续执行脚本，否则什么都不会发生
```

### 为进入区域的玩家运行脚本

要为进入区域的玩家运行脚本，在运行脚本内容前，如果用户不是进入区域的玩家，我们可以提前退出脚本。

```JavaScript
const { data, name, region, user } = event;
const token = data.token;
if (user !== game.user) return; // 如果用户是进入该区域的玩家，继续执行脚本，否则不会有任何反应
```

### 脚本应为哪个用户运行？

这取决于您的脚本需要执行什么操作：

为 GM 运行脚本：

- 如果您需要更新场景元素，例如灯光、图块、门等。
- 如果你需要更新仅被游戏主持人拥有的内容

为进入区域的玩家运行脚本

- 如果你需要更新指示物本身或指示物所代表的角色
- 你想向玩家显示一个对话框

例如：

- 开启或关闭灯光应由 GM 执行
- 触发对角色造成伤害的陷阱应由进入区域的玩家执行

### JavaScript：相等运算符

（译者注：可以参考[菜鸟教程-JavaScript-比较和逻辑运算符](https://www.runoob.com/js/js-comparisons.html)）

我们已在之前的文章中了解了一些相等运算符，现在让我们更深入地探讨一下。

#### 严格相等与宽松相等

到目前为止，我们一直在使用严格相等运算符 `===` 。该运算符会检查两个值是否在值和类型上都相同。通常建议始终使用严格相等运算符，但我们将探讨宽松相等运算符的工作原理，以防你在其他资源中遇到它。

```JavaScript
console.log(1 === 1); // true
console.log(1 == 1); // true
```

在这个例子中，两个运算符之间没有区别。

```JavaScript
console.log(1 === "1"); // false
console.log(1 == "1"); // true
```

请注意，严格相等运算符在这里返回 false，而宽松相等运算符返回 true。这是因为虽然两个值都是 `1` ，但它们不是同一类型。一个是数字，另一个是字符串。

另一个例子：

```JavaScript
console.log(1 === 1.0); // true
console.log(1 == "1.0"); // false
```

在这个例子中，严格相等运算符返回 true，但宽松相等运算符返回 false。这是因为值 `1.0` 是一个数字，而字符串 `"1.0"` 是一个字符串。

宽松相等运算符会在比较之前将值强制转换为字符串。因此，虽然在严格相等中两个数字相同，但宽松相等实际上会检查 `"1" == "1.0"` ，这将返回 false。

（译者注：因此不建议在js中使用`==`，建议全用`===`，同理，下面的NOT运算符最好也用`!==`而不是`!=`）

#### NOT 运算符

如果你想检查两个值是否不相同，可以使用 NOT 运算符 `!==` 。如果值不相同，该运算符将返回 true；如果值相同，则返回 false。

与相等运算符类似，NOT 运算符也可以进行严格或宽松的比较。

```JavaScript
console.log(1 !== 1); // false
console.log(1 != 1); // false
```

```JavaScript
console.log(1 !== "1"); // true
console.log(1 != "1"); // false
```

```JavaScript
console.log(1 !== 1.0); // false
console.log(1 != "1.0"); // true
```

### JavaScript: return 语句

return 语句用于退出函数。它有两种使用方式：

- 从函数中返回一个值
- 提前退出函数

目前我们只关注提前退出函数的情况。在未来的文章中，我们可能会使用 return 语句从函数中返回值，并解释如何使用它。

示例：

```JavaScript
console.log("This line is printed");
return;
console.log("This line is not printed"); // 这一行永远不会被执行
```

# 实践应用：开启灯光

在本示例中，我们将演示当令牌进入区域时如何开启灯光。您需要一盏处于关闭状态的灯光来完成此示例。

```JavaScript
const { data, name, region, user } = event;
const token = data.token; // 确保用户是GM
if (game.users.activeGM !== user) return; 
const light = fromUuidSync("Scene.qy1psUnwEDy6kh2x.AmbientLight.RswAQULznRmNDPhI");
light.update({ hidden: false });
```

或者，对于多盏灯光的情况：

```JavaScript
const { data, name, region, user } = event;const token = data.token;//We make sure the user is the GM
if (game.users.activeGM !== user) return; 
const lightsUUIDs = [
    "Scene.qy1psUnwEDy6kh2x.AmbientLight.RswAQULznRmNDPhI", 
    "Scene.qy1psUnwEDy6kh2x.AmbientLight.RswAQULznRmNDPhI"
]; 
for (const uuid of lightsUUIDs) {    
    const light = fromUuidSync(uuid);    
    light.update({ hidden: false });
}
```

# 实践应用：触发陷阱

遗憾的是，目前没有通用的方法可以对角色施加伤害。在本示例中，我们将使用 D&D 5e 系统的函数来执行一系列复杂的操作。请查阅您所使用系统的文档、Discord 频道或 Discord 服务器，以获取该系统特定的函数信息。

```JavaScript
const { data, name, region, user } = event;
const token = data.token;
const actor = token.actor;
// 如果玩家拥有该指示物，我们可以为触发用户运行该脚本。
if (user !== game.user) return;
 
// 第一步我们保存一个掷骰结果
const save = await actor.rollAbilitySave("dex");
 
// 如果结果是成功，那么我们只应用一半的伤害
const damageMultiplier = save.total >= 15 ? 0.5 : 1;
 
// 掷骰伤害
const damageRoll = new Roll("4d8");
await damageRoll.roll();
// 如有必要，我们将伤害减半，并将其四舍五入到最接近的整数
const damage = Math.floor(damageRoll.total * damageMultiplier);
 
// 展示一条包含伤害的聊天信息
damageRoll.toMessage({ flavor: "You triggered a fire trap!" });
 
// 应用伤害
actor.applyDamage([{ value: damage, type: "fire" }]);
```

## JavaScript：三元运算符

在最后一个示例中，我们使用了一种新的语法，这被称为三元运算符。它是 if 语句的一种简写形式。

我们的示例：

```JavaScript
const damageMultiplier = save.total >= 15 ? 0.5 : 1;
```

与下方代码等价：

```JavaScript
let damageMultiplier;

if (save.total >= 15) {    
    damageMultiplier = 0.5;
} else {    
    damageMultiplier = 1;
}
```

或者用伪代码表示：

```Plain Text
const damageMultiplier = IS CONDITION TRUE ? TRUE VALUE : FALSE VALUE;
```

请注意这种语法虽然简洁明了，但切勿在复杂逻辑中过度使用，否则可能导致代码难以阅读。

# 区域：高级

## 控制区域触发次数

在前面的示例中，当进入区域时，伤害会施加到角色身上。这是区域的一个很好的用途，但大多数时候，你可能希望只运行一次陷阱行为或其他行为。

### 方法一：禁用行为

被触发的行为在区域脚本中作为一个变量`behavior`可以被使用，你可以通过将 `behavior.disabled` 属性设置为 `true` 来禁用该行为。这将防止在进入区域时运行该行为。

```JavaScript
const { data, name, region, user } = event;
const token = data.token;
 
// 我们确保用户是GM，因为玩家无法禁用behavior
if (game.users.activeGM === user) {
    // 被触发的行为在区域脚本中作为一个变量可用，就像'event'一样。
    behavior.update({ disabled: true });
}
 
// 在这里我们可以决定这个特定脚本是像之前示例中那样以GM还是玩家形式运行
if (user !== game.user) return;
 
// 举个例子，给角色治疗10点生命值
token.actor.applyDamage([{ value: 10, type: "healing" }]);
```

从此刻起，该行为已被禁用，未来进入区域时也不会再运行。

### 方法二：存储永久计数器

有时你可能希望某个行为运行特定次数，例如一个只能使用前三次的治疗喷泉。在这种情况下，我们可以在行为中存储一个计数器。

```JavaScript
const { data, name, region, user } = event;
const token = data.token;
const MAX_USES = 3;
 
// 首先我们检查当前的使用情况
const uses = behavior.getFlag("core", "uses") || 0; // 如果标志未被设置，||语法用于设置默认值
 
// 如果使用次数超过最大值，我们就退出脚本
if (uses >= MAX_USES) return;
 
// 我们确保用户是GM，因为玩家无法对行为进行更新
if (game.users.activeGM === user) {
    behavior.setFlag("core", "uses", uses + 1);
}
 
if (user !== game.user) return;
 
// 举个例子，给角色治疗10点生命值
token.actor.applyDamage([{ value: 10, type: "healing" }]);
```

## Foundry API：setFlag、getFlag

这是我们首次见到 `setFlag` 和 `getFlag` 函数。这些函数用于在文档中存储自定义数据，它们只是 `update` 方法的简写形式。让我们看看等效代码：

```JavaScript
const document = fromUuidSync("Scene.qy1psUnwEDy6kh2x.AmbientLight.RswAQULznRmNDPhI"); // 一个随机的文档
 
// 使用setFlag方法
document.setFlag("core", "isMagical", true);
 
// 使用update方法
document.update({ flags: { core: { isMagical: true } } });
//or
document.update({"flags.core.isMagical": true});
```

获取flag

```JavaScript
const document = fromUuidSync("Scene.qy1psUnwEDy6kh2x.AmbientLight.RswAQULznRmNDPhI"); // 一个随机的文档
 
// 使用getFlag方法
const isMagical = document.getFlag("core", "isMagical");
 
// 获取flag对象
const isMagical = document.flags.core.isMagical;
```

注意：如果之前从未设置过该flag，它将是未定义的，我们需要在使用前检查这一点。

```JavaScript
// 使用getFlag方法
const isMagical = document.getFlag("core", "isMagical"); // undefined
 
// 获取flag对象
const isMagical = document.flags.core.isMagical; // 如果之前没有设置flag，这将在控制台中报错，因为“core”对象不存在
console.log(document.flags.core); // undefined
```

我们可以通过使用可选链操作符 `?.` 来检查flag是否存在，然后再使用它。

```JavaScript
const isMagical = document.flags.core?.isMagical; // 会返回undefined但是不会报错
```
