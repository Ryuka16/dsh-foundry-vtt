注意：激活条件可以进行组合，所以以下的语法是有用的:
1. &&  // 表示“与”（AND）
1. ||  // 表示“或”（OR）
1. ??  // 空值合并运算符：如果第一个值为 null、undefined 或 false，则采用第二个值
1. !   // 表示“非”（NOT）或取反
1. =   // 赋值操作符（通常用于宏中，而非条件判断，因为它表示赋值）
1. ==  // 等于（值相等即可）
1. === // 严格等于（值和类型都必须相等）
1. <   // 小于
1. <=  // 小于或等于
1. >   // 大于
1. >=  // 大于或等于
damageTypes
通常包含所有投掷的伤害类型
- 用法示例：damageTypes.fire（若造成火焰伤害则返回true）
- 或使用["cold", "thunder"].some(t => damageTypes[t])
defaultDamageType

isAttuned
布尔值，当物品需要同调且已同调时为true
isConcentrationCheck
布尔值，判断是否为专注检定（似乎需要在midi工作流专注设置中选择掷骰专注，实测dnd5e自己的专注检定无法作为midi工作流）
isDeathSave

actor

- actor.raceOrType：种族/类型（首先返回种族）
- actor.typeOrRace：类型/种族（首先返回类型）
- actor.isCombatTurn：战斗回合标识（若处于战斗中）

- target.isHitEC：与midi的挑战护甲模式有关，EC为闪避等级
- target.canSense：目标可感知攻击者时为true
- target.canSee：目标可看见攻击者时为true

computeDistance(tokenUuid, targetUuid) <= 10
检测目标与角色之间的距离，除此之外，以下midi函数也可用findNearby(disposition, token, distance, {maxSize, includeIncapacitated}) ，checkNearby("Friendly", token, 5) 。
例如：checkNearby(CONST.TOKEN_DISPOSITIONS.HOSTILE, tokenUuid, 5)代表着当角色周围五尺内有敌对角色时。findNearbyCount('CONST.TOKEN_DISPOSITIONS.HOSTILE', tokenUuid, 5, 0) 将计数角色5尺周围敌对角色的数量
item.itemType == "spell"

仅限于法术，法术基础环阶为0（i.e.戏法）时

workflow.item.system.properties.has("mgc")

workflow.castData.baseLevel == 4 
施放法术时法术的基础环阶为4时
workflow.castData.castLevel == 4 
施展法术时法术的实际环阶（或者说消耗的法术位）是4时
workflow.item.system.type?.baseItem == "longsword"

["shortbow", "longbow"].includes(workflow.item.system.type?.baseItem)

workflow.item.system?.rarity == "uncommon"

workflow.saveResults[0].total < 10

workflow.activity.ability == "int"

## 目标相关
以下target 均可直接删去以代表掷骰物品拥有者的数据
target.appliedEffects.some(e => e.name.toLowerCase().includes("inspiration"))
目标身上有名称中含有”inspiration“的效果
target.effects.some(e => e.name == "Effect Name") 
目标身上有名为Effect Name的效果
target.statuses.frightened
目标被恐慌
["lg", "med", "sm", "tiny"].includes(target.traits.size)
筛选目标体型
target.items.some(i => i.name == "itemName") 
目标拥有名为itemName的物品时
target.attributes.hp.value != target.attributes.hp.max 
目标当前生命值不等于最大生命值时
target.attributes.hp.value < target.attributes.hp.max / 2 
目标半血以下
target.abilities.str.value >= 22 
目标的力量属性值大于等于22
target?.system?.traits?.ci?.value?.has("diseased") 
当目标对疾病免疫时返回true
target.details.cr <= 3 
目标CR小于等于3时
target.details.level == 10 
目标总职业等级等于10
target.details.gender
目标的性别
## 战斗相关
若处于战斗中，以下字段可用：
- combatRound：战斗轮数
- combatTurn：战斗回合
- combatTime：等于combat.round + (combat.turn ?? 0) / 100
- isCombatTurn：若为掷骰者回合则为true
若未处于战斗：
- combatTime：默认为0
