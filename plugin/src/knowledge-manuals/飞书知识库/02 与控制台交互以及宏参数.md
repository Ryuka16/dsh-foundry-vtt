# 与控制台的互动

JavaScript 控制台是一个网页浏览器工具，允许你与浏览器中运行的代码进行交互。这是一个强大的工具，可以用来调试和测试宏。

- 要打开控制台，右键点击页面并选择“检查”，或按 `Ctrl + Shift + I`（Windows），按 `F12` ，Mac 按 `Cmd + Option + I`。
- 切换到面板顶部的`控制台/Console`标签页。
- 你现在可以阅读控制台日志了。
- 找出底部的文本输入框（开头会有一个带有 `>` 符号的文本框），这会用来输入代码给控制台。

我们将使用控制台记录宏的数据，并检查 Foundry VTT（FVTT）数据结构。

---

# 宏参数

每个宏都有两个默认参数可以使用。这些将在示例中使用，让我们来研究它们所代表的含义：

- `token`：指当前选择的指示物。如果没有选择任何指示物且用户是 GM，这个值将缺失。如果没有选择任何指示物且用户是玩家，则会引用分配给玩家的角色的指示物。
- `actor`：这引用当前选择的标记的角色卡。如果没有选择任何指示物且用户是 GM，这个值将缺失。如果没有选择任何指示物且用户是玩家，这会引用分配给玩家的角色的角色卡。

---

# 你的第一个宏

我们创建一个简单的宏，将角色卡和指示物记录到控制台以便检查。

```JavaScript
console.log(actor);
console.log(token);
```

或者

```JavaScript
 console.log(actor, token);
```

在控制台打开时，保存并运行宏，确保场景中选中了一个指示物。你应该会在控制台看到以下输出：

```JavaScript
Token {...} // 对于DND5e，会是Token5e
Actor {...} // 对于DND5e，会是Actor5e
```

其中 `{...}` 表示指示物和角色卡的实际数据。

# 使用控制台检查数据

我们可以用控制台检查指示物和角色卡的数据。

- 点击token或actor，在控制台中展开其数据。
- 你会看到一长串键和值（译者注：x: y这样结构的内容，前者通常称为键，后者通常称为值）。这是一个 `JavaScript object`。你可以不断扩展对象，深入数据结构。

### JavaScript 对象

（译者注：可以参考[菜鸟教程-JavaScript-对象](https://www.runoob.com/js/js-obj-intro.html)）

JavaScript 对象是一种结构化存储数据的方法。对象是一组键值对，每个键是一个字符串，每个值可以是任何类型的数据，包括其他对象。

物体可以通过花括号`{}` 来识别。例如：

```JavaScript
 { name: "John", age: 30, city: "New York", }
```

对象的属性可以通过点符号`.`来访问。例如，如果这是 指示物 数据的一部分：

```JavaScript
{
    document: {        
        name: "John",        
        texture: {            
            src: "icons/svg/dice-target.svg",        
        },        
        width: 1,        
        height: 1,    
    }
}
```

你可以使用 `token.document.texture.src` 访问指示物的图像路径。例如：

```JavaScript
 console.log(token.document.texture.src);
```

控制台输出：

```JavaScript
 icons/svg/dice-target.svg // 以DND5e的范例角色Akra为例，输出会是systems/dnd5e/tokens/heroes/ClericDragonborn.webp
```

#### 关于引号的说明

在访问对象时，在这些例子中，有时你会看到部分对象被引号包裹。这是因为对象是字符串。例如，指示物`document.texture`对象的 `src` 属性是一个包含图像路径的字符串。

有时，键也需要引号标记，因为键包含特殊字符。

例如：

```JavaScript
 {
     document: { // document键，没有特别的字符，因此不需要用引号标记
         name: "John", // "John"是一个字符串值，所以我们要用引号标记
         texture: {
             src: "icons/svg/dice-target.svg",
         },
         width: 1, // 1是一个数字，所以我们不需要用引号标记
         height: 1,
     }
 }
```

嵌套属性也可以通过对象中的点符号访问，上述示例等价于：

```JavaScript
{
    document: {
        name: "John",
        "texture.src": "icons/svg/dice-target.svg", // 这个键包含特殊符号，所以要用引号标记
        width: 1,
        height: 1,
    }
}
```

请注意，如果你想避免混淆，也可以选择一直用引号标记，例如：

```JSON
 {
     "document": {
         "name": "John",
         "texture.src": "icons/svg/dice-target.svg",
         "width": 1,
         "height": 1,
     }
 }
```
