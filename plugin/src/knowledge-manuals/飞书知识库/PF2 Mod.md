# 便捷自动化

以下mod能够在细节上改善你的自动化生活

- [PF2e Dailies](https://foundryvtt.com/packages/pf2e-dailies)（一键完成每日准备项目的更新）
- [PF2e Extempore Effects](https://foundryvtt.com/packages/pf2e-extempore-effects)（创建系统本体没有的临时效果）
- [PF2e Item Activations](https://foundryvtt.com/packages/pf2e-item-activations)（装备启动项自动创建动作）
- [PF2e Item Revitalizer](https://foundryvtt.com/packages/pf2e-item-revitalizer)（角色物品自动更新）
- [PF2e Modifiers Matter](https://foundryvtt.com/packages/pf2e-modifiers-matter)（检定调整值可视化）
- PF2e Ranged Combat（远程尤其是装填武器相关自动化）
- PF2e Reaction Checker（反应动作自动化）
- [PF2e Summons Assistant](https://foundryvtt.com/packages/pf2e-summons-assistant)（召唤法术/物件自动化）
- [Pf2e Sustain Reminder](https://foundryvtt.com/packages/pf2e-sustain-reminder)（提示需要维持的动作）
- [PF2e Usage Updater](https://foundryvtt.com/packages/pf2e-usage-updater)（调整及计算动作频率的刷新时间）
- [PF2e Utility Buttons](https://foundryvtt.com/packages/pf2e-flatcheck-helper)（杂项自动化，如纯骰检定，战斗延迟轮次，生命链接等）
- [PF2e Visioner](https://foundryvtt.com/packages/pf2e-visioner)（能见度/掩蔽状态自动化）
- [PF2e Keybind Menagerie](https://foundryvtt.com/packages/pf2e-f-is-for-flatfooted)（使用快捷键快速赋予目标提前预设的状态）
- [PF2e Flat Check](https://foundryvtt.com/packages/pf2-flat-check)（纯骰检定相关自动化，经实测PF2e Utility Buttons至今仍无法取代）
- [Quick Send To Chat](https://foundryvtt.com/packages/roll-from-compendium)（PF2e Dorako UX死亡后，替代其发送到聊天框小功能的模组）
- [PF2e Chances](https://foundryvtt.com/packages/pf2e-chances)（自动计算掷骰成功度的概率）
- [PF2e Trigger](https://github.com/reonZ/pf2e-trigger) （用蓝图实现高级自动化）
- [PF2e Assistant](https://github.com/7H3LaughingMan/pf2e-assistant) （大量物品、法术与零碎物件的自动化）
- [PF2e Prepared Spellkits](https://github.com/scari08/pf2e-prepared-spellkits) （准备施法者专属的每日法表预设，可以进行快速切换）
