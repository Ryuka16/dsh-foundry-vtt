This is an open list of modules that use libWrapper. It can serve as a source of examples for module developers thinking of implementing libWrapper support for their module(s), but also as a repository of modules that can be used to validate libWrapper functionality after updates.

If you use libWrapper in your module, please edit this page to add a link to it!

In the "Required" column, please write "Yes" if your module requires libWrapper, "Shim" if you use the [provided shim](https://github.com/ruipin/fvtt-lib-wrapper/blob/master/shim/shim.js), and "No" if libWrapper is optional but you use a custom compatibility mechanism.
Use the "Notes" column for anything else you might want to highlight.
