## Module Settings  
* **Toggle Animations**: Client setting to disable Animations locally. Use the Sequencer settings for a more robust solution.

* **Disable Automatic Recognition**: Disables the Automatic Recognition menu.

* **Global Delay**: Delay the start of all animations in milliseconds. Generally useful to allow users to drag sheets out of the way to watch Animations. 

* **JB2A Asset Location:** Only use if your JB2A module is hosted on something akin to an S3 bucket. This ensures the internal A-A database is registered with the correct pathway.

  * Example: https://s3bucketLocation/jb2a_patreon from the patreon module, or https://s3bucketLocation/JB2A_DnD5e for the free module

* **Hide the Animation Tab from Players:** Prevents non-GM users from accessing the A-A Menu on Items.

* **Disable Melee to Range Switch:** Globally disabled all Melee/Range switch animations from the Melee Menu animations.

* **Disable Persistent Effect Tips**: Disable all UI tips for how to delete Persistent type effects.
