## Audio/Sound  
  
Each Audio section provides a file picker to choose the file path, and a Sequencer Database viewer button, and the following options:  
1. **Volume**: 0 - 1  
2. **Delay**: Delays the start of the audio in milliseconds  
3. **Wildcard**: Placing an **asterisk** ( * ) symbol in place of the file name for sound effects will randomize sounds played from that folder so long as they share the same file type. See the Sequencer WIKI for more information
