附魔词条的绝大部分都是修改物品本身的数据，值所接受的对象可以通过导出物品的json来知晓。



# 行动通用键值

通用键值是适用于大部分行动的附魔键值，他们的格式形如`activities[Activity Type].activation.condition`，其中Activity Type填写行动的类型，即attack，save，damage，etc

| **属性键值** | **改变模式** | **值** | **是否接受掷骰数据** | **含义** |
|-|-|-|-|-|
| activities[type].activation.type |  | CONFIG.DND5E.activityActivationTypes |  | 用以修改行动是动作/附赠/反应或是其他 |
| activities[type].activation.override |  | 布尔值 |  | 决定一些特殊的物品（如法术）的默认行动的激活是否使用物品详情页的数据 |
| activities[type].activation.value |  | 数字 |  | 当activities[type].activation.type为天/秒一类支持值的类型时可用 |
| activities[type].consumption.scaling.allowed |  | 布尔值 |  | 修改是否行动允许消耗递增 |
| activities[type].consumption.scaling.max |  | 数字 |  | 若支持消耗递增，则最大递增等级为？ |
| activities[type].consumption.spellSlot |  | 布尔值 |  | （仅对法术有效）是否消耗法术位 |
| activities[type].consumption.targets |  | [{  <br/>"type": "itemUses",  <br/>"value": "1",  <br/>"target": "",  <br/>"scaling": {}  <br/>}] |  | 行动的消耗目标（不会在行动面板中显示） |
| activities[type].duration.concentration |  | 布尔值 |  | 修改行动是否需要专注 |
| activities[type].target.affects.choice |  | 布尔值 |  | AOE效果是否可以选择目标 |
| activities[type].target.affects.count |  | 数字 |  | 行动可影响的目标数 |
| activities[type].target.affects.type |  | ally/enemy等 |  | 行动影响的目标类型 |
| activities[type].target.affects.special |  | 字符 |  | 输入-self可以使AOE效应不瞄准自己 |
| activities[type].uses.max |  | 数字 | √ | 行动的最大使用次数 |
| activities[type].uses.spent |  | 数字 |  | 行动已消耗次数 |
| activities[type].uses.recovery |  |  |  | 决定行动的使用次数如何恢复 |
| activities[type].range.units |  |  |  | 射程的单位 |
| activities[base].range.value |  |  |  | 射程值 |
| activities[base].img |  | 图片路径 |  | 行动的图标 |
| activities[base].name |  | 字符 |  | 行动名称 |
| activities[type].damage.parts | 加/覆盖 | {"number": 骰数,"denomination": 骰面,"bonus": "", "types": ["damageType1","damageType2",...]}  <br/>若为自定义公式，则为：{"custom":{"enabled":true,"formula":"你的公式"}} | √ | 行动的伤害（若支持） |
| activities[type].damage.includeBase |  | 布尔值 |  | 是否包含基础伤害（即武器详情页伤害） |
| activities[type].damage.critical.bonus |  | 字符 | √ | 行动伤害的重击伤害加值 |
| activities[type].damage.critical.allow |  | 布尔值 |  | 是否允许伤害重击（仅适用于豁免与伤害行动） |



# MIDI附魔词条

以下词条专门用来修改行动MIDI标签页内容或是由MIDI添加的选项内容：

| **属性键值** | **改变模式** | **值** | **是否接受掷骰数据** | **含义** |
|-|-|-|-|-|
| activities[base].effectConditionText |  | 字符 | √ | 修改midi标签页的“激活效果条件” |
| activities[base].useConditionText |  | 字符 | √ | 修改midi标签页的“使用条件” |
| activities[base].macroData.command |  | 宏命令 |  | 为行动插入行动宏 |
| activities[base].macroData.name |  | 字符 |  | 行动宏名称 |
| activities[base].midiProperties.automationOnly |  | 布尔值 |  | 行动仅自动化，不可手动使用 |
| activities[base].midiProperties.confirmTargets |  | "default"/"always"/"never" |  | 掷骰前是否确认目标 |
| activities[base].midiProperties.forceDialog |  | "default"/"always"/"never" |  | 行动使用时是否强制配置消耗对话框 |
| activities[base].midiProperties.ignoreTraits |  | ["idi","idr","idv","ida","idm"] |  | 行动忽略免疫/抗性/吸收/调整 |
| activities[type].midiProperties.otherActivityCompatible |  | 布尔值 |  | 是否可用作其他行动（其他行动兼容） |
| activities[type].midiProperties.triggeredActivityId |  | 触发行动名称 |  | 行动触发的行动名称是？不确定行动id/识别符/uuid是否可用 |
| activities[type].midiProperties.triggeredActivityConditionText |  | 字符 |  | 触发行动的激活条件 |
| activities[type].midiProperties.triggeredActivityRollAs | 覆盖 | "self"/"firstTarget"/"firstHitTarget"/"firstMissedTarget"/"firstSaveTarget"/"firstFailedSaveTarget" |  | 触发行动的掷骰视同由谁进行：物品拥有者/第一个目标/第一个命中目标/第一个击失目标/第一个豁免目标/第一个豁免失败目标 |
| activities[type].midiProperties.triggeredActivityTargets | 覆盖 | 直接从下拉框中选择即可 |  | 触发行动的目标 |

# 攻击行动附魔键值

| **属性键值** | **改变模式** | **值** | **是否接受掷骰数据** | **含义** |
|-|-|-|-|-|
| activities[attack].attack.ability | 覆盖 | 直接从下拉框选择 | —— | 攻击使用的属性 |
| activities[attack].attack.bonus | 加 | 字符 | √ | 攻击行动的攻击检定加值 |
| activities[attack].attack.critical.threshold | 降级/加 | 数字 | × | 攻击行动的重击阈值，若改变模式为“加”则在原本的阈值上进行加或减，若改变模式为“降级”则直接覆盖为指定阈值 |
| activities[attack].attack.flat |  | 布尔值 |  | 是否固定命中加值，若为true，则攻击计算加值时只计算行动本身的加值而无视熟练加值与属性调整值 |
| activities[attack].attack.type.classification |  | 直接从下拉框中选择 |  | 决定攻击类型：武器，法术或徒手 |
| activities[attack].attack.type.value |  | 直接从下拉框中选择 |  | 决定攻击是近战攻击还是远程攻击 |
| activities[attack].attackMode |  | DND5E.attackModes |  | 决定攻击模式是单手/双手/投掷/远程 |
