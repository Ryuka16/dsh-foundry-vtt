# 一个基本的大版本更新要诀

- 低版本使用[Forien's Copy Environment](https://foundryvtt.com/packages/forien-copy-environment)（或其他配置导出mod，如[World Setting Sync](https://foundryvtt.com/packages/world-setting-sync)）导出世界的配置文件（包括系统和mod）。
- **注意提前备份！！！！！！**
- 正常安装高版本，并更新所有的mod，移除不再支持的模组。免科学加速更新参考<cite doc-id="GBLNw30Biiq6iKk8DF8cx4oMnAb" file-type="wiki" title="FVTT 系统与MOD下载加速代理 v12-14支持" type="doc"></cite>。
- ~~赞美欧姆弥赛亚~~
- 高版本启动，主界面**右键世界-编辑世界-以安全模式启动**，这会禁用所有的mod避免冲突。
- 进入世界，等待系统迁移完成。
- 启用[Forien's Copy Environment](https://foundryvtt.com/packages/forien-copy-environment)（或你之前使用的其他配置导出mod），重新导入配置文件。
- 第二次进入世界后，使用`ctrl+f5`或`ctrl+shift+r`，强制刷新所有缓存，并让你的PL第一次进入新版本世界时这样做。
- 检查 mod 的工作情况。
- 开始游戏。
