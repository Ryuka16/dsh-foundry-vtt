# 一、它是做什么用的？

截至目前为止，item piles基本上是唯一一个用于管理物品、掉落、背包、商店等功能的mod。

# 二、安装它需要什么？

## 1、本地配置

此处主要是操作便利性和美观性设置，开启预加载文件即可，如果你的标题栏真的很挤，建议用tidy 5e sheet把不用的抬头标签都塞进三点内。

如果你有更多的物品类别需求和预设价格需求，可以在最下面添加。

## 4、系统专门设置

![图片展示的是Item Piles模组配置界面中的“系统专门设置”页面。其中有“重置系统专门设定为默认”按钮，可将物品堆设置重置为当前游戏系统的默认设置。还可设置角色类型、物品战利品类型、物品武器类型、物品装备类型等，能配置物品数量属性和价格属性的路径，以及进行货币配置、次要货币配置、货币小数点位设置和物品过滤等操作。此图与文档中“系统专门设置”部分对应，说明模组预设完整一般无需变动，除非用户想进行特定更改。](https://feishu.cn/file/YAi6bGyHMor5hnxb73dcmMynnsh)

如果你安装了子mod，此处是预设完整的，不需要变动，除非你想更改其中一些东西（你知道你在做什么）。

你也可以在货币中添加货币类型，并与原有的货币添加兑换比例。此时，它将出现在角色卡货币一栏。

如果你不希望仅仅只是“以物易物”地让某种硬通货成为预设价格，你也可以在次要货币中添加这种物品作为新货币，它并不会出现在金币边上，但你可以在放入货币的时候选择次要货币。

![图片展示了](https://feishu.cn/file/NSN5bM8Kso6dyNxItkoc8Yv3nxh)

物品过滤是很重要的一环，它决定了当你使用Monk's tokenbar创建战利品时，什么东西被排除在战利品之外，以免出现拿走对方天生武器的问题。安装了子mod后此处就不需要再动了，除非你希望有任何东西也被排除在外。

# 四、创建物品堆

当你第一次把一个物品拖到场景中时，模块会在你的侧边栏创建角色

![图片展示了Item Piles中物品堆的默认形式。画面中有一个带有黄色装饰的白色头盔图标，下方文字为“Default Item Pile”，表明这是默认的物品堆名称。该图片与文档中“创建物品堆”部分内容相关，用于直观呈现第一次将物品拖到场景中时，模块在侧边栏创建角色的样式，即默认物品堆的外观。](https://feishu.cn/file/Pzk3bl2pXoCFPxxRXGucYSCvnjc)

不要删，它是你放置在地图上所有物品堆的共同原始角色，以及创建出物品堆的默认形式。

每次迁移世界都会重新生成一次，因此有时会有多个该角色，如果你不是强迫症建议用文件夹装起来。

如果你向已有的物品堆上拖拽物品，系统会提示你是否要将其加入该堆。

拖拽物品前按住左 Alt 键会绕过对话框，将该物品添加到物品堆中。

你也可以打开物品堆，将物品拖放到界面中。

另外，已经配置好的随机表也可以，将【已配置好每条随机项目内物品】的随机表拖入已有的物品堆，就会掷一次随机表并把那件物品加入，金库除外，因为金库采用了网格式储存，和物品堆/商人/宝箱不一样。

最后，你也可以为任意一个NPC配置物品堆，并将其设置为某种类型，以实现手动战利品/商人/银行 的功能。

# 五、查看物品堆

## 1、作为PC

如果你是玩家，可以通过双击物品堆来查看。你需要在物品堆旁边放一个token才能检查，除非物品堆配置的互动距离较远（参见arms reach）。

## 2、作为NPC

如果你是GM，你可以同时框选目标NPC和物品堆然后双击物品堆，此时你就作为该NPC在查看了。



最后，点击拿走即可拿走物品，点击“在X人间平分”可将货币尽可能平均地分配给每个有代表角色的PC账号的默认角色。

## 2、容器

首先在主要设置中，勾选启用，再在其它设置中将类型切换为“容器”。

容器和物品堆的唯一区别就是容器可以上锁，同时它可以对各种状态下的容器图标进行更改。

![图片展示了Item Piles配置界面中容器类型物品堆的设置。在“主要设置”下，已关闭和已锁定状态均勾选。在“其他设置”中，关闭、打开、空、锁定图像路径及声音路径均为“path/image.png”和“path/sound.wav”。该图片与上下文紧密相关，直观呈现了文档中提到的容器类型物品堆设置内容，包括可以上锁、可更改状态下的图标和声音路径等特性。](https://feishu.cn/file/UiA9bpT9EoEucJxNeZJcZp3dnhd)

![图片展示了《看门狗2》中物品堆界面。画面右上角有四个图标，其中右上角两个图标被红色框线突出显示，分别是上锁图标和下锁图标。这与上下文介绍的容器类型物品堆相关，上下文提到容器可以上锁，且在设置关闭和锁定后，容器类型的物品堆会在其右键菜单上出现这两个新图标，可快捷切换关闭和锁定状态。](https://feishu.cn/file/YqRYbqa0OoXGwWxi8OMcNV3QnSd)

当你设置关闭和锁定后，容器类型的物品堆会在其右键菜单上出现两个新图标，可以快捷切换关闭和锁定状态。

锁定状态下，无法查看物品堆内容。

关闭状态下，没有任何区别，双击照样查看，也可以拿走，只是多了一个“点击关闭”的UI。

## 4、商人

![图片展示了《我的世界》中商人“刺客”的物品面板。左侧有“描述”和“设置”选项，右侧分为“购买物品”和“填充物品”两部分。购买物品栏显示了狂野的神莓、茶宝宝、镇钉皮甲、短剑、轻弩等物品，其中茶宝宝和镇钉皮甲为免费，其余有价格。填充物品栏同样列出这些物品，部分物品有齿轮图标，可进行单个配置。该图与上下文介绍商人类型相关，直观呈现了商人面板及物品信息。](https://feishu.cn/file/ZImzb8iGloyNHVxwi9XcfMd6nZd)



首先在主要设置中，勾选启用，再在其它设置中将类型切换为“商人”。

此时，你将看到NPC的面板产生了变化，成为了商店的形式。它默认将NPC身上所有你设置排除的东西以外的物品全部加入商店，并且由于NPC身上的武器都是另外创建的，没有价格所以是免费，因此记得把商人身上的东西都删了再填充。

对每个物品而言，左侧点击数量可以更改其存量，齿轮可以单个配置该物品，眼睛可以隐藏该物品，商店图标可以将其设置为非卖品（可以看到，但不能买）。

# 八、战利品联动功能

使用此功能需要通过monk's tokenbar实现。

![图片展示了展示了monk's tokenbar的战利品设置界面。其中，“显示战利品菜单”和“仅限被击败”选项被勾选。在“将敌人转换为战利品”下拉菜单中，“Item Piles”选项被选中。该图片与文档中介绍战利品联动功能的内容相关，直观呈现了在战利品设置中将“将敌人转换为战利品”改为item piles的操作步骤，以及勾选“显示战利品菜单”和“仅限被击败”的设置情况。](https://feishu.cn/file/G4zhb2xxcoxB71xtAbCc2dBUnjb)

在monk's tokenbar的战利品设置中，我们首先要将“将敌人转换为战利品”改为item piles，然后勾选“显示战利品菜单”和“仅限被击败”（此处选开）。如果想自动转换金币，还要勾选战后设置中的根据CR自动转换金币。

![图片展示了战利品实体设置界面。其中“Convert tokens”选项被红色框突出显示，其下方文字说明当分配给实体时，战利品应当被归入哪里，Default为root。此外，还有“创建画布对象”选项，Default为true，以及“打开战利品实体”选项，Default为无。该图片与文档中介绍战利品实体选项的内容相关，直观呈现了“Convert tokens”等设置项，帮助理解战利品实体的配置方式。](https://feishu.cn/file/FlkhbIH5QoSZyZxheTUc5ozVnDc)

在战利品实体选项中，有3种方法：

1、Convert tokens可以将每个敌人战后都直接变成物品堆，优点：快速，缺点：敌人一多东西分散。

![图片展示了战利品实体中“Creating Journal Entry in the root folder”选项，其含义为当分配给实体时，战利品应当被归入哪里，且默认为“root”。该图片位于文档中介绍战利品实体选项时，对应“Create entry here可以在日志页面创建本次战斗获得的战利品，优点：统一，缺点：日志用的次数不多，不一定能想起来看”这一内容，是对“Create entry here”方法中战利品归类方式的说明。](https://feishu.cn/file/YzSrbqjLDoE1caxi0eycYHn1nCh)

2、Create entry here可以在日志页面创建本次战斗获得的战利品，优点：统一，缺点：日志用的次数不多，不一定能想起来看。

3、创建一个“战利品”NPC，将其item piles设置为物品堆。之后，在战利品实体处选择该NPC。个人认为这是最优方法。此时，需要勾选“创建画布对象”以在战后创建战利品，“打开战利品实体”选开。
