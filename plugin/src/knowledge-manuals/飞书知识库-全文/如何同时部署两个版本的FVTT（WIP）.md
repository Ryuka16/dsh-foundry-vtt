# 如何同时部署两个版本的FVTT（WIP）

> 当你偏爱的某个游戏系统更新特别缓慢时，这也可能派上用场。

此方案对硬盘大小有要求，因为你需要有两个用户数据文件夹。由于macOS与Linux一般采用node部署，且其方案已在<cite doc-id="Ai4JwyB8ViweCGkRzE6c0OzJndh" file-type="wiki" title="Node 多开FVTT方法" type="doc"></cite>介绍过，故不在此文赘述，

在开始说明之前，我们需要了解如何部署携带版（portable version）的fvtt。

首先，前往官方的下载页面，在操作系统选项选择Windows Portable选项，而不是Windows系统

![图片展示了Foundry Virtual Tabletop官方下载页面中“Operating System”选项的下拉菜单。在“Download Version”为“Windows Portable”的情况下，下拉菜单中“Select Operating System”选项被突出显示，其下有Windows、Mac OS、Linux和Node.js四个选项。该图片与上下文紧密相关，上下文提到在下载携带版fvtt时，需在官方下载页面操作系统选项中选择Windows Portable，此图直观呈现了该操作步骤中的关键选择界面。](https://feishu.cn/file/NQGEbg9dXoWWN8xgdYJcOH09nDh)
