# 如何判断一个包的类型是系统，mod，还是世界？

取决于包的json，`module.json`是mod，`world.json`是世界，`system.json`是系统，他们在用户数据文件夹中（即Data）分别处于modules/systens/worlds文件夹下。这会直接影响到你在本篇教程中最终的解压路径。

2.下滑找到你希望下载 mod 的版本**（大多数情况选最新就好，但有一些mod限制了版本）**

3.点击右边的**`Manifest URL`**，会下载文件**`module.json`**（也可能是浏览器跳转到页面，但都是一个意思）

![图片展示的是一个Mod的版本列表界面。左侧列出三个版本，分别是Version 4.0.0、Version 3.4.0和Version 3.3.1，每个版本后有发布时间。右侧有三个不同版本的“Manifest URL”按钮，其中Version 4.0.0对应的“Manifest URL”按钮被红色框线突出显示。该图片与文档中“下滑找到你希望下载mod的版本，点击右边的`Manifest URL`，会下载文件`module.json`”的内容相关，直观呈现了点击“Manifest URL”按钮的操作位置。](https://feishu.cn/file/OXNkbdjGioMKPrxoZ1VcTRdIn5e)

4.打开文件（或在浏览器页面）找到**`download`**字段，复制后面`""`内的链接，如这里复制的链接为：https://dragonflagon.cafe/mods/pak/df-curvy-walls

![这张图片显示的是`module.json`文件的内容界面，高亮标注出了`download`字段，其双引号内的链接为`https://dragonflagon.cafe/mods/pak/df-curvy-walls`，该内容对应手动安装教程里的第4步要求，是需要复制下载的mod资源链接，这是获取对应mod文件的关键操作对象，为后续粘贴到浏览器地址栏下载mod的步骤提供了目标链接。](https://feishu.cn/file/Y8qobNCWeopHZfxSoWAcaENFngb)

5.将复制的链接粘贴到浏览器地址栏，之后就会下载对应的 mod 文件

![这张图片展示的是浏览器的地址栏下拉界面，其中高亮显示了对应步骤4中需要复制的mod文件下载链接`https://dragonflagon.cafe/mods/pak/df-curvy-walls`，该链接正是文档步骤4中提到的需要复制的内容，地址栏下拉列表里还包含对应网址的历史记录及必应搜索该网址的选项，界面顶部标签页显示该页面来自“DF Curvy Walls | Foundry Virtual”，与文档中mod的主题内容相匹配。](https://feishu.cn/file/SIbrb5ge5oTJWuxm3d3cJeiWnpe)

6.解压下载的文件（不要问我怎么解压），然后打开解压后的文件夹，找到**`module.json`**文件

![图片展示了FVTT手动安装mod时解压后的文件夹内容。文件夹内有多个文件夹，如common、css、lang等，以及CHANGELOG.md、include、module.json、README.md等文件。其中，module.json文件被红色框突出显示。该图片与文档中“打开解压后的文件夹，找到module.json文件”步骤对应，直观呈现了module.json文件在解压文件夹中的位置，帮助用户确认找到该文件。](https://feishu.cn/file/GLrNbyshpooVYzxvE4ZcIKjwnNb)

7.打开**`module.json`**文件，找到**`id`**字段（如果没有，那就自己新增一个`id`字段，具体查阅<cite doc-id="N9ZuwyOkqiHCmCkID9WcU32qnec" file-type="wiki" title="mod 相关" type="doc"></cite>页面）

![图片展示的是一个JSON文件内容，其中关键信息为“id”字段，其值为“df-curvy-walls”。该图片与文档中手动安装FVTT模组的步骤相关，是在步骤7中打开`module.json`文件后，找到并展示`id`字段的内容，用于后续将文件夹名称更改为`id`字段后的内容，即更改为“df-curvy-walls”，以完成模组安装步骤。](https://feishu.cn/file/LMtmbLQqxopHapx8BGPcaevfn4c)

8.将文件夹名称更改为**`id`**字段后的内容，这里为：`df-curvy-walls`

![图片展示的是一个文件夹图标，文件夹名称为“df-curvy-walls”。该图片与文档中手动安装FVTT模组的步骤相关，对应步骤8，即在打开的`module.json`文件中找到`id`字段后，将文件夹名称更改为`id`字段后的内容，这里即为“df-curvy-walls”。此图直观呈现了文件夹名称，帮助用户在后续将下载的mod文件夹名称更改为`id`字段内容的操作中，明确文件夹名称。](https://feishu.cn/file/JsQ0bcHstoRTUhxI7yRc0YiKnvd)

9.找到你 FVTT 的**`Data`**目录，这里是自己设置的，可以在 FVTT 设置查看具体位置

![图片展示了Foundry Virtual Tabletop的界面。画面右上角有四个图标，其中红色框突出显示的是“设置”图标。该图片与文档中“找到你FVTT的`Data`目录，这里是自己设置的，可以在FVTT设置查看具体位置”内容相关，用于指引用户在FVTT界面中找到设置选项，以便后续根据文档步骤进行mod安装操作。](https://feishu.cn/file/PJffbVFhgomrPvx3qNScveV7nsc)

![图片展示了FVTT（Foundry Virtual Tabletop）软件的应用配置界面。其中，用户数据路径被红色框突出显示，其值为“D:/FoundryVTT”，并有箭头指向。该图片与文档中手动安装mod的步骤相关，对应步骤6，即在打开解压后的文件夹后，找到`module.json`文件，此时需在该界面找到`id`字段，将文件夹名称更改为`id`字段后的内容，这里即为`df-curvy-walls`。](https://feishu.cn/file/DZ1hbOSI0oa2Isx0UMwcQoYgnLg)

10.复制下载的 mod 文件夹（确保已经根据**`id`**字段更改名称），将其粘贴到对应**`Data`**文件夹目录下的**`module`**文件夹中

![图片展示了在Windows系统下FVTT Data文件夹中的modules文件夹内容。画面中，文件夹路径被红色箭头指向，显示为“文件夹 > 添加数据 (D) > FoundryVTT > Data > modules”。右侧文件列表中，有多个mod文件夹，如simple-quest、zzz_mod_chn等。右下角弹出的右键菜单中，“重命名”选项被红色框突出显示。该图片与文档中手动安装mod的步骤相关，对应步骤10，即复制下载的mod文件夹后，将其粘贴到对应Data文件夹目录下的module文件夹中，此图直观呈现了操作前的文件夹位置及重命名操作。](https://feishu.cn/file/BZZDb5sg1oJlqUxgUMocqrennQf)

# **github下载注意事项**

1.github下载时，不要直接点打包下载，而是点一旁的**`release`**（作者发布的包）

![这张图是Sticky Folders项目的GitHub页面，展示了手动安装教程中提到的错误下载方式，图中用红色箭头和红色框高亮标注了“Download ZIP”选项，并配有红色文字标注“错误的下载方式！”。该图用于说明github下载mod时的错误操作，对应文档中github下载注意事项的第一条，提醒用户不要选择“Download ZIP”的打包下载方式，而是点击对应release的正确包进行下载。](https://feishu.cn/file/GDaBb6vIyocXotxHcxWcQoennvf)

![图片展示的是一个GitHub项目页面，页面上方有“Sticky-Folders”标题，下方是项目相关文件列表。页面右侧有“About”板块，其中“Releases”部分被红色框线突出显示，内有“v0.4.0 (latest)”等版本信息。图片右侧有红色箭头指向“Releases”并标注“点这里的Releases”，与上下文“github下载时，不要直接点打包下载，而是点一旁的release（作者发布的包）”相呼应，指导用户在GitHub项目页面下载mod时的操作步骤。](https://feishu.cn/file/FhZFbYT6iop79exsLw1c2TN8nLe)

2.来到对应的**`releases`**页面，可以找到自己希望下载的 mod 版本。一般情况在对应版本下会有**`module.json`**和**`module.zip（或是其他压缩格式）`**文件

![图片展示的是在GitHub上下载mod文件的页面。页面显示了v1.0.5版本，其中“Assets”下有“StickyFiles.zip”和“StickyFiles.json”两个文件。其中“StickyFiles.zip”被红色框突出显示。该图片与文档中“github下载注意事项”部分内容相关，对应步骤2，说明来到对应的releases页面后，可找到希望下载的mod版本，一般在对应版本下会有module.json和module.zip文件，这里点击module.zip（或其他压缩格式）即可下载对应的mod文件，然后续接上文步骤6开始安装mod。](https://feishu.cn/file/DXY6bc348oTgbZxbIN1cdIVqnpg)

3.这里我们点击**`module.zip（或是其他压缩格式）`**即可下载对应的mod文件，然后续接上文的**`步骤6`**，开始安装 mod

4.点击**`module.json`**下载就按照上文下载方式，需要找到**`download`**字段下载，续接上文**`步骤4`**。

5.如果没有**`module.json`**和**`module.zip`**，那么则直接参照上文的下载方式，直接下载 mod 即可。



# **gitlab下载注意事项**

1.与github下载时类似，需要找到作者发布的包，这里点击**`tag`**或**`releases`**页面（`Dice so Nice!`的页面是**`tag`**）

![图片展示的是在GitLab上找到的`Dice so Nice!`项目的页面。页面左侧有项目管理等功能选项。右侧显示了项目信息，包括`5.1.6`分支、`882`条评论等。关键信息是右侧红色框标注的“Last tag”处，箭头指向“v5.1.6”，表明这是项目的一个版本标签。该图片与文档中gitlab下载mod的步骤相关，用于说明在GitLab上找到作者发布的包后，找到希望下载的版本并点击“build”以下载对应mod文件的操作。](https://feishu.cn/file/Ri0DbK5R9on40lxEcbKcWNZGnfb)

2.找到你希望下载的版本，然后点击右边的下载，在点击**`build`**，即可下载对应的 mod 文件，然后续接上文的**`步骤6`**，开始安装 mod

![图片展示了在GitLab上下载`Dice so Nice!`模组的步骤。在`tag`页面找到希望下载的版本，如`v1.8`，点击右侧的下载按钮，再点击`build`，即可下载对应的mod文件。图片中红色框突出显示了`v1.8`版本的`build`下载选项，箭头指向该选项，直观呈现了下载操作的关键步骤，与上下文介绍的GitLab下载注意事项相呼应。](https://feishu.cn/file/T91dbQj80o4pD8xSg5YcPtSfnsb)
