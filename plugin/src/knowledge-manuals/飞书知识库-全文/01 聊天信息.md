<title>01 聊天信息</title>

聊天消息是一种强大的工具，可用于向所有人展示您在宏中创建的信息。在本文中，我们将学习如何在宏中使用 `ChatMessage` 类。

---

# Basic Chat Messages 基础聊天消息

在本文中，我们将不使用 `ChatMessage` 类本身，而是使用 `ChatMessage` 类的 `create` 方法。

`create` 方法用于创建新的聊天消息。它接受一个对象作为参数，该对象包含聊天消息的属性。

```JavaScript
ChatMessage.create({    
    content: "This is the content of the message",    
    speaker: {...}, // This is who is sending the message    
    whisper: [], // This is an array of users to whisper to
});
```

## 示例：发送基本聊天消息

如果我们想向所有人输出聊天文本，只需要 `content` 属性。

```JavaScript
ChatMessage.create({    
        content: "This is a basic chat message",
});
```

## 示例：向特定用户发送聊天消息

如果我们想向特定用户发送聊天消息，需要指定 `whisper` 属性。

```JavaScript
const player1 = game.users.getName("Player 1"); // 通过名字获取用户
const player2 = game.users.getName("Player 2"); 
ChatMessage.create({    
    content: "This is a chat message to Player 1 and Player 2",    
    whisper: [player1, player2], // 向数组添加需要接收的用户
});
```

## 示例：向当前游戏主持人发送聊天消息

有时你可能希望宏向你发送消息，以便获知玩家运行了某个宏。

```JavaScript
const activeGM = game.users.activeGM; // 获取在线的GM
ChatMessage.create({    
    content: "This is a chat message that only the GM can see",    
    whisper: [activeGM],
});
```

# 聊天消息发言人

聊天消息的 `speaker` 属性用于指定消息的发言人。

获取发言者对象最简单的方法是使用 `ChatMessage` 类的 `getSpeaker` 辅助方法。

```JavaScript
const speaker = ChatMessage.getSpeaker(game.users.getName("Player 1")); // 获取Player 1的speaker对象
ChatMessage.create({    
    content: "This message is created as if sent by Player 1",    
    speaker: speaker, // 将speaker对象加入聊天信息中
});
```

你也可以使用演员或代币作为发言人。

```JavaScript
const speaker = ChatMessage.getSpeaker(token); // 获取选中token的speaker对象
ChatMessage.create({    
    content: "This message is created as if sent by the token",    
    speaker: speaker,
});
```
