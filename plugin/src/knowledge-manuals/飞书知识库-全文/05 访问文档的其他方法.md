<title>05 访问文档的其他方法</title>

在上一篇文章中，我们学习了如何通过 ID 或 UUID 访问文档。然而，还有其他访问文档的方法。

**示例情况：**

你需要一个宏来访问特定物品，但该物品可能存在于多个角色身上，而你希望这个宏对所有角色都适用。

---

# 通过名称访问文档

虽然 ID 和 UUID 对文档来说是唯一的，但 name 并非如此。例如，你可能有多个同名的角色。请记住，当使用 `getName`方法时，将返回第一个具有该名称的文档。

```JavaScript
const actorName = "My Actor";
const actorDocument = game.actors.getName(actorName);
console.log(actorDocument);
```

## 示例：更改特定命名的物品的图像

让我们回到之前通过名称访问特定物品的示例。

在这个示例中，我们将创建一个宏，用于检查当前选定指示物的角色卡上是否存在特定物品，如果存在，则将该物品的图像更改为另一个图像。

```JavaScript
const itemName = "My Item";
const itemDocument = token.actor.items.getName(itemName); 
if (itemDocument) {  
    itemDocument.update({ "img": "my/new/image.webp" });
}
```

## JavaScript 数组、数组方法和循环

（译者注：可以参考[菜鸟教程-JavaScript-数组](https://www.runoob.com/js/js-obj-array.html)）

在 JavaScript 中，数组是存储在单个变量中的值的集合。数组用于在单个变量中存储多个值，可以通过索引访问或循环遍历。它们可以通过方括号 `[]` 来区分。

**示例：**

```JavaScript
const myArray = [1, 2, 3, 4, 5];
console.log(myArray[0]); // Output: 1
console.log(myArray[2]); // Output: 3
console.log(myArray.length); // Output: 5
```

您可以使用 `push` 方法向数组添加值。

**示例：**

```JavaScript
const myArray = [1, 2, 3, 4, 5];
myArray.push(6);
console.log(myArray); // Output: [1, 2, 3, 4, 5, 6]
```

# 查找所有具有特定名称的文档

正如我们在前面的示例中所见，您可以使用 `getName` 方法来按名称查找文档。但是，如果您有多个同名的文档， `getName` 方法将返回第一个具有该名称的文档。

要查找所有具有特定名称的文档，我们需要使用数组方法。

**示例：**

```JavaScript
const itemName = "My Item";
let itemDocuments = []; // 创建一个数组来存储物品
for (const item of game.items) {  
    if (item.name === itemName) {    
        itemDocuments.push(item); // 如果名称匹配，则将物品加入数组
    }
}
console.log(itemDocuments); // Output: [item1, item2, item3]
```

## JavaScript For 循环

（译者注：可以参考[菜鸟教程-JavaScript for 循环](https://www.runoob.com/js/js-loop-for.html)）

我们已经了解了条件和数组，但这是我们第一次接触循环。循环用于多次重复执行一段代码。

我们可以指定循环次数，也可以遍历数组，JavaScript 会自动遍历数组中的每个元素。

**示例：遍历数组**

```JavaScript
for (const item of game.items) {  
        console.log(item);
}// Output: item1, item2, item3
```

**示例：遍历数字**

```JavaScript
for (let i = 0; i < 5; i++) {  
    console.log(i);
}// Output: 0, 1, 2, 3, 4
```

请注意，处理数组还有更高级的方法，但这些方法在性能或可读性上并不优于基本的 for 循环。因此，本指南将不涵盖这些内容。一旦你熟悉了 for 循环和数组，你可以根据需要进一步阅读有关数组及其方法的更多信息。如果你想了解更多关于 JavaScript 数组和数组方法的内容，可以查阅 [MDN 数组文档](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)。

# 同时操作多个文档

既然我们已经掌握了循环和数组的使用方法，现在可以利用它们来同时操作多个文档。

## 示例：批量修改场景中特定名称指示物的图像

我们已经了解如何获取特定名称的所有文档以及如何进行更新操作。现在让我们将这两者结合起来，创建一个宏，用于批量修改场景中特定名称指示物的图像。

```JavaScript
const tokenName = "My Token";
for (const tokenDocument of canvas.scene.tokens) {  
    if (tokenDocument.name === tokenName) {    
        await tokenDocument.update({ "texture.src": "my/new/image.webp" });  
    }
}
```

你也可以嵌套循环。假设你想更改所有场景中特定名称的所有指示物图像。

```JavaScript
const tokenName = "My Token";
for (const scene of game.scenes) {
    for (const tokenDocument of scene.tokens) {
        if (tokenDocument.name === tokenName) {      
            await tokenDocument.update({ "texture.src": "my/new/image.webp" });    
        }  
    }
}
```

作为最后一个示例，让我们关闭当前场景中的所有灯光。

```JavaScript
for (const lightDocument of canvas.scene.lights) {  
    await lightDocument.update({ hidden: true });
}
```

## JavaScript 关于 `await` 的说明

如上例所示，我们使用 `await` 关键字等待更新完成后再处理下一个文档。虽然在本例中每个更新彼此独立，无需如此操作，但在处理异步代码时，使用 `await` 仍是良好的编程习惯。

# 高级：批量更新

如果您需要处理大量文档，可以通过批量更新来提升性能。在大多数使用场景中，这并非特别必要，可能只是为了优化而优化。但处理多个文档时，采用批量更新仍是良好的实践。

需要注意的是，批量更新只能在相同的 `Collection` 内进行。例如，您无法同时批量更新指示物和物品，也无法通过单次更新修改所有场景中的所有指示物。

## Collections 集合

在 Foundry 中，集合是一种包含一组文档的数据结构。诸如 `game.actors` 、 `game.items` 、 `game.scenes` 和 `game.journals` 等都属于集合。您可以在 `game.collections` 中找到它们的完整列表。

虽然像 `Actor` 这样的对象本身不是集合，但它们是可以将其他文档作为集合嵌入其中的文档。例如， `Actor.items`就是属于该角色的物品集合。

## 批量更新语法

批量更新是通过 `updateEmbeddedDocuments` 方法完成的。

```JavaScript
canvas.scene.updateEmbeddedDocuments("Token", [updateData]);
```

第一个参数是我们正在更新的文档类型，在本例中为 `Token` 。第二个参数是一个包含我们要更新的数据的对象数组。

如果您不确定要更新的文档类型，可以在控制台中输出其类型。

```JavaScript
console.log(token.document.documentName);
```

让我们回顾之前的示例，但这次我们将使用批量更新。

## 批量更新示例

假设我们想要更改当前场景中所有令牌的图像。

```JavaScript
const tokenName = "My Token";
const updateData = [];
for (const tokenDocument of canvas.scene.tokens) {  
    if (tokenDocument.name === tokenName) {    
        updateData.push({
            _id: tokenDocument.id, 
            "texture.src": "my/new/image.webp" 
        });  
    }
}
await canvas.scene.updateEmbeddedDocuments("Token", updateData);
```

如你所见，我们使用 `_id` 属性来标识要更新的文档。同时，我们使用 `updateEmbeddedDocuments` 方法来更新文档。（译者注：`_id`在批量更新中是必须的）

如果我们想要更改所有场景中所有令牌的图像，可以使用相同的方法，但需要为每个场景分别调用 `updateEmbeddedDocuments` 来遍历所有场景。（译者注：不能一次更新的原因是没有`game.tokens`这么一个collection）

```JavaScript
const tokenName = "My Token";
for (const scene of game.scenes) {  
    const updateData = [];  
    for (const tokenDocument of scene.tokens) {    
        if (tokenDocument.name === tokenName) {      
            updateData.push({ 
                _id: tokenDocument.id, 
                "texture.src": "my/new/image.webp" });    
        }  
    }  
    await scene.updateEmbeddedDocuments("Token", updateData);
}
```

掌握了这些知识后，你现在应该能够在你的世界中执行各种批量更新操作。由于这是你第一次操作，强烈建议在开始更改之前对你的世界进行备份。
