## 0. 血的教训（最重要，先看这条）

1. **金标准一直摆在资料库里**：网格构筑师（`01_跑团工具\网格构筑师\`）的 TRAP_SCRIPT 就是陷阱结算的正确答案，照抄即可。我却自己发明了 UUID 托管、缓存、清理三层，绕了三轮才回到原点。
2. **图标绝不猜**：`icons/svg/status.svg`、`icons/svg/trap.svg`、`claw-hooked-barbed.webp` 全 404。必须先 grep 用户世界导出 JSON 拿真路径。
3. **midi 13.0.55 的目标来源是 `game.user.targets`**，`midiOptions.targetUuids` 被无视——自动触发单目标时照抄网格构筑师（单 token 恰好能工作）；要换目标必须 `updateTokenTargets` 清脏+写入+延时。

## 1. 复盘：陷阱项目翻车时间线（每坑一句话根因）

1. **UUID 陷阱第一轮被「物品无归属角色」拦截**——合集包物品没挂 NPC，midi 拒绝结算。→ 必须复制挂「网格机关·陷阱发动者」NPC。
2. **第二轮托管后卡死**——`MidiActivityMixin.ts:598 Cannot read properties of undefined (reading 'uuid')`：midi 豁免结算读 `game.user.targets`，集合里有 undefined 脏项（smarttarget 模块嫌疑）→ 崩在 completeItemUse 内部、markDone 没执行、重复触发=卡死。→ 结算前 `updateTokenTargets([])` 清空、`updateTokenTargets([tk.id])` 写踩入者、`await 80ms`、结算后清空。
3. **DC 覆盖永远是 10**——`act.save.dc.calculation:"flat"` 不是合法值，系统丢回默认 10。→ 正解 `calculation:""` + `formula:数字`（网格构筑师 Line 303）。
4. **NPC 旧副本污染**——测试把 DC10 副本留在了「网格机关·陷阱发动者」NPC 物品栏。→ 找同源副本（`gmlTrapCopy`+`sourceUuid` flag）直接 `actDoc.update({"save.dc.calculation":"","save.dc.formula":...})`，不再无脑复制。
5. **save 结算永远只炸第一个**——midi 无视 targetUuids 用 `game.user.targets`。→ 最终弃 midi 自掷豁免（`new Roll("1d20+"+bonus)` + `r.toMessage({speaker})`），三档语义 half/full/none 自己判。
6. **「过了豁免还扣血」**——Overtime 参数 `rollType:"check"`（属性检定）应 `"save"`（豁免）+ `damageBeforeSave:true` 先扣血观感错 → `false`。
7. **手动触发只命中一个 token**——中心点判定 `t.document.x + t.document.width/2` 错：`width` 是**格数**不是像素。→ token 像素边界矩形（`t.x/t.y/t.width/t.height`）与陷阱多边形包围盒相交判定，边界接触算。
8. **改完代码陷阱不生效**——RegionBehavior 的 executeScript **放置时固化**，改宏必须删旧陷阱重放。
9. **旧版格子删不掉**——flag 结构升级不兼容：旧平铺 `{simpleTrapsLayer:true}`（布尔）vs 新嵌套对象，删除逻辑只认对象。→ 匹配用 `getFlag(...) !== undefined` 通吃两版 + 给清理脚本。
10. **面板宏升级后旧 DOM 不重建**——`window.__st.panel` 持久对象，新控件（DC 覆盖框）看不到。→ showPanel 开头「新字段探测」，缺新字段则 remove 重建。
11. **V13 面板崩溃**——`Cannot set property element of #<Application> which has only a getter`：V1 Application 已弃，element 只读。→ 手搓 jQuery 浮窗（fixed 定位 + zIndex 10001 + appendTo body）。
12. **面板透明一坨**——用了不存在的 `var(--surface)`。→ V13 是 `--color-surface`，且要兜底色。
13. **按钮切场景消失**——唤醒块 `clearInterval(poller)` 注入成功即停；切场景重建控制栏 DOM 清掉按钮。→ 常驻轮询（见 §3.1）。
14. **导入报错**——`_id`/`author` 必须 16 位字母数字（宏实体同 activity `_id`）；Import Data 只认单对象。
15. **探针自己崩**——`JSON.stringify(args[0])` 遇 Token5e 循环引用；`Object.getPrototypeOf(undefined)`；`advancement?.length`（5.2+ 要用 `.size`）。→ 探针也要本地验证。

## 2. 正解存档（照抄这些，别再发明）

### 2.1 TRAP_SCRIPT 金标准（网格构筑师 Line 23-45，逐条照抄）
```js
if(!game.users.activeGM || game.user.id!==game.users.activeGM.id) return;   // 主 GM 才结算
const f = region.getFlag('world','simpleTrapsLayer'); if(!f) return;
const mode = f.triggerMode||'once';
if(mode==='once'&&f.triggered) return;
const token = event?.data?.token; if(!token?.actor) return;
const actorId = token.actor.id;
if(mode==='perActor'&&(f.triggeredActors||[]).includes(actorId)) return;
// 自掷豁免（弃 midi，原因见 §1.5）：
const sd = actor.system?.abilities?.[ab]||{};
const bonus = (typeof sd.save==="number"&&isFinite(sd.save))?sd.save:(sd.mod??0);
const r = new Roll("1d20+"+bonus, actor.getRollData()); await r.evaluate();
r.toMessage({ flavor:"...", speaker: spk(actor, token) });   // ★带 speaker，消 AC5E/blfx 警告
// 三档：half=成功半伤无状态；full=成功也全伤；none=成功无伤。失败=全伤+状态+Overtime。
```
- 目标集合判定：**token 像素矩形 ∩ 陷阱多边形包围盒**（`PIXI.Polygon`），不要算中心点。
- markDone：`perActor` 推 actorId 进 `triggeredActors`；`once` 置 `triggered:true`——都 `region.setFlag('world','simpleTrapsLayer',{...f,...})`。

### 2.2 Overtime 参数（51-推荐观看.md + data-dict Line 564）
`flags.midi-qol.OverTime`（mode 0）：`turn=start/end, damageRoll=..., damageType=..., saveDC=..., saveAbility=con, saveCount=1-, rollType=save（豁免！不是 check）, damageBeforeSave=false, actionSave=dialog, label=...`

## 3. UI 正解（按钮注入 / 面板持久化）

### 3.1 按钮注入轮询必须常驻
```js
let logged = false;
setInterval(() => {
  const $anchor = $("button.control.ui-control.layer.icon.fa-solid.fa-bookmark");
  if (!$anchor.length) return;              // 锚点（冒险者履历按钮）没出现，等下一轮
  if ($("#" + BTN_ID).length > 0) return;   // 按钮在，什么都不做
  const $btn = $(BTN_HTML); $btn.on("click", () => runMacro());
  $btn.insertAfter($anchor);
  if (!logged) { logged = true; console.log("已挂载（常驻巡查）"); }
}, 1500);
```
**严禁 `clearInterval` 即停**——切场景/重开控制栏会重建 DOM。1.5s 心跳只做一次选择器查询，极轻；重活只在点击时发生。

### 3.2 浮动面板持久化（localStorage）
- 位置：拖动 mouseup 存 `localStorage['simpleTraps.panelPos']={left,top}`；恢复时 **clamp 防出屏**（left≥0、top≥0、right≤innerWidth-宽-8、bottom≤innerHeight-60）；有记忆切 left/top + `right:'auto',bottom:'auto'`。
- 主题：`localStorage['simpleTraps.theme']`，applyTheme 时写入。
- 显隐切换用 `$panel.find(".cls").toggle(...)`，**勿用 `.first()`**（只切第一个匹配项）。

### 3.3 旧数据清理脚本（flag 兼容两版结构）
```js
const ds = canvas.scene.drawings.filter(d => d.getFlag('world','simpleTrapsLayer') !== undefined);
const rs = canvas.scene.regions.filter(r => r.getFlag('world','simpleTrapsLayer') !== undefined);
if (ds.length) await canvas.scene.deleteEmbeddedDocuments('Drawing', ds.map(d=>d.id));
if (rs.length) await canvas.scene.deleteEmbeddedDocuments('Region', rs.map(r=>r.id));
```
