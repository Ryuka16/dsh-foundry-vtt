## 〇、先纠正一个概念：日志里没有 JSON

把全部 611 个日志页扫了一遍：**没有一处 ```json 代码块，也没有 JSON.parse**。所谓「分裂之家的 json 写法」，实际上是三层东西：

| 层 | 载体 | 作用 |
|---|---|---|
| **自动化** | dnd5e 富集器记法 `[[/…]]`、`@UUID[…]` | 掷骰、豁免、伤害、发放、链接实体/歌单/宏 |
| **排版** | 模块自定义 CSS 类 + 固定 HTML 结构 | 叙事框 / 调查框 / 遭遇框 / 音频框 / 危害框 / 任务框等 |
| **资产** | `modules/house-divided/assets/...`（186 处 webp 引用） | 头像、指示物、场景图 |

house-divided 模块本体 = **一个 ESM（`house-divided-compiled.mjs`，约 170 KB）+ 一个 CSS**（manifest 键是老式的 `esmodules`，用 `m.es` 去查会误判成「零 JS」）。JS 里注册了：①自定义日志面板 **`HouseDividedJournalSheet`**（继承 dnd5e 的 JournalEntrySheet5e，羊皮纸外观就靠它，见第三节）；②`%APPROVAL%…%` 审批富集器；③声誉追踪等设置。日志页内的富集器渲染主要仍来自 dnd5e 5.3.3 + 核心——模块对 dnd5e 富集器做了上游补丁（源码注释：*Modified by Loot Tavern adventure. See dnd5e pull request #4419*，作用是给富集器注入所在页面的 rollData 上下文）。

## 一、自动化写法（8 类，全部有本世界真实用例）

### 1. 技能检定 `[[/check …]]` —— 全模块用量最大（546 次）

```
[[/check skill=inv dc=16]]
[[/check skill=prc dc=12]]
[[/check skill=ins dc=16 passive=true]]
[[/check skill=inv dc=10]]{检定 check}
```

- **实测渲染**：变成一组可点击的掷骰按钮 `<span class="roll-link-group" data-type="skill" data-ability="int" data-skill="inv" data-dc="16">`，带骰子图标 + 一个「请求玩家掷骰」副按钮（`data-action="postRequest"`）；`{}` 里是自定义标签。
- **`passive=true`**（18+ 处，如「察觉迹象特征」清单）：渲染成 `<span class="passive-check" data-passive="true">` 被动检定样式，hover 显示计算过程。
- 本世界用到的技能缩写：`inv` 调查、`prc` 察觉、`arc` 奥秘、`ins` 洞悉、`med` 医药、`his` 历史、`nat` 自然。

### 2. 豁免 `[[/save …]]`（21 次）

```
[[/save con dc=14]]
[[/save dexterity dc=12]]
```

- 属性缩写与全名**都能用**（`con`/`constitution`、`dex`/`dexterity`、`wis`/`wisdom` 混用）。
- **实测渲染**：`<span class="roll-link-group" data-type="save" data-dc="14" data-ability="dex">`，显示为「DC 14 敏捷」+ 请求掷骰按钮。

### 3. 伤害 `[[/damage …]]`（50 次）

```
[[/damage 2d6 type=bludgeoning]]
[[/damage 3d6 type=bludgeoning average=true]]
[[/damage 5d4 type=psychic]]
```

- **实测渲染**：带 `average=true` 时直接显示均值 **「10 (3d6) 钝击」**——均值在外面、括号里是可点击的 3d6 掷骰链接；伤害类型中文化（钝击/穿刺/挥砍/心灵）。
- 注意与 `[[/damage average]]`（无参、取物品活动伤害）是两回事——AHD 全部用的是**显式骰式 + type=**。

### 4. 普通掷骰 `[[/r …]]` / `[[/roll …]]`（10 次）

```
[[/r 1d4]]
[[/r 20 # 临时生命值]]
[[/r (1d4 * 10)]]
[[/roll (1d4 * 3)]]
```

- **实测渲染**：`<a class="inline-roll roll" data-formula="1d20" data-flavor="测试注释">`——`#` 后是注释（显示为 flavor），**支持括号表达式**。

### 5. GM 暗骰 `[[/gmr …]]` / `[[/gmroll …]]`（11 次）

```
[[/gmroll 1d4]]
[[/gmr 1d20 # 宅缚灵伏击几率]]
[[/gmr 1d12 # 宅缚灵休眠]]
[[/gmr 2d10[lightning] + 2d10[bludgeoning] # Maelstrom Damage]]
[[/gmr 2 + (1d4 * 2) # 额外尸妖]]
```

- **实测渲染**：`class="inline-roll gmroll"`——只有 GM 能看到结果。
- 进阶写法：`XdY[伤害类型]` 带类型骰、`数字 + (表达式)` 混合公式，都有真实用例。

### 6. 奖励发放 `[[/award …]]`（7 次）

```
[[/award 200g]]              ← ⚠ 原版自己的笔误（裸 g），不渲染
[[/award 47cp]]
[[/award 800gp]]
[[/award 5d6cp 2d6sp]]
[[/award 1d2pp 1d20gp 1d100sp 1d100cp]]
[[/award 7d12cp]]
```

- 币种：`pp/gp/sp/cp`，支持**骰式发放**（`5d6cp`）与**多币种一次发**（空格分隔）。
- **实测渲染**：合法写法变成「100 gp 奖励」发放按钮（dnd5e award 富集器）。
- **⚠ 币种必须写全 `gp/sp/cp/pp`**：裸写 `g` 不是合法币种，整段**原样不渲染**——原版 7 处 award 里就有 1 处踩了这坑（`[[/award 200g]]`）。对照实验：`[[/award 200g]]` 原样 vs `[[/award 100gp]]` / `[[/award 47cp]]` 均渲染成按钮。
- （勘误：本文档上一版曾把「不渲染」误判为「世界缺 party 卡」，已用对照实验纠正；按钮点击后的发放去向与 party 有关，本世界暂无 party，点击效果未实测。）

### 7. 实体链接 `@UUID[...]` —— 全模块最高频（每页 1~44 处）

```
@UUID[Actor.OIVtnbNiNbCi0gEa]{宅缚灵 Housebound}                          ← 怪物卡
@UUID[Item.2TpTXZIzWHqpHWOv]{克琳的魅影护甲}                               ← 物品
@UUID[Compendium.dnd5e.spells.Item.ghXTfe7sgCbgf1Q8]{侦测魔法 detect magic} ← 核心法术库
@UUID[JournalEntry.Kr7jDRSSoh9h54FH.JournalEntryPage.IAffhvl2mXE0DZSW]{事件：盛筵与狂欢}  ← 跨日志到页
@UUID[.hiHnb3z8JkPlEhhB]{继承信函}                                         ← 相对引用同日志的页
@UUID[JournalEntry.Q2Ugx1bL0kbKlRXR.JournalEntryPage.uJ8F15Har6MVMj6a#reuniting-usk]{重聚乌斯克} ← 页内锚点
@UUID[Playlist.wkwYAvfsdenrnpXD]{狂野迷宫 The Wild Maze}                   ← 歌单
@UUID[Playlist.GeUcEkyqtnFMYkZ4.PlaylistSound.C14Gr5OJqEompbRH]{分裂之屋 A House Divided} ← 歌单内单曲
@UUID[Actor.X4vtehnvPo43XEXD.Item.lNNNGBrEwgcX0ge4]                        ← 怪物卡上的具体物品
@{Macro.6ay8EaH7NRkH3yTu}{切换外貌}                                        ← 宏（见下「不生效」注）
```

- **实测渲染**（Playlist 为例）：`<a class="content-link" data-uuid="Playlist.L92Lp0rZX5mDprRJ" data-type="Playlist" data-tooltip="播放清单">🎵森林智慧</a>`——可点击、可拖拽。
- **音频的「自动化」真相**：AHD 的 45 个音频框**不会自动播放**——它们只是排版好的 GM 提示框，真正的「播放」动作是框里那个 `@UUID[Playlist…]{}` 链接（点开歌单/单曲手动播）。模块零 JS，没有自动触发逻辑。

### 8. 模块源内容里存在、但**本环境不渲染**的写法（照抄会踩坑）

| 写法 | 出现处 | 实测结果 |
|---|---|---|
| `@{Actor.xxxx}{名字}` / `@{.页ID#锚点}{名字}` | 角色传记等页（`@{` 出现 14+ 次/页） | **原样显示**，不是链接。dnd5e 5.3.3 与核心都不认 `@{}` 引用 |
| `{生物 Creature}`、`{死灵 Necromancy}` 术语高亮 | 遍布全文 | **原样显示花括号**。没有任何已注册富集器处理 `{}` |
| `&Reference[invisible]{隐形 Invisible}` | 影卫庄园页 | 源内容里 `&` 已被转义成 `&amp;`，富集器正则匹配不上 → **原样显示** |

> 这三种是原版（EN）内容自带的记法，本环境（Foundry 13.351 + dnd5e 5.3.3 + 零 JS 模块）没有对应的渲染器。**自己写日志时别用这三种**；要链接就用 `@UUID[...]`。

## 三、外观三件套（羊皮纸背景 / 装饰标题 / 彩色文本框）的来源

**它们不在页面内容里，在「日志条目用的面板」上。**

| 事实 | 实测证据 |
|---|---|
| 原版分裂之家条目都在条目级 flags 里指定模块面板 | `entry.flags.core.sheetClass === "house-divided.HouseDividedJournalSheet"`（读取原版条目实测） |
| 新建的条目默认用 dnd5e 面板 → 黑底、无装饰 | 默认注册项 `dnd5e.JournalEntrySheet5e`（default: true，注册表实测）；新建演示条目未设 flag 时就是它 |
| 模块面板已注册、可选 | `CONFIG.JournalEntry.sheetClasses.base` 里有 `house-divided.HouseDividedJournalSheet`（label「House Divided」，makeDefault: false，canBeDefault: true） |
| **页面内容标记与面板无关**——同一页内容在两种面板下 enrichHTML 产物一致 | 对原版页与自建页同屏渲染，`h2.border` / `.box-text` / 羊皮纸 `ui/parchment.jpg` 背景的计算样式逐项相同 |

**给任何日志开这套外观的两种方法：**

1. **UI**：右键日志条目 → 配置（Configure）→ 面板类型选 **「House Divided」**。
2. **API**：`entry.update({'flags.core.sheetClass': 'house-divided.HouseDividedJournalSheet'})`（实测生效；`entry.getFlag('core','sheetClass')` 回读确认）。

> 演示日志《写法演示 · 分裂之家日志规范》已按方法 2 设好 flag，外观与原版一致。

### 自研外观（「龙华卷轴」模块）

照 house-divided 的面板模式做了我们自己的主题模块 **`lh-journal-theme`**（鎏金夜卷：深墨渐变底 + 鎏金标题 + 七种语义配色盒子，作用域 `.lh-theme-gold`，不影响 HD 与核心样式）。要点：

- 面板类照抄 HD 的成熟模式：继承 `dnd5e.applications.journal.JournalEntrySheet5e` → 构造器 `this.options.classes.push(...)` → `_renderFrame` 里 `frame.classList.add("themed","theme-dark")` 强制主题 → 顶层 `DocumentSheetConfig.registerSheet(JournalEntry, "lh-journal-theme", LHJournalSheet, {types:["base"], makeDefault:false})`。
- **日志内容里嵌 `<style>` 块走不通**：会被核心净化器剥掉（实测渲染产物中无 style 元素）。自研 CSS 必须走模块文件。
- **服务器 `/upload` 有扩展名过滤（本服务器实测）**：`.json`/`.txt` 可传，`.css`/`.js`/`.mjs` 返回 success:true 但**静默不落盘**。因此模块代码文件需经服务器文件管理器放置（zip 包：`99_临时草稿\lh-journal-theme.zip`，内含安装说明）。
- 演示日志《写法演示 · 龙华卷轴主题》已建好并预设 flag `lh-journal-theme.LHJournalSheet`——模块未启用时自动退回默认面板，启用后即时换装。

### 自研主题系统 v2.1.0（贴图雕花 + 反向适配 · 内容驱动，无需面板配置）

## 四、实测记录（证据链）

**方法**：在你的世界（Edge 在线 GM 会话）里通过 REST 桥执行：
`TextEditor.enrichHTML(测试串, {async:true, relativeTo:页文档})`，输出节选如下——

- `[[/check skill=inv dc=16]]{调查检定}` →
  `<enriched-content enricher="dnd5e-enricher"><span class="roll-link-group" data-type="skill" data-ability="int" data-skill="inv" data-dc="16"><a class="roll-link" data-action="roll">🎲调查检定</a><a class="enricher-action" data-action="postRequest" …></span></enriched-content>`
- `[[/check skill=ins dc=16 passive=true]]` → `<span class="passive-check" data-passive="true" …>`
- `[[/damage 3d6 type=bludgeoning average=true]]` → `…data-formulas="3d6" data-damage-types="bludgeoning" data-average="true">10 (3d6) 钝击`
- `[[/save dex dc=14]]` → `…data-type="save" data-dc="14" data-ability="dex">DC 14 敏捷`
- `[[/r 1d20 # 测试注释]]` → `<a class="inline-roll roll" data-flavor="测试注释" data-formula="1d20">`
- `[[/gmr 1d4]]` → `<a class="inline-roll gmroll" …>`
- `@UUID[Playlist.L92Lp0rZX5mDprRJ]{森林智慧}` → `<a class="content-link" data-uuid="Playlist.L92Lp0rZX5mDprRJ" data-type="Playlist">🎵森林智慧`
- `[[/award 100gp]]` → 渲染成「奖励」按钮；`[[/award 200g]]`（裸 g）→ **原样输出**（币种非法，见上文第六节勘误）。
- `@{Item…}{}` / `{死灵 Necromancy}` → **原样输出**（本环境无对应渲染器）。
- `<section class="secret">`（GM 秘密段）→ `TextEditor.enrichHTML` **默认剥离**；传 `{secrets: true}` 则保留（实测）——核心按用户身份决定是否保留：玩家读不到、GM 可见。日志面板的真实行为未逐端核实，但机制本身已验证。

另实测：GM 打开日志页默认进 **ProseMirror 编辑模式（显示源码）**——这是编辑器特性，不是渲染坏了；切到只读视图即见上述全部效果。
