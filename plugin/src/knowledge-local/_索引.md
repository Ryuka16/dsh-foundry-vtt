| 飞书 wiki | 直接 HTTP 抓页面 HTML 后转 md（无需登录） |

**写 .ps1 脚本的坑**：用 write 工具生成的 .ps1 没有 BOM，PowerShell 5.1 会按 GBK 读 → 中文路径变乱码（龙华→榫欏崕）导致路径全部失败。必须先补 BOM：

```powershell
$f = '脚本.ps1'
$c = [System.IO.File]::ReadAllText($f, [System.Text.UTF8Encoding]::new($false))
[System.IO.File]::WriteAllText($f, $c, [System.Text.UTF8Encoding]::new($true))
```
