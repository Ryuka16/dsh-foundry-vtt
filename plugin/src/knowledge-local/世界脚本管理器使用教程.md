# World Scripter 世界脚本管理器 · 使用教程

> 本教程对应改造版 **World Scripter v1.1.0**。
> 核心：把「一个无处下手的巨型世界脚本文本框」变成「按分类拆分、可命名、带作用标注、可单个/全部导入导出、可测试运行」的脚本块管理器。

---

## 一、安装

1. 把 `world-scripter` 文件夹放到服务器 **`Data/modules/world-scripter/`**（结构如下）：
   ```
   Data/modules/world-scripter/
   ├─ module.json            # 模块清单
   ├─ lang/{en.json,zh.json} # 语言
   ├─ module/{world-scripter.js, scripter-ui.js}
   ├─ templates/scripter-app.hbs
   ├─ styles/scripter.css
   └─ README / 教程.md
   ```
2. 重启 Foundry / 刷新页面 → 进入世界 → 「游戏设置 → 管理模块」→ **启用 World Scripter**。
3. 若你之前有旧版，启用新版本前建议先导出一份旧脚本备份。

---

## 二、打开世界脚本管理器

- 进入 **游戏设置 → 模块 → World Scripter** 设置页。
- 页面里会有一个「**打开世界脚本管理器**」按钮，点击即打开管理器窗口。
- （旧版是直接一个大文本框，新版已换成这个按钮。）

---

## 三、界面说明

| 区域 | 内容 |
|---|---|
| 左侧「脚本块列表」 | 所有块，每个显示**名称 + 作用描述**；点击选中；右侧小方框是**启用/停用**开关 |
| 右侧「编辑器」 | 选中块的 **名称 / 作用描述 / JavaScript 代码** 输入区 |
| 右侧「元操作」 | **语法检查 / 测试运行 / 上移 / 下移 / 删除** |
| 底部「工具栏」 | **导出单个块 / 导入单个块 / 导出全部 / 全部导入** |
| 左上「新增块」 | 新建一个脚本块 |

---

## 四、脚本块怎么组织（按分类分）

建议**按功能 / 种类**把世界脚本拆成多个块（你的原脚本就是几件事混在一起，拆开才好找好改）：

- `骰控`（挂载 mapRandomFace、socketlib 分骰）
- `冒险者履历`（renderAdventurerLogApp 等）
- `21点 / 赛马 / 拼酒`（小游戏）
- `YGM GM 代办`（globalThis.YGM，供各宏调用）
- `全局宏 Toggle` 等

每个块填三样：
- **名称**：一眼知道这是什么（如「骰控」）。
- **作用描述**：一句话说明它做什么（会显示在左侧列表）。
- **代码**：该块的 JavaScript。

## 五、单个 / 全部 导入导出（重点）

### 5.1 导出单个块
1. 左侧**选中**某个块。
2. 底部点「**导出单个块**」→ 下载该块的 JSON 文件（单个对象）。
   ```json
   {
     "id": "xxx",
     "name": "骰控",
     "description": "商团骰运干预",
     "enabled": true,
     "code": "// ..."
   }
   ```

### 5.2 导出全部块
1. 点「**导出全部**」→ 下载全部块的 JSON（**数组**）。
   ```json
   [ { }, { }, { } ]
   ```

### 5.3 导入单个块
1. 点「**导入单个块**」→ 弹窗。
2. **粘贴**上面「导出单个块」的 JSON（单个对象），或点「选择文件」选那个 `.json`。
3. 确定 → 追加为新块。

### 5.4 全部导入
1. 点「**全部导入**」→ 弹窗。
2. **粘贴全部块的 JSON（数组）**，或选文件。
3. 确定 → 逐个追加为脚本块。

> ⚠️ **重要提示**：Foundry 自带的「导入数据 / Import Data」对话框**只认单个 JSON 对象，不认数组**。
> 所以「全部导入」这类数组格式，**请用本管理器的「全部导入」，不要用 Foundry 的 Import Data**。
> （单个对象虽也能给 Import Data，但本管理器追加更省事。）

> 📌 **本管理器 + 《宏后台核心》宏的联动**：见同目录 **《世界脚本宏格式规范.md》**。
> 它讲清楚「世界脚本 = 一个宏里的一段 JSON 数组」、每块四字段、以及**怕格式乱怎么防**（备份→验证→走界面别手撸 JSON）。**做世界脚本前务必先看那份。**

## 六、语法检查 & 测试运行

- **语法检查**：对**全部**块用 `new AsyncFunction` 校验一遍，有问题会报「块名 + 错误」。
- **测试运行**：单独跑**当前选中块**的代码（结果看 F12 控制台）。适合改代码后立刻验证某一块。
  > 注意：单块测试只跑该块本身。若它依赖别的块（如调用 `globalThis.YGM`），请先让被依赖块启用。

---

## 七、启用 / 停用 / 排序

- 左侧每块右侧小方框 = **启用/停用**。停用的块启动时不执行，但保留在列表里方便以后再开。
- 「**上移 / 下移**」调整执行顺序。**执行顺序 = 块在列表从上到下的顺序**，前面块定义的全局函数，后面块可用。

---

## 八、执行机制

- 启动（`ready`）时，按列表顺序**串联执行所有「启用」的块**。
- 所有块在**同一个全局作用域**下运行：块 A 挂到 `globalThis.xxx` 的，块 B 能直接用（跟你原来一大坨脚本共享全局的行为一致）。
- 某块报错只中断该块，不会影响其它块；错误会打控制台 + 弹顶部通知。

---

## 九、把你的旧脚本迁移成多块（推荐流程）

1. 先「导出全部」备份旧数据（或直接复制原 `scripts` 内容）。
2. 打开管理器 → 复制你原 `world-scripter` 大文本里的代码，按功能拆成若干段。
3. **新增块**，逐段粘贴进去，分别命名 + 写作用描述。
4. 勾选「语法检查」确认没拆错。
5. 刷新页面，F12 看各块是否按顺序执行成功；哪块失败定位到哪块，单独改。

> 拆分后：以后要改骰控只动「骰控」块，要导出给别人只导出那一个 JSON，谁看都很清楚——这就是「分栏 / 标签 / 作用标注」带来的维护便利。

---

## 十、常见问题

- **管理器按钮在哪**：设置 → 模块 → World Scripter 设置页，不在右侧栏。
- **导入报错**：检查是不是把「数组」粘进了「导入单个块」。数组用「全部导入」。
- **某块启动没生效**：确认该块右侧启用开关是勾上的，且页面已刷新（`ready` 才执行）。
- **依赖全局**：被调用的全局（如 YGM）所在块必须排在前面且启用。
