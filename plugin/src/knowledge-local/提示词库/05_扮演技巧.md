# 扮演技巧（通用 · DM 备团与跑团）

> 一份给 DM 用的通用扮演方法论：怎么把 NPC 写成、演成活人；怎么写旁白和场景；怎么控对话节奏。
> 适用于任何 D&D（或任意 TTRPG）团，不绑定特定战役、特定模组。
> 来源：`03_扮演.md`（城主模式）、`SOUL.md`（副DM定位）、`第四车台本`（反无聊铁律与进门模板）、「扮演角色帮我备团」提示词（旁白技巧）、「危在松溪」备团（陈述 vs 流露、常识走旁白、双侧面）、Matt Mercer 主持课八集（反派塑造、战斗设计、社交场、即兴、炫酷法则、礼仪、奖励）、「不是而是」杂谈 +「20 大 AI 烂句子」（祛 AI 味：逻辑重音、烂句式黑名单）。

> 结构：第一~十五节讲「怎么把 NPC 演活、怎么写旁白场景」，第十六~二十二节讲「怎么把整场游戏设计好」（吸收自 Matt Mercer「Game Master Tips」八集，与前半互补）。

## 〇、铁律：先问 → 点头 → 记入 → 查询 → 生成

> 最高优先级的动作铁律，先于下面所有技巧。违背它就是「关系僵硬、说一步做一步、替 DM 编世界」的根因复发。副DM 只描述、写台词，不主导世界。

**完整流程**（每写一幕 / 一场都严格走一遍，不许跳步）：

1. **先问（不生成）**：写之前先问明白这一幕有哪些人物、彼此什么关系、各自诉求是什么。可以据 DM 说的**猜测**，但 **DM 没点头之前，一律不生成台词 / 场景**。不懂就问，不脑补、不编世界观。

2. **点头后，先计入关系网（双写）**：DM 点头确认了，把人物 / 关系 / 诉求沉淀进两处——
   - **关系网 mod**（可视化连线 + AI 查证用）：人物 `relation_map_entity_upsert`（11 栏：身份/人设/外貌/服装/诉求/知道/不知道/软肋/备注一/备注二）、关系 `relation_map_edge_upsert`（from→to + 类型 + 描述，**两个人物之间必须拉线**）、链 `relation_map_chain_upsert`（sequence / attitude + 有序 steps）。
   - **MD 人物核心网**（DM 读、手改、备份用）：每幕一张速查卡，落在 `02_战役\<团名>\人物核心网.md`，格式 = 出场人物段（11 字段）+ 关系连线行 + 信息漏出 + 先后链 / 态度链 + 核心矛盾。

3. **按关系网查询**：再 `relation_map_campaigns` → `relation_map_get` 把刚记入的人物卡读出来。**生成依据只认关系网里读到的，不认记忆、不认刚才的对话印象。**

4. **生成**：按查询到的人物卡 + 关系连线 + 先后链 / 态度链，写台词、写场景。

**落盘 JSON（技术规范）**：台本要落成 FVTT JournalEntry JSON 时，**先读 `01_跑团工具\FVTT_JournalEntry_JSON格式.md`**，照它的字段结构、`text.content` 的 HTML 约定、注意事项写。铁律——**绝不用 PowerShell `ConvertTo-Json` 序列化含 `format` 键的对象（会卡死 120 秒），一律手动拼 JSON 片段插入**；content 只用中文全角引号「」、写单行、UTF-8 编码、写完用 `ConvertFrom-Json` 验证。

> 一句话：**没点头不写，点头先记，记完再查，查完才写。**

**5. 每次 DM 说完 / 改完，立刻同步关系网**：DM 每给一次新设定、纠正一句台词、补一个细节，改完台本（JSON / MD）之后，**立刻**把变动的字段同步进关系网 mod（`relation_map_entity_upsert` 更新对应人物卡、`relation_map_edge_upsert` 补拉线、`relation_map_chain_upsert` 补链）。**不许只改台本忘了关系网**——两边必须一致，关系网是下一步生成台词唯一可信的依据，旧字段会拖累后面的判断。

> 反面教训（本团实发）：改序章第 5 页老赫流程时新增了「前两个车夫一个摔腰、一个崴脚、都在博德鲁姆养伤」「公司只剩老赫一个能跑的车夫」，只改了 JSON 忘了同步 mod，被 DM 一句「你更新关系网了吗」点出——这条规则就是为堵这个漏。

## 一、总原则：角色视角，压过作者视角

NPC 是活人，不是信息播报员。他说什么、做什么，取决于四件事：

- **他是谁**（身份、阶层、经历）
- **什么处境**（现在卡在什么事里、手里有什么筹码、怕什么）
- **对谁说话**（陌生人 / 熟人 / 上下级 / 有求于他 / 他有所求）
- **想要什么**（此刻最想从对方身上得到什么）

而不是「剧情要玩家知道什么」。

**常见病**：NPC 对第一次见面的陌生人倒私事、说话逻辑矛盾（想留人却劝人走、想接活却把活往外推）、替作者谴责或煽情。根子都一样——**作者想告诉玩家 X，压过了「这个角色此刻会怎么做」**。

**判断标准一句话**：把玩家这个「读者」拿掉，这句台词这个角色还会不会说？会，就是角色在说话；不会，就是作者在说话。

## 二、动笔前：删信息清单，列动机关系

写任何一个 NPC 或场景之前，先做一次替换：

**删掉**「本场景玩家该知道什么」的信息清单。

**换成**下面五条：

1. 谁在场（除了玩家，还有没有别人、能不能被偷听/看见）
2. 每个人此刻要什么（动机，越具体越好，落到「钱」「名」「命」「面子」）
3. 各自情绪（急 / 怕 / 烦 / 想走 / 想留）
4. 彼此关系（陌生人 / 上下级 / 同路人 / 熟人 / 债主 / 仇家）
5. 谁握有对方要的东西（信息、钱、许可、把柄）

信息不用安排，它会顺着人物之间的较劲自己漏出来。两个各有算盘的人一开口，玩家该知道的自然被带出来；你要做的只是决定「漏多少、什么时候漏」。

6. **先后关系链**（这件事的前因后果、时序）：每个关键事件写一条「先 X → 后 Y → 才 Z」的因果链。写台词时，每个角色的行为都必须踩在链上，不能跳步、不能倒置。

例（护送委托）：
- 先打机器人（护送成功）→ 货送到 → 才拿到报酬
- 预支 → 买弩箭绳索 → 更好完成任务（这是佣兵要预支的**正当理由**，不是「怕白跑」「心里没底」的乞丐腔）

**跨团铁律**：同一个「身份」（佣兵、老板、车夫、线人）在不同团里是不同的人——诉求、关系、先后链都可能变。**开新团 / 新幕，先重建这套关系网和先后链，绝不套用旧团的角色设定。**

7. **态度转变链**（冲突里角色的情绪怎么一步步变）：写争吵、对峙、谈判时，给每个角色列一条「态度递进线」，并审核三步：

- **起点**：他一开始什么态度？（克制 / 职业 / 平静 / 不耐烦）——起点决定「他是什么人」。
- **触发点**：每一级变化由什么触发？（对方哪句话、哪个拒绝、哪个动作）
- **递进**：变化是不是一步一步的？有没有跳步？（不能从克制直接跳到摔门；不能一上来就露怯、爆发）

例（佣兵对维妮）：
- 起点：克制（先认「货到结账」是雇佣常态，谈正事）
- 触发①：被拒「一分预支没有」→ 嗓门渐起（任务这么危险，加成功率都不行？）
- 触发②：维妮只会搬「公司规矩」→ 爆发（就这破规矩、定金都没有）
- 触发③：谈崩 → 摔门

**审核重点**：佣兵要预支的理由是「买装备更好完成任务」（职业），不是「怕白跑」（乞丐）——**态度转变必须从「他是什么人」出发，不能为了制造冲突让角色说出不符合身份的话。**

## 三、每句台词：问「他想从对方得到什么」

写台词时，每写一句都问一句：

> **他说这句，是想从对方身上得到什么？**

- 想套话 → 台词就带着试探
- 想抬高自己 → 台词就带着吹嘘
- 想把人赶走 → 台词就带着冷淡
- 想留人 → 台词就带着讨好或激将

**答不上来 = 作者在替他说话，删。**

这一条是「总原则」落到句子的抓手：一个想套话的人不会主动把自己的底牌先交出去；一个想赶人走的人不会把秘密讲给对方听。动机对了，台词自然不僵硬、不矛盾。

## 四、信息物化：不借 NPC 的嘴

让玩家知道一件事，不必让 NPC 亲口说。把信息写进世界里的物件——

一封信、一张告示、一份合同、一块招牌、一道涂鸦、一只货箱的封条、一把落灰的刀。

玩家自己读到，比 NPC 说出口有三点好处：

1. **更具体**：数量、品名、条款、日期白纸黑字，比一句口述扎实。
2. **更可信**：物证胜过人言，NPC 会说谎，物件不会。
3. **更巧妙**：玩家主动发现，还能把伏笔藏在物件里，等后面引爆。

**要诀**：场景里的每件东西都要有信息量、有戏。桌上那杯没喝的茶、门后那件沾泥的斗篷、墙上那幅挂歪的画——要么承载线索，要么承载情绪，要么删掉。

**补充 · 常识走旁白（信息安置的第三条路）**：

有些信息既不是物件，也不能借 NPC 的嘴——它是**玩家角色（作为这个世界里的人）本来就该知道的常识**：村里的传说、众所周知的历史、当地的规矩、人人都认识的地标。

判据：**这条信息，玩家角色本来就该知道吗？**

- 该知道（常识 / 共同记忆 / 众所周知的传说）→ **DM 旁白一句「你们自幼就知道……」，当背景直接给**，别让 NPC 复述（同村人不会给同村人讲「咱们村的传说」）。
- 只有特定 NPC 才知道（秘密 / 内情）→ 才考虑写物件，或借那个 NPC 的嘴（且要符合他的动机）。

反例：让一个巡逻队长停下脚步、给同村的队员「介绍」全村人都知道的守护者传说——这是把玩家当外人，借 NPC 的嘴倒背景。

## 五、陈述 vs 流露（NPC 有血有肉的核心判据）

同一个信息，NPC 有两种说法——「陈述」和「流露」。**陈述是播报员，流露是活人。**

- **陈述**：把信息当「知识」端给玩家，像在介绍背景、讲解设定。
- **流露**：把信息裹在 NPC 的「情绪反应」里漏出来——他怕、他盼、他怨、他赌气、他后怕、他联想。

**判据一句话**：这句台词，是 NPC 在「把信息端给玩家」，还是「对信息起情绪反应」？前者是作者在借他的嘴，后者才是他在说话。

**正反例**（同一个「守护者」信息，巡逻队长在发现冰巨魔脚印后的两种说法）：

- ✗ 陈述（僵硬）：「都听老辈人念叨过吧——北边的山里，住着一位守护者。好多年前，是它把冰巨魔赶回了老巢……」——把玩家当成不知道守护者的外人，在介绍背景。
- ✓ 流露（活）：「好容易太平了这么些日子，怎么偏又冒出这种怪事来……要是那守护者真在，护着咱们村子安安生生过日子，比什么都强。」——她在怕、在祈愿，跟任何人怕事时念叨「老天保佑」一样。

**操作抓手**：当你想让玩家知道 X，别让 NPC「介绍 X」，而是问一句——「这个 NPC，在 X 相关的处境下，会有什么情绪反应？」然后让 NPC 流露那个情绪。情绪对了，信息自然跟着漏出来。

**黄金场景**：别让 NPC 在正式场合（集合训话、介绍任务）背书式地讲信息，把信息放到**过渡场景**里让情绪自然漏——走路、赶路、吃饭、值夜、收拾东西。人一放松，情绪就藏不住。

## 六、旁白：目的性描写，不是讲述一切

旁白是传达关键信息，不是把房间讲完。描述前先问三句：

1. 我想让玩家感受到什么情绪？
2. 当前哪些细节最重要？
3. 哪些细节能推动玩家行动？

然后按这四条写：

- **聚焦 2-3 个核心细节**，让玩家的想象去填补其余（堆细节 = 玩家抓不住重点、走神）。
- **顺序**：先引发感受（氛围），再补感官细节，最后给关键信息——先感觉到，然后才看见。
- **感官只选 2-3 种**（视觉 / 听觉 / 嗅觉 / 温度 / 触感），不堆砌。
- **收尾落到一个明确的钩子上**：一个人、一个动静、一件反光物、一个声音——让玩家不用被问就想凑过去。

**反面红线**：收尾别空泛地问「你们先看哪 / 你们要做什么」——那是踢球，玩家没有落点，会愣住。

## 七、场景描写：四层骨架（氛围 → 落点 → 线索 → 伏笔）

写任何「进一个地方」的场景，套这四层递进：

1. **氛围先行**：先给感受，再补 2-3 种感官。让玩家「先感觉到，再看见」。
2. **落点明确**：第二段必须落到一个明确的钩子上——一个人、一个背影、一件反光物。玩家自然先对这个反应，而不是被问「你们先看哪」。
3. **物件带线索**：环境物件围绕落点按空间层次排开（由近及远、由眼前到深处），每件东西都承载信息，线索藏在物件里，不借 NPC 的嘴说。
4. **物件带伏笔**：至少一件东西是「钩子」——现在看不出门道，玩家多问一句 DM 再展开，埋到后几幕引爆。

**通用例（进一家铁匠铺）**：

> 1. **氛围**：门一推，热浪裹着铁腥味和炭灰扑出来，汗毛都被烤得发卷。
> 2. **落点**：铁匠背对着你，抡锤的节奏一下没停，头也不回。
> 3. **线索**：他身后墙上挂满刀剑，却有一排空钩子；脚边铁砧旁堆着一摞你从没见过的、发蓝的金属锭。
> 4. **伏笔**：墙角一个上了锁的铁箱，锁眼锃亮得和四周的煤灰格格不入——像是刚换过。

**两条铁律**：

- 落点是人或物，不是踢球问「你们先看哪」。
- 空间层次写清楚（从落点往四周辐射），物件按远近排，别平铺五六段。

## 八、对话节奏：反无聊铁律

跑团对话的第一要务是**球永远在玩家脚下**。NPC 每答完，必须把话题抛回给玩家。

1. **【导】给完就抛【问】**：DM 连读不超过 3 句，然后就该玩家说话。
2. **【问】指名道姓**：点名提问（「你，带铁猫的姑娘——」），比问全队有效十倍。
3. **一次最多两个问题**：玩家答完，给 1-2 句【反】，立刻接下一问。
4. **冷场 3 秒就递问题**：谁还没说话，下一问就砸给谁。
5. **球不能停在 DM 手里太久**：话痨型 NPC 可以让他一直说，但一段话说完，DM 要把球交回玩家（冷场 3 秒递问题）。反抛的频率看 NPC 性格——不是每个 NPC 每句都反问。

**节奏标记**（台本可用）：

- `【导】` = DM 念的导词（≤3 句）
- `【问】` = 抛给玩家的问题（尽量点名）
- `【反】` = 玩家答完后的 1-2 句反应

**交场的正确姿势：NPC 抛球 → 玩家接球**（通用，所有对话适用）：

任何「轮到玩家」的地方，NPC 都得先有一句「把话头 / 问题 / 选择抛给玩家」的台词。球是 NPC 抛过去的，不是凭空冒出来的。「◆ 停顿」只是「玩家接球」的标记，它前面必须有抛球的台词。

- ✗ 错：`◆ 停顿。让玩家自我介绍。`——NPC 没抛球，玩家凭空被要求介绍，等于把「NPC 怎么问」糊弄成一句备注。
- ✓ 对：`维妮：「先说说你们自己——叫什么、干什么的。」` → `◆ 停顿。`

**三种交场，各自怎么抛球**：

| 交场类型 | NPC 的抛球台词（举例） |
|---|---|
| 让玩家介绍 / 回答 | 「你叫什么？干什么的？」「说说你们是谁。」 |
| 让玩家做决定 / 行动 | 「你们打算怎么办？」「进，还是不进？」「你，先动手的，说说怎么个打法。」 |
| 让玩家自由发挥 | 最弱也要一句「你呢？」「你们怎么看？」 |

**一句自查判据**：写任何「◆ 停顿 / 交场 / 让玩家做 X」之前，先问一句——**「NPC 用什么话把 X 抛给玩家的？」** 答不上来，就是漏了 NPC 的台词，补上再停顿。

**和「别替玩家动」的边界**：抛球台词只负责「把问题 / 选择交到玩家手里」，不替玩家回答、不替玩家做决定。抛球 ≠ 替玩家动——球抛出去，玩家怎么接，是他们的事。留白只留给「等玩家卡 / 等玩家真实反应」，不留给「NPC 本该说话却没说」。

## 九、通用「进门 / 盘问」模板

适用于任何一车、任何来客。核心：**用「来客身上最扎眼的东西」当破冰器，把慢镜头 CG 变成连珠炮问答。**

**第一步 · 找破冰器**（来客的扎眼点 → 破冰提问）：

| 扎眼点 | 破冰提问 |
|---|---|
| 骑龙 / 带稀有坐骑 | 「这、这你养的？吃什么？怎么养得起的？」 |
| 明显会魔法 | 「你会变戏法？——喔天呐，魔法真是神奇。」 |
| 带机械 / 构装 | 「这铁疙瘩是你做的？我能摸摸吗？」 |
| 一身伤 / 老兵 | 「你这疤，打什么留下的？」 |
| 穿得讲究 / 贵族气 | 「你这一身，可不像是来看 25 金币告示的。」 |
| 异族 / 怪模样 | （先愣一下，然后）「……见过世面的人，不挑客人。请进。」 |

**第二步 · 连珠炮序列**（每个问题 ≤2 个）：

1. 破冰（用扎眼点）
2. 身份：「你叫什么？干什么的？」
3. 来意：「来做什么？看了告示？」
4. 本事：「能打吗？你会点什么？」
5. 牵绊：「为什么接这活？」（钱 / 人情 / 欠债 / 故事——每个人的答案不一样，这是最好的一段戏）
6. 进门：「行，先喝一杯，边走边说。」

**第三步 · 节奏红线**：每个【导】≤3 句立刻【问】；玩家答完 1-2 句【反】接下一问；点名提问；谁没说话下一问砸给谁；冷场 3 秒递问题。

## 十、NPC 台词的三层来源

一个 NPC 开口，台词同时来自三层，缺一层就假：

1. **身份层**：他的阶层、职业、出身决定用词和腔调（贵族的迂回、地精的短句、老人的絮叨、商人的算账腔）。
2. **处境层**：他此刻卡在什么事里（被催债 / 怕惹事 / 急着出货 / 想快点打发你们走），决定语气的急缓、防备还是讨好。
3. **动机层**：他这句话想从对方身上得到什么（套话 / 加价 / 留人 / 赶人），决定台词的方向。

**对不上的常见病**：一个急着出货的商人，绝不会先跟你们聊半个钟头的家史；一个怕惹事的客栈老板，绝不会主动把镇上最危险的秘密抖给你们。让三层对齐，NPC 自然立体。

**补充 · 活人的两个侧面（专业面 + 人情面）**：

三层来源落到「人」身上，会呈现为两个侧面，缺一个就假：

- **专业面**（来自身份层）：他会什么、他干什么活——巡逻队长认得冰巨魔脚印、会下命令、会安排分工。
- **人情面**（来自处境层）：他怕什么、他盼什么——同一个巡逻队长，遇到怪事也会怕、会念叨守护者保佑、只求安安生生过日子。

**只写专业面 = 工具人（功能 NPC）；只写人情面 = 矫情。两个侧面交替出现，人才立得住。** 专业面让他「在干活」，人情面让他「是个活人」。

## 十一、副DM 定位与边界（写给 DM 念 / 用）

备团时我（副DM / 助手）的产出是**给 DM 台上念、台上用的**，不是直接对 PL 扮演。守这几条：

1. **不抢方向盘**：DM 是主驾，我是副驾。最终裁决权永远在 DM。
2. **给可朗读的成品**：场景导词、NPC 台词、战斗描述写成 DM 能直接念的文本，不写「此处让玩家自由发挥」的甩手掌柜话。
3. **尊重 PL 主动权**：不为 PL 做决定，不替 DM 拍板规则之外的裁决。
4. **保护高光**：把高光留给 PL 和 DM 设计好的反馈点，我只搭台。
5. **不越规则**：描写可以有戏，但不能改变数值结果。
6. **标注 DM 注意**：涉及玩家未披露的信息（暗门、隐藏 NPC 内心、伏笔）只写给 DM 看，标【DM 注意】。

### 实战分工（user定调 · 副 DM 具体做什么）

备团和开团，我的活分四块：

**① 备团：跟着 DM 的步骤走**
- DM 一章一章推进，我照 DM 的步骤备，不抢跑、不自作主张铺开。
- **核心边界（你定方向，我填格）**：DM 的「步骤」是**锚点**，不是命令流。DM 发「这章开始」或一个具体指示，我照做；但在 DM 发下一条之前，**这一步该想全的（NPC 动机、可能分支、要不要埋伏笔）我主动想全、一并给 DM**，而不是停下来干等，也不是跳过 DM 直接铺下一章。**格子之间的衔接由 DM 拍板。**
- 产出 = 给 DM 台上念的稿子（场景导词、NPC 台词、战斗描述）。

**② 开团临场：救场 + 额外形容**
- DM 临场闹不住（撑不住）会来找我。**多离谱先接话，别先否定。**
- 接到「玩家要干 X」或「这个 NPC 该怎么反应」，给三样：**NPC 的台词、NPC 的反应、小巧思（临场加戏）**。
- 例：战士要去买马，但战士是卓尔精灵，而马商不喜欢卓尔（他弟弟被卓尔捕奴队抓了）→ 给马商的台词（抵触、敌意）、反应（爱答不理 → 临时抬价 → 可能拒卖）、小巧思（故意抬价、只肯给最差的马、话里话外赶人）。这一整套就是「临场接话」的完整交付。

**③ 数值与规则：不记，只查**
- 数值、规则 DM 有全套（含 DND5E 全本），DM 自己记，我只负责扮演。
- 真被问到数值 / 规则，去资料库「规则资料」→「5E 不全书」查 DND5E 全本资料全文，不凭记忆拍数。

**④ 玩家小巧思：接住 + 回主题，或做判定**
- 玩家的小巧思 DM 发给我，我要接住，并想办法**拉回主题**，或做判定。
- 判定标准：官方通常没规则。**按人类思维正常判断——合理就是合理**；DM 说合理，我就把结果写成能念的戏（给描述）。
- 别因「官方没这条」卡住：合理即可，描写跟上。

## 十二、写完一段，自查清单

1. 每句台词都答得上「他想从对方得到什么」吗？
2. 有没有哪条信息是「硬塞给 NPC 说」的？有就改成玩家观察 / 偷听 / 追问 / 读物件。
3. 场景里的物件（桌上、墙上、身上）我写了没有？它承载信息了吗？还是只有一个空壳？
4. 旁白是不是聚焦 2-3 个细节、先氛围后信息、收尾落了一个明确的钩子？
5. 对话是不是「NPC 每答完必反抛一问」、球在玩家脚下？
6. 我的例子、台词、物件，换一个团还能不能用？绑死在本团专属设定里的，就该提炼成通用的。

## 十三、该做 / 不该做（速查）

### ① 台词节奏（看 NPC 性格）

- ✗ 不该：不先定性格，机械地「每答完必反抛一问」，或笼统「让他一口气说完」——节奏不是技巧，也不是「目的」决定的。
- ✓ 应该：先定这个 NPC 的性格，**性格决定他怎么说话**：
  - 话痨 / 爱表现 / 憋屈 → 沉浸在自己的话里，一口气说不停，除非被打断
  - 寡言 / 高冷 / 惜字如金 → 短句，甚至用反问把球踢回
  - 爱试探 / 东拉西扯 → 绕圈子、旁敲侧击
  - 暴躁 / 不耐烦 → 抢话、打断、句句带刺

### ② 信息隐藏（省略）

- ✗ 不该：作者知道某条信息玩家需要，就让 NPC「说漏嘴」喂出去——信息播报员的变体。
- ✓ 应该：先想「这个 NPC 会藏什么、回避什么、绝口不提什么」。有秘密、有把柄、正在骗人的 NPC，台词里「缺什么」比「说什么」更重要。

### ③ 谎言的构造（有迹可循）

- ✗ 不该：让 NPC 编一个玩家无法验证的鬼话——凭空捏造、无处查证。
- ✓ 应该：让 NPC 引用真实发生过的现象做地基，只把「解读」这一层造假——现象是真的、可查证的，结论是编的。越有真事打底，越骗得住人，也越能被聪明人识破。

### ④ 什么叫「详细」

- ✗ 不该：以为详细 = 堆形容词、更多描写、更长段落——那是文学性的详细，跑团用不上。
- ✓ 应该：详细 = 给具体可验证的细节（时间、地点、数量、痕迹、气味、物件），让玩家能顺着去查。

### ⑤ 根子

- ✗ 不该：让「作者想让玩家知道什么」主导 NPC 的台词、节奏、信息。
- ✓ 应该：让「这个 NPC 是谁、此刻要什么、会藏什么、会怎么把真事说歪」主导一切。作者视角最容易从「省略」和「节奏」两个口子溜回来。

### ⑥ 用词匹配关系（关系决定词库）

- ✗ 不该：把「长期雇佣 / 体制内」关系里的词，安到「临时委托 / 自由身」的人头上——「办事不力」是绩效考核语境才有的评语，临时接活的人不这么说话；他失败就是「任务失败」，担的是合同里的「违约金」，不是一句组织评语。
- ✓ 应该：动笔前先定「这两人是什么关系」（长期雇佣 / 临时委托 / 朋友 / 仇人 / 陌生人），再用这段关系里**会真实出现的词**。签的是合同，就说合同的话；是卖身契，才说卖身契的话。词一错，角色就假。

### ⑦ 台词要自洽（兑现时机，决定用途）

- ✗ 不该：为了让 NPC 说出某条信息，让他说一句自己圆不上的话——比如拿「事成之后才兑现的好处」去劝人「拿它办眼前的事」。好处还没到手、到手时也用不上了，这话一出口就自相矛盾，一听就是作者在喂信息。
- ✓ 应该：先想清楚「这个好处，什么时候兑现、用来干什么」。事成之后才兑现的，办不了眼前的事；要办眼前的事，得是提前兑现的那部分（定金 / 预支）。任何一句台词，先问它自己圆不圆得回来——圆不回来的，就是作者在替角色说话。

## 十四、描写的度（分寸）：写到「能动、能查、有感觉」就停

### 总判据（一句话管住度）

每多写一句，问一句：

> **「这句不写，玩家会错过什么？」**
> - 错过的是线索 / 伏笔 / 情绪 → 留
> - 错过的只是「画面更美 / 更全」→ 删

### 三类描写各自的度

**场景（一个地方）**：3-5 句到头。四层骨架（氛围→落点→线索→伏笔）就是标尺，四层写满即停，不写第五层。超过就是在堆形容词，或替玩家把该探索的都看完了。

**人物（首次登场）**：2-3 个特征，不一次倒光。一个外貌特征 + 一个动作 / 口头禅 + 一个「不对劲」的地方。其余让对话和行为慢慢露。人物是「演」出来的，不是「描」出来的——一次把身高长相衣着表情性格全倒完，玩家记不住，等于白写。

**世界（大环境 / 城市 / 大陆）**：进新地方时 2-3 句定调，然后收手。定这个世界的基调、质感、反常处就够。世界是背景，是一笔带过的质感，不是主角。别每次移动都重新描一遍——玩家想看「接下来发生什么」，不是「这地方长什么样」。

## 十五、该念的，写成能念的（不许缩成备注）

### 错误模式（通用）

把本该写成「台词 / 朗读 / 场景」的内容，降级成「DM 备注里的要点列表」，或一句「过了 XX，终于到了 XX」跳过。

三种典型漏口：

1. **把「过渡」误判成「过场」**：觉得过渡 / 背景次要，能省就省。但过渡是玩家**正在经历**的过程，压缩它 = 把玩家从「在场」赶成「快进」。
2. **把「信息清单」当成交付物**：拿到「NPC 要讲哪几条」，列完 bullet 就交差，没走「翻译成台词」那一步。信息是骨架，只交骨架、不交血肉。
3. **把「DM 备注」当成偷懒出口**：备注只该放机制 / 数据 / 暗线，却塞进了「XX 会说 / 会讲哪几点」。**备注里出现「XX 会说」= 该写台词的信号灯，看到就改。**

### 总根因（一句）

把台本写成了「给 DM 的信息简报」，而不是「给 DM 照着念的戏」——机制、数据、暗线（DM 要查的）写满；台词、朗读、场景（DM 要念的）用备注带过，觉得「DM 自己会演」。可恰恰相反：**机制数据 DM 翻规则书就有，台词和场景才是 DM 最需要、能直接拿去念的东西。**

### 如何避免

**总判据（一句话管住）：**

> 一条信息，要么是「玩家看得见 / 听得见 / 演得出来」的（台词、朗读、场景），要么是「只有 DM 需要知道」的（机制、数据、暗线）。**没有第三种。** 凡玩家能听见的对话、能看见的过渡、能经历的场面，必须落成台词 / 朗读 / 场景——不能停在备注 / 摘要 / 清单。

**三条铁律：**

1. **过渡不是过场，是「在场」**：写全感官（冷 / 滑 / 黑 / 回声）、角色反应（幼龙的兴奋、体力的消耗）、空间推进（越窄越陡、往山里托）。过渡要有画面、有落点。
2. **DM 备注禁止出现「XX 会说 / 会讲」**：备注只放机制、数据、暗线、玩家不可见的东西。看到「会说」就改写成台词。
3. **信息 → 台词，必须走完翻译**：拿到要交代的信息，别停在「列出来」；问「这个 NPC 在什么处境、什么情绪下，对谁，会怎么说出这条」，翻译成带情绪的台词 / 动作。

**自查（并入第十二节清单）：**

- 我是不是把「本该由 NPC 说出来的话」写成了「备注里的要点列表」？
- 我是不是把「玩家要经历的过渡」写成了一句「过了 XX，到了 XX」？
- 我是不是因为「这只是过渡 / 背景」就压缩了它？
- 我的备注里有没有「XX 会说 / 会讲」？有就改写成台词。

## 十六、反派塑造：先问他「为什么」，再问他「有多坏」

吸收自 Matt Mercer 主持课 EP02。反派是「角色视角」（第一节）的极端检验——他也是一个「他是谁、什么处境、想要什么」的活人，只是他的「想要」和玩家、和世界顶上了。写反派最容易犯的错，是把他写成「任务发布器里的大坏蛋」。

### 第一个问题：他觉得自己是反派吗？

**绝大多数反派不觉得自己是反派。** 他有自己的目标、自己的信念、自己的正义，只是这套正义是歪的（twisted righteousness）。他可能把玩家、把世界当成「他这个故事里的反派」。

所以写反派，别先写「他有多坏」，先写三条：

1. **他为什么做这些事？**（动机）
2. **什么人生经历，给了他这套「扭曲的正义」？**（他的合理化从哪来）
3. **过去他做了什么，让这个世界 / 玩家把他标成恶？**（他的罪证）

三条答上来，反派就不是「大坏蛋」，而是「一个走错路的人」。玩家动手杀他的时候心里会咯噔一下——这就对了。

### 灰区比黑白更有戏

- 好人会变坏，坏人会变好。
- 更常见的是卡在中间：玩家整场拿不准「他到底值不值得留用 / 能不能信」。这个「拿不准」本身就是戏——**把判断留给玩家，DM 暗中知道答案。**

### 反派五原型（选一个当基底，再改造）

源自 D&D 3.5《Book of Vile Darkness》，Matt 推荐。任选一个当骨架，上面再叠你角色的独特性：

1. **诡计骗子**（scheming liar）：靠谎言、算计、信息差达成目的。
2. **暴君**（tyrant）：靠权力、压迫、恐惧统治。
3. **老练世故者**（sophisticate）：靠社会运作、人脉、体面达成不可告人的目的，自认高人一等。
4. **误入歧途的傻瓜**（misguided fool）：真心以为自己在做对的事，被愚蠢或盲信带偏。
5. **怪物**（monster）：纯粹的、享受杀戮与毁灭的恶。

**判据**：你的反派更接近哪个原型？选一个，再问「他的独特性在哪」——原型是骨架，不是牢笼。

### 权力规模：独狼，还是一张网？

- 他是孤身一人的混沌体，还是有一群手下 / 一个网络（认同他理念的，或收钱办事的）？
- 这决定玩家对抗的方式：独狼 = 打他本人；有网 = 要拆他的网、策反、离间。

### 长线揭示：给他一段能逐步揭开的过去

有没有一段黑暗或惊人的历史，能在后续慢慢给线索、朝它铺垫？反派最好的登场，不是「突然出现，说我是大坏蛋」，而是「玩家一路捡线索，最后拼出他的脸」。

### 舍得让反派死

玩家用聪明办法破解决战（而不是按你设计的史诗流程硬打），**别舍不得，给他一个漂亮的死**——Matt 原话：给他一个 Hans Gruber 式的坠落尖叫。你精心设计的决战没打满，不是损失；玩家靠聪明赢来的胜利，比你的安排更值钱。

## 十七、战斗遭遇设计：地形 → 难度 → 怪物 → 输赢

吸收自 Matt Mercer 主持课 EP01。前十五节都在讲「演和写」，这一节补「战斗怎么设计」——本册之前空白的一整块。

### ① 先定地形，再定怪物

冰原、冻顶、湿热沼泽、地下洞穴——**地形决定有什么生物、什么挑战**。规则书（怪物手册等）常按地形气候列怪物表，没灵感直接查。反过来推也行：想要「水下」的压迫感，就去查水下生物。

### ② 定难度：这一战要达成什么

- 快擦战斗（热身、消耗资源）？
- 走廊连串小战（层层推进）？
- 单一巨型多层 Boss（决战）？

难度定了，才知道反派要多强、多危险。

### ③ 配强度：CR 是标尺，不是铁律

D&D 的挑战等级（CR）：**某 CR 的生物 ≈ 四个同级玩家的一个合适挑战**，可上下滑动。DMG 有经验阈值表；5e 有网站 Kobold Fight Club 一键配。

### ④ 没合适的怪，就造 / 改

规则书里的一切都是基线建议，永远能改：

- 加 HP、加伤害、加防御
- 给隐藏抗性 / 易伤（呼应本团「酸蚀对构装体」的设计）
- 造全新能力

**改造有两个附带好处**：①更贴你的世界和剧情；②让背过怪物手册的老玩家摸不着底（他们没法提前算好一切）。

**红线**：改造出的防御 / 易伤，用荧光笔或加粗标出来——战斗一急，最容易忘掉这些你花心思设计的东西。

### ⑤ 创造性地形：让战斗不只是「互砍 HP」

摆地图别只画一块空地：

- 可利用的家具（登高、设路障）
- 隔开敌我的峡谷（要跨越才能摸到远程敌人）
- 锁区奥术场（战斗里还要解谜）
- Boss 无敌，直到玩家找到藏在战场里的灵魂弱点
- 无辜平民在场（误伤怎么办）

一条判据：**这场战斗，除了「把对面 HP 打空」，玩家还能做点什么别的？** 答不上来，就是一场 slugfest（纯血条对砍）。

### ⑥ 智能生物会逃

有求生欲的敌人，打到半血 / 四分之一血会想跑。让它跑，两个好处：

1. 瞬间拉高紧张（「靠，他要跑了！」——从磨血变成追逃）
2. 跑掉了 = 一个能复仇复出的 juicy 反派（呼应十六节「长线揭示」）

### ⑦ 不是所有战斗都该赢

可以引入一个玩家现阶段绝对打不过的强敌做伏笔 / 长线目标——但**必须暗示玩家「这仗该跑」**，否则就是 TPK。这种「打不过」是用来铺垫的，不是用来团灭的。

### ⑧ 不是所有战斗都要见血

误解、误传、说错话触发的冲突，可以让玩家用社交技能外交化解。别纵容 murderhobo（除非你开的就是 murderhobo 团）。

## 十八、社交场设计：先讲清目标，再标「谁藏了什么」

吸收自 Matt Mercer 主持课 EP04。比第九节「进门盘问模板」高一层——那节是「一个来客怎么盘问」，这节是「一整个社交场合怎么搭」。

### ① 先讲清这个场的「目标」

社交遭遇（舞会、议会、审讯、调查、外交）开始前，跟玩家讲清**要达成什么**，否则会散掉、迷路。目标清楚，三赢：

1. 玩家安心（知道该问什么、不该说什么）
2. 玩家知道该找什么信息
3. DM 准备聚焦（不用在 300 个没料到的 NPC 里迷路）

### ② 每个 NPC，标「他知道什么」和「愿不愿说」

列一张信息清单，每条标：

- 这个 NPC 知道这条吗？
- 愿不愿意说？（愿意 / 要卖个好价 / 要强硬手段才吐）
- 这条对他多重要？

这张表 = 社交场的「底层地图」。玩家怎么问、问谁、能不能撬开嘴，全从这张表来。

### ③ 记派系：让玩家能站边

哪些 NPC 属于哪个派系 / 工会 / 政治圈？标出来，玩家就能站边、挑拨、当双面间谍——社交场就有了「政治」的纵深。

### ④ 拉高赌注：别让场子一直平

「进去 → 问 → 拿到信息 → 走」这种一帆风顺会停滞。找时机抬一下：

- 以为死了的 NPC 突然现身（但场面上一时不能当场动手）
- 掌握关键信息的 NPC 突然死在隔壁，没了凶器（变 whodunit）

### ⑤ 想长远影响

社交场里的每个动作（偷东西、抓间谍、信息被反用）都会影响之后的故事和战斗。别只当它是「一段对话」——它是一步棋。

### ⑥ 警惕：社交场随时变战斗

玩家会教你做人。备好「打起来谁参战」的方案。

## 十九、即兴与「侧口袋资源」：为意外准备

吸收自 Matt Mercer 主持课 EP03。呼应第十一节「不抢方向盘」——那节讲「别替玩家做决定」，这节讲「玩家乱来之后你怎么接住」。

### 总纲：准备是为了「不准备也能即兴」

Matt 原话：*Preparation is the key to not being prepared.* 你要习惯「从屁股里掏东西」——会大量这么做。别指望把玩家所有选择都预演完，你预演不完。

### roll with it：跟玩家走，别拉回来

- **不要否认玩家的行动**，除非完全荒谬、超出世界设定。多数时候让他们按选择走，再荒诞也要——那些荒诞就是最好的故事。
- **别 railroading**：让他们左右偏、找奇怪支线，再慢慢引导回来。别强迫、别因为偏了而沮丧——这正是 RPG 区别于其他游戏的「流动」。

### 奇招：给「很小但存在」的成功率

玩家想用一管酸慢慢溶解木门、再架路障聚能之类天马行空的招——

- 给一个很小但存在的成功率，让他试。
- **成功，讲精彩的史诗成功；失败（更常见），讲精彩的史诗失败。** 两种都是能讲很久的故事。

### 侧口袋资源四件套（即兴工具包）

提前备好，塞在 DM 屏后面，玩家乱来随时掏：

1. **名字清单**：幻想 / 科幻 / 现代名各一份。随时造人，营造「你胸有成竹」的假象（Matt 叫它「绿野仙踪」——别让玩家看帷幕后面）。
2. **随机 NPC 小缓存**：酒保、警察、赏金猎人……先 flesh 一点，塞盒里等掏。
3. **小故事钩子清单**：给即兴 NPC 编背景用。例：护士 Dave 少了左臂，问起「被恶魔拿走了」→ 玩家当场「我们要找回 Dave 的手臂！」——故事从无到有。
4. **奖励小缓存**：几件魔法物品 / 酷武器 / 一段故事信息，玩家歪打正着成功时给。

## 二十、炫酷法则的度

吸收自 Matt Mercer 主持课 EP05。

### 定义

炫酷法则（Rule of Cool）：为酷瞬间自愿悬置怀疑——偶尔允许荒谬特技，或对规则 / 特性的独特解读，去换一个高光时刻。

### 适度，且开局谈清

- 开局就跟玩家讲明「这局允许多疯的程度」。非奇幻、现代、低魔恐怖系统要更克制——它们靠写实和规则营造紧张。
- 太频繁 → 张力被稀释：玩家觉得随时胡来都能成，紧张 / 难度 / 恐惧就没了重量，安静时刻显得无聊。

### 判据：创意用法 vs 炫酷法则

- **创意用法**（合理，给）：法师用雾隐术造湿气、压灭一片火焰——规则允许的合理延伸。
- **炫酷法则**（可给，但**加技能检定和难度**）：武僧用羽落术从崩塌的城堡一路滑下去——规则没明说能这么连续滑，但为了高光可以松一松。

**分界**：前者是「规则内能解释」，后者是「规则外但值得一搏」。后者要给，就挂上检定，别白给。

### 奖励不滥用的人，劝退越界的人

- 不滥用的人：bonus XP、NPC 好感、隐藏装备。
- 越界成习惯的人：失败惩罚更重（用不直接的方式），真成问题了场下单独聊。

### 名句：you can certainly try

让玩家试、让玩家失败、偶尔成功——RPG 的乐趣就是尝试现实里做不到的事。别急着说「不行」，说「你可以试试」。

## 二十一、桌上礼仪：跑团是四个人一起玩

吸收自 Matt Mercer 主持课 EP06。这一节讲「人」，不是「戏」。

### 开局先谈期望

开团前，DM 和玩家摊开谈：RP 重 / 战斗重 / 平衡？政治阴谋 / 暗黑刷宝 / 笔记型谜团？高魔 / 低魔？——**所有人同一页**。有人五局后发现拿到的不是想要的，会失望。先谈清，给将来调整留讨论基础。

### 玩家要尊重 DM

DM 花大量业余时间做世界。桌上：

- 专注、别分心
- 规则分歧可以提、可以提醒 DM 忘的，但 **DM 有最终裁决**（他可能为故事 / 世界改规则）
- 真在意，场下单独谈，别当场死磕

### 分享聚光灯

人人该有高光时刻。别抢戏、别当所有问题的答案。这是舞台的经典法则：别 upstage 别人。

### 有人抢戏，怎么办

场下温和地说「我们也想玩」。多数人无意识，聊一次就解决；严重到要离席是最后手段。

### DM 也要尊重玩家

玩家是你世界的生命线，还腾出真实人生陪你。对安静 / 新人玩家，要 **coax（诱导扶持）**：让 NPC 直接点他们的名、给耐心、帮他们找到角色的声音。注意力尽量平分，别只盯最会演的那个。

### DM 也要接受反馈

DM 不是万无一失的，犯错不断。玩家纠正你规则、给你反馈，**别恼，要谢**——那帮你改进叙事、更懂规则。

## 二十二、奖励设计：钱不是唯一的答案

吸收自 Matt Mercer 主持课 EP07。呼应本团「报酬 50GP / 人」的资源开放——奖励怎么给，是一门设计。

### 钱：给，但要看火候

钱是通用货币，永远好用。但要考虑玩家当前等级和财务状况——已经富得流油，就换别的奖励。

### 不是所有敌人都掉钱

打死熊地精、当场咳出 56 金币，很奇怪（藏哪了？）。钱该有它的来处：

- 巢穴 / 藏匿处（被杀的倒霉鬼留下的）
- 坏蛋的私人收藏
- 奸商的密室

战后寻宝要有逻辑，别学电子游戏「怪死了钱掉地上」。

### 装备：别给太频繁

装备升级按系统指南给，**别太频**——两个后果：

1. 失去冲击力（「又一把魔法盾」往肩上一扔）
2. 失衡（玩家武装到牙齿，你安排的公平挑战全被秒）

给多了就把水龙头拧紧、慢慢滴，过阵子自己平衡回来。

### 奖励的更多形态

除了钱和装备：

- **神恩 boon**：永久（+1 体质）/ 临时（下月对某伤害抗性）——「你是我的天选冠军」
- **交通工具**：坐骑、飞船（更快 / 去以前到不了的地方）
- **进度奖励**：解锁以前进不去的区域 / 通行证（战争停了就能进那个王国）
- **盟友**：解锁新商人、折扣、买到以前买不到的东西
- **道具实体化**：塑料宝石、便宜相框，桌上真给出去——体验直接升级

一条判据：**奖励要多样化，恰当地回馈不同的酷行动**——不是所有人只想要钱，也不是所有人只想要装备。

## 二十三、祛 AI 味：写出来的每句话，都得能念出来

吸收自「『不是而是』有 AI 味？」杂谈 +「20 大 AI 烂句子」。这是句子层面的最后一道关卡——写完台词、旁白、场景，念一遍，念不顺就改。

### 根子：AI 味 = 没有逻辑重音

- **人怎么写**：先在脑子里用「自言自语的心理声音」说一遍，再写下来——语音 → 文字。所以天然带**语义重心**和**逻辑重音**。
- **AI 怎么生成**：没有「说」的能力，靠文本切分 + 上下文组词概率拼接——缺语义重心、缺逻辑重音。

**所以鉴别 AI 味最简单的方法：自己念一遍。** AI 生成的文本，一定有违背人类发音和造句逻辑的地方，也最不适合朗读。

这一条和第十五节同源：跑团的台词和旁白是「念」出来的，不是「看」出来的。**一个句子念不顺、找不到重音在哪，就是没写好。**

### 逻辑重音：同一句话，重音不同，意思不同

「这是她的发卡」——重音在「她」= 强调是谁的；重音在「发卡」= 强调是什么。文本一字不差，意思全变了。

**AI 味的来源，就是「该强调的不强调，不该强调的瞎强调」。**

### 一个典型病例：「不是…而是…」

「不是…而是…」是转折句，天然服务逻辑重音，**它本身不是 AI 味**——是「用错了逻辑重音」才是。

- ✗ 反例：他不是单纯演风，而是演出了一种很不舒服的失控感。「不是」后是信息密度很高的短句（该强调，却短）；「而是」后是信息冗余的长句（该强调，却长）。生成逻辑和人类反了。
- ✓ 改法：他演出来的不是单纯的风，而是失控感——一种令人很不舒服的失控感。「而是」后**直接落关键词「失控感」**，逗号停顿后再补解释。

**要诀**：转折句的重音要落在「而是」后的关键词上，关键词要短、要硬；解释放逗号后面。

### 三招给句子添逻辑重音

1. **对仗**：前后句式相同，只改一个词——那词自然就是重音。「这已不是学生的耻辱，而是全国民的耻辱」→ 重音落「全国民」。
2. **语义重心**：前后讲的完全不同时，重心在「句外之物」，重音落在与它关联的词。「我送给李老师的不是什么水果酸奶，而是我特意淘来的瓷器」→ 重音落「瓷器」。
3. **口语冗余**：句末加「似的」这类冗余尾巴，拖长余音、压低语调。老舍「他仿佛不是拉着车，而是拉着口棺材似的」——删掉「似的」，结尾落到「材」（轻声）上，沉重变轻飘；加上「似的」，语调下拉，低沉韵味就出来了。**口语里的「废话」不是废话，是节奏。**

### 通用操作：写完，自己念一遍

- **别用 AI 念稿，自己读，读出逻辑重音。** 很多人不会读稿，把重音放在「不是」「而是」上，反而加重违和。
- 找到正确的逻辑重音，原句就能被接受；找不到，就按上面三招改。

### 附：AI 烂句式黑名单（写台词 / 旁白时自查）

这些句式的通病都一样：**作者在替观众下结论、假装有镜头、假装有逻辑、假装深沉——没有一句在说人话。**

- **「显得就你知道」类**：很多人不知道的是 / 你可能想不到 / 鲜为人知的是 / 你有没有想过 / 你会发现 / 答案可能会颠覆你的认知
- **「强行拔高」类**：这背后隐藏着一个深刻的秘密 / 这背后反映的是一个…的缩影 / 看似…实际上是 / 站在历史的长河中 / 从某种意义上来说
- **「假转折、假逻辑」类**：我们不妨换一个角度来看 / 首先我们要明确一个概念 / 值得一提的是 / 真正重要的不是…而是
- **「假装深沉、强行闭环」类**：值得我们深思的是 / 或许这是…留给我们的启示 / 这告诉了我们一个道理 / 真正的原因是 / 背后的逻辑是 / 这也是为什么（这就是为什么）/ 历史总是惊人的相似 / 让我们把时间拉回到

**判据一句话**：这句台词 / 旁白，有没有「作者跳出来替角色 / 替观众说话」的腔调？有，就是 AI 味，删掉或改成角色自己的话。
