# 服务器购买与部署
部署 FVTT 最关键的是你需要让其他玩家能连上，可通过服务器或者内网穿透等方式实现，本教程只讲解在服务器部署。
FVTT 并不吃服务器配置，而是占用你本地的配置（即访问 FVTT 服务器的客户端配置）。
FVTT 特别需要带宽，因此常规的轻量云很难满足需求，故而一般都会购买 CVM（云服务器）。

# 系统、世界包和 mod 的简要介绍
系统：即你跑团所用的规则，FVTT 社区程度最高的就是 D&D5e 系统和 PF2 系统，这也是大多数人的选择，当然，也有一些其他的系统规则，包括但不限于战锤、FU、COC 等（我并未了解太多，就不过多赘述）。
世界包：即你跑团所用的模组书，比如凡达林的失落矿坑、风暴君王之雷霆或拥王者等。你可以使用别人准备好的世界包，也可以自己创建。
mod：如果你玩过单机游戏，那么应该知道 mod 是什么。简单来说，mod 是非官方（也可能是官方233）给游戏提供的额外插件，包括但不限于扩展游戏玩法、优化玩家操作和新增额外资源等。比如上述的FVTT 汉化就属于此范畴，mod 是由社区中的玩家制作并分享。
## 关于世界包
如今，大部分官方世界包采用冒险mod的形式发布，本质是一个合集包，你在启用之后可以直接将此合集包的内容导入你的世界中。

# 推荐：FLC 浏览器
考虑到不同 PL 或 DM 可能因为浏览器，导致 FVTT 出现问题，所以推荐使用 FLC 浏览器。
🔗 书签: 
FLC 是一款快速简洁的应用程序，允许用户管理和加入 FVTT 服务器。它具有以下特点：
- 快速、精简
没有臃肿的浏览器插件，节省了宝贵的资源。整个应用只有 5MB，比谷歌 Chrome 节省 60% 的内存。
- 安全、开源
所有数据均存储在本地。浏览器本身不会收集任何分析和统计信息。源代码可在 GitHub 上获取。
- 高兼容性
本地服务器、IP、VPN、http 和 https 链接以及官方 Foundry VTT 托管提供商均可使用。
- 无头服务器启动器
NodeJS 服务器是运行 Foundry VTT 服务器的一种高效方式。它所需的资源比独立的基于 Electron 的客户端要少得多。（注：无头服务器是指没有图形界面，也就是不需要在服务器上开着一个完整的客户端）
注意：FLC 是一个非官方的、采用 MIT 许可证的开源项目 ，与 Foundry Virtual Tabletop 和 Foundry Gaming, LLC 没有任何关联，请不要向 Foundry 的工作人员寻求帮助支持。
