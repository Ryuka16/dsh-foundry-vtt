## 一 · 根因与解法（一句话）

| 现象 | 根因 | 解法 |
|---|---|---|
| 行为脚本里 `region.getFlag("world","lhDC")` 返回 `undefined`（只有第一个 flag 读到了） | `setFlag` 是异步写入，而 Region 建好时行为已被复制进去并可能立刻触发 ⇒ **读 flag 与写 flag 存在时序竞态** | **不要把参数存 flag 再读——直接内联进脚本字符串** |

**做法**：宏里用占位符拼装脚本，把运行时算出的值（如施法 DC、魅力调整值）**焊死成字面量**进脚本：

```js
const 挂模板 = '... value: "turn=end, saveAbility=@S@, saveDC=@DC@, damageRoll=@D@ ..." ...';
const 挂 = JSON.stringify(挂模板)
  .split("@N@").join(名).split("@DC@").join(DC)      // ← DC 在这里变成数字字面量
  .split("@D@").join("10d8").split("@T@").join("fire")
  .split("@S@").join("dex").split("@R@").join(10);   // ⚠ 数字不要加引号
```
> ⚠ **踩坑**：`rounds` 一度被拼成字符串 `"10"` ⇒ 已修为 `.join(10)`（数字）。
> 判据：`duration.rounds` 是 NumberField，字符串会被 dnd5e 拒绝。

### 为什么飞蝇斗篷不走 Region
**实测**：`RegionDocument` 的字段只有 `name / shapes / behaviors / visibility / color / elevation / locked / flags`
—— **没有 attach / token / follow 任何一个** ⇒ **Region 无法跟随 token**。
而飞蝇斗篷是「从你四周散发 5 尺」的**跟随光环** ⇒ 改用已装的 `auraeffects` 1.5.2。

**Aura Effects 的权威结构**（照抄包内范本 血疟长生军 `your-dm-toolkit.your-actors / aDsNZgRvKdZykbk7` 的 `hydarnesAura0001`）：
```
type: "auraeffects.aura"  ｜ transfer: true ｜ showRadius / canStack 在顶层
system 键（16 个）：applyToSelf · bestFormula · collisionTypes · color · combatOnly · disableOnHidden
                · disposition · distanceFormula · evaluatePreApply · opacity · overrideName
                · script · showRadius · canStack · stashedChanges · stashedStatuses
```

### 飞蝇斗篷原错误效果的处理（**不删，只停用**）
原效果 `FYCEsIKeLjkqRZv6`「魔能祈唤:飞蝇斗篷」把 OverTime 挂在了**施法者自己**身上
（`damageRoll=max(@abilities.cha.mod,0)` 毒伤）⇒ 施法者会**自伤**，而区域内敌人**不受伤害**。
⇒ 该效果已置 **`disabled: true`**（数据保留、可回滚），毒伤改由宏创建的 Aura 效果承担（`applyToSelf:false` 保证不自伤）。

## 四 · 技术资产（下一个 AI 直接用）

```js
// ① 模板形状 → Region polygon
const obj = 模.object; if (!obj.shape) obj._refreshShape();
const s = obj.shape;
const pts = (s.points || s.toPolygon().points).map((pt, i) => i % 2 ? pt + 模.y : pt + 模.x);
//   实测：circle 20ft ⇒ s.points 为 falsy，走 toPolygon() ⇒ 45 点 ⇒ 90 个坐标

// ② 建 Region（3 行为）
await canvas.scene.createEmbeddedDocuments("Region", [{
  name: 名,
  shapes: [{ hole: false, type: "polygon", points: pts }],
  behaviors: [
    { name: "进场", type: "executeScript", system: { events: ["tokenEnter", "tokenMoveIn"], source: 挂 } },
    { name: "回合", type: "executeScript", system: { events: ["tokenTurnStart"], source: 挂 } },
    { name: "离场", type: "executeScript", system: { events: ["tokenExit", "tokenMoveOut"], source: 删 } }
  ],
  visibility: 0
}]);

// ③ 行为脚本上下文（Foundry 源码 ExecuteScriptRegionBehaviorType）
//    变量 = scene / region / behavior / event；支持 async/await；this = globalThis
//    字段是 system.source（★ 不是 system.script —— 踩过这个坑，曾误判「区域行为都是空壳」）

// ④ 挂/删效果的唯一正确 API
await MidiQOL.socket().executeAsGM("createEffects", { actorUuid: a.uuid, effects: ef });
const e = t.actor.appliedEffects.find(x => x.name === N); if (e) await e.delete();
```

**四条纪律**：
1. **参数内联，不要存 Region flag 再读**（时序竞态，读不到）。
2. **进场必须按名字去重** —— `tokenEnter` 与 `tokenMoveIn` 会**同时触发**（实测挂出 2 条同名效果）。
3. `rounds` / `seconds` 拼装时**不要加引号**（NumberField）。
4. **改行为脚本不要用 `behavior.update`** —— 实测改完 behavior **不再触发**；要改就整段重建 Region。
