## 二、匹配：为什么必须用 identifier，不能用名字

### ★ 反面案例（真实踩到）
本包**护盾术**（`ident: "shield"`）按名字搜 `"Shield"` ⇒ 命中 **`CPRMonsterFeatures` 里的 `"Shield"`**，其 `ident = "shieldGuardianShield"`（**盾牌守卫的盾**，完全另一个东西）。
**⇒ 按名字匹配会静默配错件，且不报错。**

### 正确做法
**用 `flags["chris-premades"].info.identifier` 精确匹配。**
本包 493 件 → 匹配官方 **463 件（93.9%）**。

### 后缀修正规则（再捞回 22 件）
```js
const fix = (id) => {
  if (idx[id]) return id;
  const noSup = id.replace(/SuperiorTechnique$/i, "");   // maneuversRiposteSuperiorTechnique → maneuversRiposte
  if (idx[noSup]) return noSup;
  if (id === "reduce" && idx["enlargeReduce"]) return "enlargeReduce";
  return null;
};
```
命中：12 个「战技（卓越技巧）」+ 卓越骰 + 变巨/缩小术。

## 三、替换规则（用什么 / 保留什么）

| 用 CPR 官方的 | 保留本包的 |
|---|---|
| `system.activities`（**自动化核心**） | `name`（中文名） |
| `flags["chris-premades"]`（宏绑定/版本号） | `system.description.value`（中文描述） |
| `flags["midi-qol"]`（`itemCondition` 等触发条件） | `effects`（**见下方反常识点**） |
| `flags["midiProperties"]` / `flags["dnd5e"]` | `img` 等元数据 |

### ★★ 反常识点：官方效果反而更差
官方**护盾术**的效果是：
```json
{"name":"Shield","changes":[{"key":"system.attributes.ac.bonus","mode":2,"value":"5"}],
 "duration":{"rounds":1,"seconds":null}}
```
⇒ `seconds: null` ⇒ **无战斗时算不出剩余时长**（`ActiveEffect#_prepareDuration`：`if (d.rounds || d.turns) { const cbt = game.combat; if (!cbt) return {type:"turns", _combatTime: undefined} }`）。
本包的版本已修成 `{rounds:1, seconds:6}` ⇒ **更完整**。
**⇒ 所以效果不替换，只同步活动 + flags。**

### 5.1 活动名：1066 个改为 `中文 英文原名`


**规则**：
1. 有冒号 `英文前缀: 后缀` ⇒ `物品中文名：后缀中文 英文原名`
2. 无冒号 ⇒ 查通用词典 ⇒ `词典中文 英文原名`；词典没有 ⇒ `物品中文名 英文原名`
3. 原本已是中文的（本包自建活动）⇒ 不动
4. 活动名是 `undefined`（官方部分活动）⇒ 不动，卡面按 type 显示本地化名（「效用」）

**最终统计**：`bilingual 1066 ｜ pureEng 0 ｜ pureCn 3087 ｜ total 4153` ⇒ **纯英文 0 个**。

**★ 安全性依据**：CPR 宏靠 `activityIdentifiers`（`{identifier: activityId}` 映射）与 `hiddenActivities`（存 identifier）定位活动，**不读 `activity.name`** ⇒ 改名 100% 安全。

## 六、★ 踩坑速查（三条，全部实测）

### 6.1 `CompendiumCollection#getIndex()` **不索引 flags**
```js
const idx = await pack.getIndex();
idx.contents[0].flags  // ⇒ undefined（hasFlags: false）
```
⇒ 用 index 统计「有多少件挂 CPR」会**恒得 0**（我第一次就得出「classpack 里 CPR 件数 = 0」这个错误结论）。
**⇒ 要读 flags 必须 `getDocuments()`。**

### 6.2 compendium 上 `effects: [...]` 是**追加**，不是替换
```js
await pack.documentClass.updateDocuments([{ _id, effects: [新效果] }], {pack});
// ⇒ 读回是【两条】：原有那条 + 新的那条（_id 不同）
```
⇒ 想**替换/删除 effects**，只有一条路：**重建文档**
```js
const o = doc.toObject();
o.effects = 目标效果数组;
await pack.documentClass.create(o, { pack, keepId: true });   // 实测成功
```
（本次效果名汉化即用此法：39 件全部重建，活动完整无损。）

### 6.3 `game.packs.get(短名)` 返回 undefined
建索引时若存的是 `p.collection.split(".").pop()`（如 `"CPRSpells"`），取用时必须补全：
```js
game.packs.get("chris-premades." + 短名)   // ✅
game.packs.get(短名)                        // ❌ undefined → "Cannot read properties of undefined (reading 'getDocument')"
```

### 6.4 遍历 7 包 `getDocuments()` 会 408
单次 execute_js（约 35 秒）里遍历 7 个包约 4000+ 文档 ⇒ relay HTTP 408。
**⇒ 一次只处理 1~2 个包；408 后用极轻脚本（`return "活"`）先探通道。**
