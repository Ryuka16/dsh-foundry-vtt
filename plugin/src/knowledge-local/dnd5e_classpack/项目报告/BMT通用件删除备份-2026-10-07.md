# dnd5e_classpack · BMT「任意型」通用件删除备份（2026-10-07）

## 为什么删

包 `dnd5e_classpack.itempack` 里有 **18 件 BMT（万象无常书）「任意型」通用件**，类型是 `loot` / 子型 `gear`。
它们是**空壳模板**，不是可用物品：

| 对比项 | 18 件通用件（loot） | 160 件具体变体（weapon/equipment） |
|---|---|---|
| 类型 | `loot`（**不能装备、不进武器栏、不参与 AC、挂不上活动**） | `weapon` / `equipment` / `consumable` |
| `attunement` | ❌ 丢失（空串） | ✅ `required` |
| `weight` | ❌ **0** | ✅ 正确（2 / 45 / 65 / 40 / 0.05 …） |
| `properties` | ❌ 只有 `mgc` | ✅ 完整（`amm,mgc,two,hvy`、`stealthDisadvantage` …） |
| `uses` | ❌ 无 | ✅ 有（王座之旨 5、机关械甲 4、幽影锻甲 3、射星弩 3、无重力 5） |
| `activities` | ❌ 0 | ✅ 1~6 个 |
| `description` | ✅ 完整 | ✅ 完整（已复制） |
| `effects` | 仅「莹月弓」3 条 | ✅ 莹月短弓 / 莹月长弓 **各已有那 3 条** |

**⇒ 通用件的全部内容都已在变体上，且变体字段更完整。删除 = 清理重复空壳，可 100% 重建。**

用户 2026-10-07 明确选择：「**直接删掉原件，只留具体件**」。

## 恢复方法（若日后需要重建）

原书清单写在每件通用件描述末尾的 `Base items.` 段落，可先从任一变体的描述取回（160 件变体的描述均含该段）。
或从官方/本包基础物品复制数据：`type` 用 `weapon` (martialM/martialR/simpleM/simpleR) / `equipment` (light/medium/heavy) / `consumable` (ammo)，
字段照抄同组变体（`attunement:"required"`、`rarity`、`properties` 含 `mgc`、`weight`、`uses`）。
描述全文可由同组任一现存的 160 件变体取回。

> 备份亦留在世界内存 `game.__18件备份`（18 件完整 toObject，56,906 字符）；**F5 刷新后失效**，故以本文件为准。
