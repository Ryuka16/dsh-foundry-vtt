## 三 · ★★★ 本轮学到的四条新机制（全部实测）

### 1. `mode 1 = MULTIPLY`（乘法）—— 之前的 mode 语义表漏了这一档

**官方权威写法**（`dnd5e.spells` 加速术 Haste / `dnd5e.equipment24` 速度之靴 Boots of Speed）：
```js
system.attributes.movement.walk  | mode 1 | "2"
system.attributes.movement.fly   | mode 1 | "2"
system.attributes.movement.climb | mode 1 | "2"
system.attributes.movement.swim  | mode 1 | "2"
system.attributes.movement.burrow| mode 1 | "2"
```

**实测对照**（桩 walk=30, fly=0）：

| 写法 | 结果 |
|---|---|
| `fly = +@attributes.movement.walk`（m2，跨字段） | **fly=30** ✓ 有效 |
| `fly = 2*@attributes.movement.walk`（m2，跨字段） | **fly=60** ✓ 有效 |
| **`walk = @attributes.movement.walk`（m2，自引用）** | **0** ❌ **必归零** |
| `movement.all` m2 `+30` | 30（**无效**） |
| `walk` m1 `"2"`（官方写法） | **60** ✓ |
| `walk` m5 `"60"` / m4 `"60"` | 60 ✓（但硬编码） |

⇒ **纪律**：**移速字段不能自引用**；「×(倍率)」用 **m1**；跨字段引用（fly←walk）是安全的。

### 2. `traits.toolProf` **不存在** —— 工具熟练要用 `system.tools.<id>.value`

**实测**：`CONFIG.Actor.dataModels.character.schema.fields.traits.fields` 的真实子字段 =
```
size, di, dr, dv, dm, ci, languages, weaponProf, armorProf
```
**没有 toolProf**。

**写 `system.traits.toolProf.value`（m2 "tinker"）的后果**：把字符串**拆成 7 个单字符**塞进 Set ⇒ `["t","i","n","k","e","r"]` ❌

**正确写法**：`system.tools.tinker.value` **mode 5 = "1"** ⇒ 实测 `actor.system.tools.tinker.value === 1` ✓
（工具 id 全集见 `CONFIG.DND5E.tools`，44 项，含 `thief` / `tinker`）

### 3. `bonuses.*` 存「原样字符串」是**正常**的，求值发生在掷骰时

`system.bonuses.mwak.attack` 写入 `+@abilities.cha.mod` 后，读回**仍是字符串**（`1d4[fire]` 也一样）——
> 不要据此判定「公式坏了」。**验证方法**：用 `actor.getRollData()` 实算一次。

**实测**（神圣武器）：
```
chaMod = 2
存的值 = "+@abilities.cha.mod"
new Roll("0" + 存的值, actor.getRollData()).evaluateSync().total  →  2  ✓
空白对照（加假键 system.attack.bonus）= 值纹丝不动 ✓
```
⇒ **dnd5e 把 `bonuses.*` 拼进攻击公式，`@` 在掷骰那一刻才替换。**

**副产品**：`system.bonuses.weapon.attack` **同时影响 mwak 与 rwak**（是通用武器攻击加值）。

### 4. 超魔法消耗术法点 —— identifier 写法

`consumption.targets = [{ type:"itemUses", value:"N", target:"sorcery-points" }]`
（与既有的「引导神力 23 件 → `channel-divinity`」同一机制：**target 写 identifier 而非 uuid**）

## 五 · 判为「不是缺口」（逐条理由）

- **猎人之衣** `armor{value:12,dex:null}`：皮甲基础 11 + 描述「AC+1」= **12，数值正确**（只是没单列 magicalBonus 标记）⇒ 不动。
- **多才多艺 (半精灵)**：已有 `Trait` advancement `{choices:[{count:2, pool:["skills:*"]}]}` ⇒ 拖入即弹选技能 ✓。
- **斯翠海文学徒 / 战斗学徒 / 红袍入道**：均有 `ItemChoice` advancement ⇒ 选择由系统处理 ✓。
- **熟习 / 火巨灵之遗(属性)**：走自制「自选专长」体系（`flags["your-feats"].options`）✓。
- **龟壳防御**：效果其实很全（`ac.bonus` m2 4 + 五个移速归零 + 力/体豁免优势 + 敏豁免劣势）⇒ 只缺「不能反应」，**包内 7 包 0 个「禁用反应」先例** ⇒ 无字段。
- **换位诈术 / 领导风范 / 快手投掷**：卓越骰消耗与 `roll.formula = @scale.battle-master.superiority-die` **都在** ✓。
- **122 条「工具熟练」可疑件**：实为工具物品自己的**规则说明文字**（「拥有某项工匠工具熟练项的角色……可以加熟练加值」），**不是给熟练** ⇒ 判据太宽，符合「命中数量级异常先怀疑判据」⇒ **不批量改**。
- **大德鲁伊** `class-abilityphb/pU8Ta1hNQbbit6o`：活动上有 `spellSlots:2×-1`（返还 2 环法术位），与描述（无限荒野变形 + 忽略成分）**不符** ⇒ 疑似错挂，**按用户「不要删」原则保留，记入待办**。
