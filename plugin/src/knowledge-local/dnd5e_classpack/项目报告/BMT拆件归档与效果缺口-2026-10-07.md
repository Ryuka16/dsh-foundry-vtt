## 六、技术教训（★ 本轮新增，全部实测）

### 6.1 ★★★ 参考库模板的 DC 写法是错的 —— `calculation` 必须是**空串**，不是 `"flat"`
`foundry_reference{topic:"save-activity"}` 给的是 `"dc": {"calculation": "flat", "formula": "11"}`。
**实测：写 `"flat"` ⇒ 运行时 `dc.value` 落到默认 10，formula 被完全忽略**（蕈孢 6 件首轮全部算出 DC 10）。
**包内全部 9 个正确 save 活动用的都是 `"calculation": ""`**：

```
麻绳（50尺）      calc=""  formula="17" ▸ 运行时 17 ✓
巨人屠杀者刺剑    calc=""  formula="15" ▸ 运行时 15 ✓
炸药(一管)        calc=""  formula="12" ▸ 运行时 12 ✓
反制善恶          calc="spellcasting" formula="" ▸ 运行时 8 ✓
```

⇒ **规矩：固定 DC 写 `{calculation:"", formula:"15"}`；跟随施法 DC 写 `{calculation:"spellcasting", formula:""}`。**
⇒ **通用教训：参考库模板与包内实测冲突时，以实测为准。**

### 6.2 `ActivityCollection` 不是普通对象 —— 用 `.contents`，不是 `Object.values`
`it.system.activities` 的构造器名是 **`ActivityCollection`**，`Object.values(...)` 恒为 `[]`（曾导致 `Cannot read properties of undefined (reading 'name')`）。
正确：`it.system.activities.contents[0]` 或 `Array.from(it.system.activities)` 或 `.get(key)`。

### 6.3 `statuses` / `traits.dr.value` 都是 **Set** —— `JSON.stringify` 恒为 `{}`
效果上读到 `"statuses":{}` 会误判成「写入失败」。正确：`Array.from(e.statuses)`。
（同类坑：`traits.dr.value`；此前已有记录，本轮再次踩到。）

### 6.4 ★ compendium 上用 `updateDocuments` 批量，比逐件 `update` 快两个数量级
| 操作 | 件数 | 耗时 |
|---|---|---|
| `pack.documentClass.updateDocuments(ups, {pack})` 归档 | **160** | **~1.0 秒** |
| 逐件 `d.update()`（旧经验） | 110 | **HTTP 408 超时** |

⇒ 归档、批量改字段**一律用 `updateDocuments`**；单次 160 件实测无压力。

### 6.5 变体名匹配的两个陷阱
1. **子串匹配会串味**：`indexOf("Scimitar of the Planes")` 先命中「**Double-Bladed** Scimitar of the Planes」⇒ 真正的「弯刀」版漏掉（首批 160 件里少 2 件的原因）。
   **正解**：`名称.replace(/\s*\(BMT\)\s*$/,"").endsWith(变体名)` + **变体名按长度降序** + **已用 `_id` 标记**。
2. **`slice` 位数算错**：`@item[X|BMT]` 去掉头 `@item[`（6 字符）和尾 `|BMT]`（**5 字符**）⇒ 应 `slice(6, -5)`。写成 `slice(6, -6)` 会截掉末位字符（靠 `indexOf` 子串容错掩盖，一换严格匹配就全崩）。

### 6.6 文档实体上 `d.folder` 不是 id
`ds.find(x => x.folder === "某个id")` 恒失败。**用 `x._source.folder`**。

### 6.7 遍历全部 `dnd5e.*` 官方包必 408
`for (const p of game.packs) if (id.includes("dnd5e.")) await p.getDocuments()` ⇒ HTTP 408。
**只取单个包** `game.packs.get("dnd5e.items")`（872 件）即可。若要查"某基础物品在哪个包"，用 **`pack.getIndex()`**（轻量索引）遍历 199 个 Item 包 —— 实测可跑完。

### 6.8 写入链正确顺序（照抄）
```js
const 活 = { _id:"sporesSporeAct01", type:"save", name:"剧毒孢子",
  activation:{condition:"",override:false,type:"bonus",value:null},
  consumption:{scaling:{allowed:false,max:""},spellSlot:false,targets:[{type:"itemUses",value:"1",target:"",scaling:{}}]},
  damage:{critical:{allow:false},onSave:"none",parts:[]},
  duration:{concentration:false,override:false,special:"",units:"inst",value:""},
  effects:[{_id:"sporesPoisAcid01", level:{}, onSave:false}],   // ★ 只是空壳
  range:{override:false,special:"",units:"self",value:""},
  save:{ability:["con"], dc:{calculation:"", formula:"15"}},   // ★ 空串，不是 flat
  target:{affects:{choice:false,count:"",special:"",type:"creature"},override:false,prompt:false,
          template:{contiguous:false,count:"",height:"",size:"10",stationary:false,type:"radius",units:"ft",width:""}},
  uses:{max:"",recovery:[],spent:0}, flags:{}, img:null };
const 效 = { _id:"sporesPoisAcid01", name:"剧毒孢子（中毒）", type:"base", transfer:false, disabled:false,
  statuses:["poisoned"], changes:[], description:"",
  duration:{startTime:null,seconds:6,combat:null,rounds:null,turns:1,startRound:null,startTurn:null},
  origin:null, tint:"#ffffff", flags:{}, sort:0 };
await pack.documentClass.updateDocuments(
  ids.map(id => ({_id:id, "system.activities":{[活._id]:活}, "effects":[效],
                  "system.uses":{max:"1",spent:0,recovery:[{period:"dawn",type:"recoverAll"}]}})),
  {pack:"dnd5e_classpack.itempack"});
```
⚠️ 所有 `_id` **必须恰好 16 位字母数字**（17 位会被 5.3.3 拒绝创建）。
⚠️ `activity.effects[].level` 一律写 `{}`（装备类无 level 字段，填值会**静默过滤掉效果**）。
