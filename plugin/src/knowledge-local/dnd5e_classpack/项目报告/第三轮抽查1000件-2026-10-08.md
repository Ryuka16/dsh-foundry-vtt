## 二 · ★★★ 本轮最重要的实测

### 2.1 `rounds` 无 `seconds` = 卡面不显示时长（已修 94 条）
```
写入 {rounds:10}      → 运行时 type="turns"，无 duration、无 label   ← 无战斗时算不出
写入 {seconds:60}     → type="seconds"，duration=60，label="60 秒"
写入 {rounds:10,seconds:60} → type="seconds"  ← 优先用 seconds
```
⇒ **补 `seconds = rounds × 6`（1 轮 = 6 秒）是纯补全、不改语义**：有战斗时 dnd5e 优先用 seconds，两者等价。

### 2.2 具名魔法武器缺 `magicalBonus`（67 件，官方对照 13/14 命中）
```
本包斩首巨剑：magicalBonus=undefined  → 安装+同调后 toHit="+6"（只有力3+熟练3）
官方斩首巨剑：magicalBonus="3"
实测对照（同调+装备）：
  mb=3  → toHit=+9   (3力 + 3熟练 + 3魔法)
  mb=空 → toHit=+6
  恢复  → toHit=+9
```
⇒ **判据**：描述含「攻击（检定）和伤害（掷骰）上获得 +N 加值」∧ `system.magicalBonus` 为空 ∧ 无 `bonuses.*attack` 效果
⇒ **排除项**（官方也是空，不修）：王者权杖、武者万能钥匙、奇迹牌组、恶魔护甲
⇒ **⚠️ 必须「同调 + 装备」才生效** —— 第一次实测漏了同调，toHit 纹丝不动，误判成「修复无效」

### 2.3 精金护甲（10 件）—— 字段来自 midi 官方注释
```
flags.midi-qol.grants.noCritical.all
```
**出处**：`模块文档\midi-qol\Changelog.md:6395` 原文 ——
> `Cause attack on the target to not be critical. (Think adamantine armor)`

⇒ 包内 8 件精金 + 官方 `dnd5e.items` 的 4 件**都没做**（官方只给了 2024 版 `system.properties:["ada"]` 属性）
⇒ 效果需 `transfer:true` + 装备

### 2.4 悬空 `@scale` 引用（精魂之盾）
包里唯一引用 `@scale.ancestral-guardian.spirit-shield` 的件，**全库没有任何 ScaleValue 定义它** ⇒ 降伤从来没算出过数字。
```
改前：bonus: "@scale.ancestral-guardian.spirit-shield"
改后：custom: {enabled:true, formula:"(min(4, 2 + floor((@classes.barbarian.levels - 6) / 4)))d6"}
实测：L6→2d6  L10→3d6  L14→4d6  L20→4d6   （与描述三档逐字吻合）
```
⚠️ **公式写法**：`min(...)d6` 会被 Roll 拒（`Expected "[" ... but "d" found`），**必须写成 `(...)d6` 括号包住整个表达式**（与包内先例 `(ceil(@classes.fighter.levels/17)*2)d6` 同构）

## 六 · 踩坑

1. **`toObject()` 后没有 `.id`，只有 `._id`** —— 写成 `{_id: o.id}` 会报 `You must provide an _id for every object in the update data Array.`
2. **合并语义下清空字段必须显式给空值** —— 只给 `{units:"inst"}` 时旧的 `value:"8"` 会保留
3. **magic item 测 transfer/magicalBonus 必须 `equipped=true` + `attunement="attuned"`** —— 本轮又栽一次
4. **`(...)d6` vs `min(...)d6`** —— 表达式必须整体被括号包住
5. **判据命中数超过个位数先怀疑判据** —— 本轮「治疗活动时长非立即」10 条全是 temphp 误报
