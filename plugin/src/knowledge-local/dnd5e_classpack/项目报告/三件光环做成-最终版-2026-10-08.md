## 1 · 为什么不能照原样（病根）

三件的 `flags.dae.macro.command` 完全相同，都调**未安装**的 ActiveAuras：
```js
if (args[0].macroPass === "preActiveEffects" || args[0].tag === "OnUse") {
  return await game.modules.get("ActiveAuras").api.AAHelpers.applyTemplate(args);
}
```
且 `onUseMacroName` **为空** ⇒ **宏根本不会被触发**，即使触发也因模块不存在而失败 = **双重失效（空转无害）**。

**三条替代路径全部实测排除**：
| 路径 | 结果 |
|---|---|
| ActiveAuras | **未装**（全库 214 模块里带 aura 的只有 `auraeffects` 1.5.2 active） |
| Aura Effects 的 `applyTemplate` | **不存在**（`api` 只有 `migrateActiveAuras`） |
| GPS | `game.gps` 166 个函数里 **无** `incendiaryCloud` / `darkStar` / `cloakOfFlies` |

## 2 · 关卡一：Region 方案（焚云术 / 暗黑星辰）

### 2.1 ★ 根因：`region.getFlag` 在行为脚本里读到 `undefined`
第一版把参数存进 Region 的 flag、脚本里 `region.getFlag("world","lhDC")` 读 ⇒ **读回 `undefined`**
（只有**第一个** `setFlag` 的 `lhName` 读到了）。脚本外读同一批 flag **全部正常**。
⇒ 判定为**写读时序竞态**。

**解法：参数内联进脚本字符串**（宏里拼装，把运行时算出的值焊成字面量）：
```js
const 挂模板 = '... value: "turn=end, saveAbility=@S@, saveDC=@DC@, damageRoll=@D@ ..." ...';
const 挂 = JSON.stringify(挂模板)
  .split("@N@").join(名).split("@DC@").join(DC)
  .split("@D@").join("10d8").split("@T@").join("fire")
  .split("@S@").join("dex").split("@R@").join(10);   // ⚠ 数字不要加引号
```
**修后实测**（建真模板 → 建 Region → `foundry_move_token` 移木桩进出 → 读 `token.actor.effects`）：
```
效果数: 2                      ← tokenEnter + tokenMoveIn 各一次（★ 必须按名字去重）
changes: ["turn=end, saveAbility=dex, saveDC=16, saveMagic=true,
           damageRoll=10d8, damageType=fire, saveDamage=halfdamage, allowIncapacitated=true"]
duration: { type:"turns", rounds:10 }     ← rounds 是数字
```

### 2.2 可复用代码
```js
// ① 模板形状 → Region polygon（抄自 region-attacher）
const obj = 模.object; if (!obj.shape) obj._refreshShape();
const s = obj.shape;
const pts = (s.points || s.toPolygon().points).map((pt, i) => i % 2 ? pt + 模.y : pt + 模.x);
//   实测 circle 20ft ⇒ s.points 为 falsy，走 toPolygon() ⇒ 45 点 ⇒ 90 坐标

// ② 建 Region + 3 个行为
await canvas.scene.createEmbeddedDocuments("Region", [{
  name: 名,
  shapes: [{ hole:false, type:"polygon", points: pts }],
  behaviors: [
    { name:"进场", type:"executeScript", system:{ events:["tokenEnter","tokenMoveIn"], source: 挂 } },
    { name:"回合", type:"executeScript", system:{ events:["tokenTurnStart"], source: 挂 } },
    { name:"离场", type:"executeScript", system:{ events:["tokenExit","tokenMoveOut"], source: 删 } }
  ],
  visibility: 0
}]);

// ③ 行为脚本上下文（Foundry 源码 ExecuteScriptRegionBehaviorType）
//    变量 = scene / region / behavior / event；支持 async/await；this = globalThis
//    字段是 system.source（★ 不是 system.script）

// ④ 挂/删效果
await MidiQOL.socket().executeAsGM("createEffects", { actorUuid: a.uuid, effects: ef });
const e = t.actor.appliedEffects.find(x => x.name === N); if (e) await e.delete();
```

### 2.3 三条纪律
1. **参数内联，不要存 Region flag 再读**。
2. **进场必须按名字去重** —— `tokenEnter` 与 `tokenMoveIn` **会同时触发**（实测挂出 2 条同名效果）。
3. **改行为脚本不要用 `behavior.update`** —— 实测改完 behavior **不再触发**；要改就整段重建 Region。

## 3 · 关卡二：Aura Effects 方案（飞蝇斗篷）

**为什么不用 Region**：实测 `RegionDocument` 的字段只有 `name / shapes / behaviors / visibility / color / elevation / locked / flags`
—— **没有 attach / token / follow** ⇒ **Region 无法跟随 token**；而飞蝇斗篷是「从你四周散发 5 尺」的跟随光环。

### 3.1 ★★★ 根因（这一条最值钱）

Aura Effects 模块源码（`modules/auraeffects/scripts/queries.mjs`，4624 字节）的 `applyAuraEffects`：
```js
const effectData = foundry.utils.mergeObject(effect.toObject(), {
  name: effect.system.overrideName?.trim() || effect.name,
  origin: uuid,
  type: effect.getFlag("auraeffects", "originalType") ?? "base",
  transfer: false,
  "flags.auraeffects.fromAura": true
});
if (!effect.system.canStack) {
  const bestValue = new Roll(effect.system.bestFormula.trim() || "0", effect.parent?.getRollData?.()).evaluateSync().total;
  ...
}
```
**⇒ `overrideName` 与 `bestFormula` 必须是「字符串」！**
传**布尔** `false` 时 dnd5e 的 StringField 会把它存成**字符串 `"false"`** ⇒
- `"false".trim()` ⇒ `"false"` ⇒ **`new Roll("false")` 解析失败抛错** ⇒ 整个挂载流程崩掉
- 子效果名变成 `"false"`

**⇒ 正确写法：两者都给空字符串 `""`**（源码靠 `.trim() || 默认值` 兜底）。
> ⚠ 包内范本（血疟长生军 `hydarnesAura0001`）里 `bestFormula: "false"` **同样是错的**——它只是没被触发过。

### 3.2 修后实测（**光环真的工作了**）
```
魅力调整: 2
施法者光环: ["飞蝇斗篷灵光 Cloak of Flies[auraeffects.aura] bf=\"\""]
木桩效果:   [{ 名:"飞蝇斗篷灵光 Cloak of Flies", type:"base", fromAura:true,
              changes:["turn=start, label=飞蝇斗篷灵光 Cloak of Flies,
                        damageRoll=2, damageType=poison, saveDamage=nodamage, ..."] }]
木桩applied: ["飞蝇斗篷灵光 Cloak of Flies"]
```
⇒ **两 token 相距 50px = 2.5 尺，光环把子效果挂上了木桩**，`damageRoll=2` 就是内联的魅力调整值。
⇒ `createEmbeddedDocuments` 与 `MidiOL.socket().executeAsGM("createEffects")` **两条路径都验证过**。

### 3.3 Aura Effects 的权威结构（16 个 system 键，照抄可用）
```
type: "auraeffects.aura"  ｜ transfer: true（创建时会被吃成 false，用 update 可改回）
system: { applyToSelf, bestFormula:"", collisionTypes:["move"], color, combatOnly:false,
          disableOnHidden:false, disposition:-1, distance:5, distanceFormula:"5",
          evaluatePreApply:true, opacity:0.3, overrideName:"", script:"", showRadius:true, canStack:false }
```
**判据源码**（`helpers.mjs` 14749 字节）：
```js
// 半径
const adjustedRadius = sourceToken.parent.grid.size * ((radius / sourceToken.parent.grid.distance) + sourceToken.width / 2);
// 阵营：disposition -1=敌对（两边相乘=-1）、1=友方（相等）、0=全部
if (disposition < 0) return (source.disposition * t.disposition) === -1;
if (disposition > 0) return (source.disposition === t.disposition);

// 脚本闸：空脚本直接放行
if (!script?.trim()?.length) return true;
```
**触发时机**：`addRemoveEffect` 只在 **`createActiveEffect` / `deleteActiveEffect` hook** 上跑
⇒ **改效果字段不会重跑**；要重跑就**删掉重建**。

### 3.4 飞蝇斗篷原错误效果的处理（**不删，只停用**）
原效果 `FYCEsIKeLjkqRZv6` 把 OverTime 挂在**施法者自己**身上（`damageRoll=max(@abilities.cha.mod,0)` 毒伤）
⇒ 施法者**自伤**、区域内敌人**不受伤害**。
⇒ 已置 **`disabled: true`**（数据保留、可回滚），毒伤改由宏创建的 Aura 效果承担（`applyToSelf:false` 保证不自伤）。
