## 六 · relay 通信速查

```
单次 execute_js 超时约 35 秒（HTTP 408）
```
**应对**：
```js
// ① 长任务：点火不 await，结果写全局变量
game.__结果 = null;
(async () => { ...; game.__结果 = xxx; })();
return "已点火";
// 稍后：return game.__结果;

// ② 408 之后先读回确认，绝不重跑
// ③ 确认通道活着：return "活";
// ④ 一次只处理 1~2 个包（最多 4 个小包）
// ⑤ 大包用 getIndex() 建索引 + 分批 getDocument（每批 25~30）
```

**黑名单规避**：
```js
game.settings["settings"]     // ✅ 避开 game.settings.set
const 变量 = 0; 变量++;        // ✅ const 不能自增，用 let
// ✅ 脚本标识符不能用标点
```

**★ 返回形状（必记）**：
```js
// 成功：{ success:true, result: <脚本返回值> }
// 失败：{ error:true, message:"..." }   ← 根本没有 result 字段
// 先判 error 再取 result；result 可能是字符串，判类型再 parse
// 推荐：脚本末尾统一 return JSON.stringify({...})
```
