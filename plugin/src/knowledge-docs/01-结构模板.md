3. 真正的中毒/流血效果挂【物品级 effects 数组】（ActiveEffect 结构），不是 activity.effects！

**层级铁律（实测翻车根因）**：save activity 的 effects 是空壳 `[{_id, level:{}, onSave:false}]`——往里面塞 name/statuses/duration 会被 5.3.3 清洗成空（statuses 全丢）。挂状态/OverTime 必须写在物品顶层 effects 数组。

要点：`dc.formula` 写固定数字字符串（"11"）；`onSave:false` = 豁免失败才生效；`dc.calculation:"flat"` 实测落库保留；另有资料记载 flat 会被丢回默认 10——DC 不生效时改 `calculation:""` + `formula:"16"` 再验。

## ActiveEffect（effect）

放进物品/特性顶层 effects 数组（不是 activity 的 effects）。或直接用 add_effect{uuid, statusId:"poisoned"} 挂现成状态。**img 不是 icon（写 icon 会被 5.3.3 丢弃）**。实测完整版（锯肉刀流血 OverTime）：

```json
{
  "_id": "bleedOT000000001",
  "name": "流血 Bleeding",
  "img": "icons/skills/wounds/blood-drip-droplet-red.webp",
  "origin": null,
  "type": "base",
  "system": {},
  "changes": [
    { "key": "flags.midi-qol.OverTime", "mode": 0, "priority": 20,
      "value": "turn=start,damageRoll=1d4,damageType=slashing,saveDC=11,saveAbility=con,saveCount=1-,label=流血" }
  ],
  "disabled": false,
  "duration": { "startTime": null, "seconds": 60, "combat": null, "rounds": null,
    "turns": null, "startRound": null, "startTurn": null },
  "description": "<p>伤口流血不止：每回合开始受到 1d4 挥砍伤害，可重复进行 DC 11 体质豁免，成功即止血。</p>",
  "tint": "#ffffff",
  "transfer": false,
  "statuses": [],
  "sort": 0,
```

要点：statuses 放状态 id（poisoned/prone 等）→ 挂现成状态（与 save activity 配合：豁免失败才触发）；changes 是附加自动化（flags.midi-qol.OverTime=持续伤害、flags.midi-qol.disadvantage.attack.all=攻击劣势，需 midi-qol）；mode 0=覆盖 2=加 5=减；duration.seconds=状态秒数（60=10 轮战斗）。完整「命中→豁免→失败中毒/流血」链路 = weapon 的 attack 活动 otherActivityId 指向 save 活动 + save 活动空壳 effects + 本模板。

## 特性物品（feat）与法术（spell）

- feat：`type:"feat"`，system 骨架 `{description:{value},source,uses{spent,max,recovery},type:{value:"monster",subtype:""},requirements:"",recharge:{value:null,formula:"1d6"},properties:[]}`。纯描述型特性没有自动判定逻辑，FVTT 只展示文本；要自动判定用武器 save 活动或 ActiveEffect。
- spell：`type:"spell"`，伤害骰同样走 damage.base；范围法术用 save 活动；`save.dc.calculation:"spellcasting"` = 用施法者法术 DC；升环加成 `damage.base.scaling{mode:"whole",number:1}` = 每环 +1d6。细节字段建议读一个现成法术核对。

## 常用状态 id（status-list）

poisoned 中毒 · paralyzed 麻痹 · prone 倒地 · stunned 震慑 · frightened 恐慌 · charmed 魅惑 · blinded 目盲 · deafened 耳聋 · invisible 隐形 · restrained 束缚 · grappled 擒抱 · unconscious 昏迷 · petrified 石化 · exhaustion 力竭 · flying 飞行 · incapacitated 失能 · dead 死亡 · disease 疾病 · cursed 诅咒 · bleeding 流血 · burning 燃烧。第三方模块另有 dazed/flanked/hasted/slowed/rage 等（list_status_effects 查全量）。
