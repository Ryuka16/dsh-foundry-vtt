# 01 · dnd5e 5.3.x 结构模板（内置知识）

> 来源：ThreeHats relay 通道实测 + dnd5e 5.3.3 实体导出交叉验证。版本敏感，5.2 及以下不适用。
> 使用：foundry_reference{topic:"weapon"} 等 20 主题是这些内容的速查版；本文件是完整版。

## 武器物品（weapon）

伤害骰铁律：只写 `system.damage.base{number,denomination,bonus,types}`；activities 的 `damage.parts` 必须留空数组 + `includeBase:true`。写 `parts[].formula` 会被 dnd5e 5.3.x 清洗成空（怪物没伤害）。

```json
{
  "name": "啃咬", "type": "weapon",
  "img": "icons/weapons/fangs/fangs-bite.webp",
  "system": {
    "source": { "rules": "2024", "book": "", "page": "", "custom": "" },
    "quantity": 1, "weight": { "value": 0, "units": "lb" },
    "price": { "value": 0, "denomination": "gp" },
    "attunement": "", "equipped": true, "rarity": "", "identified": true,
    "properties": [], "proficient": false,
    "type": { "value": "natural", "baseItem": "" },
    "range": { "value": null, "long": null, "units": "ft" },
    "uses": { "spent": 0, "max": null, "recovery": [] },
    "damage": { "base": { "number": 1, "denomination": 8, "bonus": "", "types": ["piercing"],
      "custom": { "enabled": false, "formula": "" },
      "scaling": { "mode": "", "number": null, "formula": "" } } },
    "activities": {
      "dnd5eactivity000": {
        "type": "attack", "name": "",
        "activation": { "type": "action", "value": 1, "condition": "" },

        "range": { "value": 5, "long": null, "units": "ft" },
        "target": { "template": { "type": null, "count": "", "contiguous": false, "units": "" },
```

## 豁免活动（save-activity）：命中后过豁免、失败中状态

三件套缺一不可：

1. **attack 活动设 `"otherActivityId": "dnd5eactivity100"`** 指向 save 活动（漏了 = 攻击不触发豁免）
2. save 活动本体：

```json
{
  "dnd5eactivity100": {
    "type": "save", "name": "",
    "activation": { "type": "", "value": null, "condition": "" },
    "duration": { "value": "", "units": "inst", "concentration": false },
    "range": { "value": null, "long": null, "units": "spec" },
    "target": { "template": { "type": null, "count": "", "contiguous": false, "units": "" },
      "affects": { "type": "creature", "count": 1, "special": "" } },
    "save": { "ability": ["con"], "dc": { "calculation": "flat", "formula": "11" },
      "scaling": { "mode": "none", "formula": "", "bonus": "" } },
    "damage": { "critical": { "bonus": "" }, "includeBase": false, "parts": [] },
    "effects": [ { "_id": "d23QTwP434lw72W2", "onSave": false } ],
    "consumption": { "scaling": { "allowed": false, "max": "" }, "targets": [] },
    "uses": { "spent": 0, "max": null, "recovery": [] },
    "properties": [], "_id": "dnd5eactivity100"
  }
}
```

3. 真正的中毒效果挂【物品级 effects 数组】（ActiveEffect 结构），不是 activity.effects！

**层级铁律（实测翻车根因）**：save activity 的 effects 是空壳 `{_id, onSave:false}`——往里面塞 name/statuses/duration 会被 5.3.3 清洗成空（statuses 全丢）。挂状态必须写在物品顶层 effects 数组。

要点：`dc.formula` 写固定数字字符串；`onSave:false` = 豁免失败才生效。`dc.calculation:"flat"` 实测落库保留；另有资料记载 flat 会被丢回默认 10——DC 不生效时改 `calculation:""` + `formula:"16"` 再验。

## ActiveEffect（effect）

放进物品/特性顶层 effects 数组（不是 activity 的 effects）。或直接用 add_effect{uuid, statusId:"poisoned"} 挂现成状态。

```json
{
  "name": "尸毒",
  "icon": "icons/magic/poison/dagger-poison-green.webp",
  "statuses": ["poisoned"],
  "duration": { "seconds": 3600, "rounds": null, "turns": null, "startTime": null, "startRound": null, "startTurn": null },
  "disabled": false, "transfer": false,
  "changes": [
    { "key": "flags.midi-qol.disadvantage.attack.all", "mode": 0, "value": "1", "priority": 20 }
  ],
  "flags": {}, "origin": null
}
```

要点：statuses 放状态 id（命中后目标被挂状态）；changes 是附加自动化（disadvantage.attack.all=攻击劣势，需 midi-qol）；mode 0=覆盖 2=加 5=减。完整「命中→豁免→失败中毒」链路 = weapon 的 attack + otherActivityId + save 活动 + 本模板。

```json
{
  "name": "僵尸", "type": "npc",
  "img": "systems/dnd5e/tokens/undead/Zombie.webp",
  "system": {
    "abilities": {
      "str": { "value": 13, "mod": 1 }, "dex": { "value": 6, "mod": -2 }, "con": { "value": 16, "mod": 3 },
      "int": { "value": 3, "mod": -4 }, "wis": { "value": 6, "mod": -2 }, "cha": { "value": 5, "mod": -3 }
    },
    "attributes": {
      "hp": { "value": 22, "max": 22, "formula": "3d8+9" },
      "ac": { "flat": 8, "formula": "" },
      "movement": { "walk": 20, "fly": 0, "swim": 0, "climb": 0, "burrow": 0, "units": "ft" },
      "senses": { "darkvision": 60, "units": "ft", "special": "" },
      "languages": { "value": "", "custom": "" },
      "details": { "type": { "value": "undead", "subtype": "" }, "alignment": "Neutral Evil",
        "cr": 0.25, "source": { "rules": "2014", "book": "MM", "page": "", "custom": "" } },
      "damage": { "immunities": ["poison"], "resistances": [], "vulnerabilities": [] },
      "conditionImmunities": ["poisoned"]
    }
  },
  "items": [], "effects": [],
  "prototypeToken": { "name": "僵尸", "width": 1, "height": 1, "displayBars": 40,
```

要点：元素名小写（"poison"/"fire"）；状态免疫用状态 id；伤害骰在物品 damage.base 不在 actor；特性是 feat 物品放 items。

## 特性物品（feat）与法术（spell）

- feat：`type:"feat"`，system 骨架 `{description:{value},source,uses{spent,max,recovery},type:{value:"monster",subtype:""},requirements:"",recharge:{value:null,formula:"1d6"},properties:[]}`。纯描述型特性没有自动判定逻辑，FVTT 只展示文本；要自动判定用武器 save 活动或 ActiveEffect。
- spell：`type:"spell"`，伤害骰同样走 damage.base；范围法术用 save 活动；`save.dc.calculation:"spellcasting"` = 用施法者法术 DC；升环加成 `damage.base.scaling{mode:"whole",number:1}` = 每环 +1d6。细节字段建议读一个现成法术核对。

## 常用状态 id（status-list）

poisoned 中毒 · paralyzed 麻痹 · prone 倒地 · stunned 震慑 · frightened 恐慌 · charmed 魅惑 · blinded 目盲 · deafened 耳聋 · invisible 隐形 · restrained 束缚 · grappled 擒抱 · unconscious 昏迷 · petrified 石化 · exhaustion 力竭 · flying 飞行 · incapacitated 失能 · dead 死亡 · disease 疾病 · cursed 诅咒 · bleeding 流血 · burning 燃烧。第三方模块另有 dazed/flanked/hasted/slowed/rage 等（list_status_effects 查全量）。
