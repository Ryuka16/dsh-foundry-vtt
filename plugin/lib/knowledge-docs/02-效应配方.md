# 02 · 效应配方（内置知识）

> 来源：用户 FVTT 技术资料库（data-dict v9.1 / 开工铁律 / midi 物品宏指南）提炼。midi-qol 版本 13.0.55 实测语境。
> 速查版：foundry_reference{topic:"bonuses|midi-over-time|midi-flags|item-macro|aura|dae|conditions|enchant|optional|trigger|overtime-activity"}。

## mode 常量表（change 键 / flags 值通用）

0=CUSTOM 自定义 · 1=MULTIPLY 乘 · 2=ADD 加 · 3=DOWNGRADE 降级 · 4=UPGRADE 升级 · 5=OVERRIDE 覆盖。优先级（DAE）：CUSTOM 0 < MULTIPLY 10 < ADD 20 < DOWNGRADE 30 < UPGRADE 40 < OVERRIDE 50。

## 加伤 / 减益（bonuses）

系统加伤（对所有攻击生效，如武器+1d4 火焰）：
```json
{ "key": "system.bonuses.mwak.damage", "mode": 2, "value": "1d4[fire]" }
```
武器键：mwak 近战武器 / rwak 远程武器 / msak 近战法术 / rsak 远程法术。value 格式 `骰[伤害类型]`。

midi-qol Optional 加值（可开关）：flags 下 `flags.midi-qol.optional.<标识>.damage.all` mode 0 value "1d4[fire]"，配 `flags.midi-qol.optional.<标识>.label` 和 `.force`。标识=英文数字。

## OverTime 持续伤害（midi-over-time）

键名：`flags.midi-qol.OverTime`（大写 O 大写 T），mode 0，value 逗号式：
`turn=start,damageRoll=1d4,damageType=piercing,saveDC=14,saveAbility=con,saveCount=1-,label=放血`
- turn=start|end（轮开始/结束）
- damageRoll 伤害骰 / damageType 类型
- saveDC+saveAbility+saveCount=1-（豁免：每轮过豁免减 1 次计数，归零结束。saveCount=1- 需 midi 13.0.37+；旧 saveRemove 已弃用）
- killAnim=true 可选击杀动画

行动版 OverTime（§23）：`flags.midi-qol.ActivityOverTime` value 指行动 identifier，每轮触发该行动。⚠ 键名大小写源文档自相矛盾且世界 0 实例，未坐实，用前必须实测。

## 常用 flags（midi-flags）

- 无视护甲/盾牌：`flags.midi-qol.ignoreArmor` mode 0 "true"（配 `flags.dae.specialDuration:["1Attack"]` 仅下次攻击生效）
- 暴击阈值：`flags.midi-qol.criticalThreshold` mode 0 "19"（19-20 暴击）
- 移速：`movement.walk` mode 1 "0.5"（减半）
- 命中爆炸（mark）：`flags.midi-qol.optional.<id>.onUseMacro` mode 0 "Name:ItemMacro"

## 物品宏三件套（item-macro）

写法 A（物品级，金标准）：
1. `flags.midi-qol.onUseMacroName` mode 0 `"[postActiveEffects]ItemMacro"`（方括号式宏名）
2. `flags.dae.macro` = `{name:"ItemMacro", type:"script", scope:"global", command:"...宏体..."}`
3. 宏本体存成 world Macro（export let 形式）

宏名中括号 pass 表（macroPass 全集）：preItemRoll / preAttackRoll / preCheckHits / postAttackRoll（命中引爆）/ preDamageRoll / postDamageRoll / preSave / postSave / postActiveEffects（施放附魔）/ isDamaged / isHealed。

AE 级逗号式 `"ItemMacro, postAttackRoll"` 且 origin 必填——用户 midi 13.0.55 实测不触发，禁用。非转移效果上 ItemMacro 会被自动重写成 ItemMacro.{物品UUID}。

宏体骨架：
```js
const me = canvas.tokens.controlled[0] ?? token;
const wf = workflow ?? MidiQOL.currentWorkflow;
const target = wf?.hitTargets?.[0] ?? wf?.targets?.[0] ?? game.user.targets?.[0];
if (!wf || !target) return;
// miss 判定：hitTargets 为空 = 没命中（切勿用 hitTargets.length>0 判命中——施放时 targets 也计入）
// identifier 只能英文数字破折号下划线；勿 JSON.stringify(token)
```
CPR fork（自定义宏技能，默认覆盖原自动化）：`export let <identifier> = { name, label, rules }`；identifier 全小写唯一；rules 数组逐条注册。

## 光环（aura）

用 ActiveEffect 挂在光源 token 上：`type:"auraeffects.aura"`，`system.distanceFormula` 半径、`system.disposition` 1 友 -1 敌 0 全体、`applyToSelf`、`collisionTypes:["move"]`、`color`、`opacity`、`showRadius`，`flags.auraeffects={originalType:"base"}`。仅做属性增减益光环；伤害光环（auraDamageEnd / OverTime 经光环送达）实测不掉血——别把伤害塞光环。

## DAE 机制（dae）

- 特殊时长：`flags.dae.specialDuration:["1Attack","1Hit","isSave","isDamaged","longRest","shortRest","zeroHP"]`（1Attack=下次攻击，isSave=豁免后）
- 为假移除/为真禁用表达式：只评估角色数据；`@/##` 双参数——##字段不求值，在目标身上替成@字段
- duration.seconds 60 = 10 轮（1 轮 = 6 秒）
- 特殊键：`macro.execute` / `macro.itemMacro` / `macro.activityMacro` / `macro.createItem`（创建物品）/ `macro.createItemRunMacro` / `macro.actorUpdate` / `macro.deleteUuid`
- DAE 宏签名：args[0] = "on"|"off"|"each"；off/each 时用 `lastArg = args[args.length-1]` 拿激活参数
- change-key 配方（角色侧）：物品/法术侧 `flags.dae.itemMacro` 等；角色侧 `data.bonuses.abilities.check`/`.save`/`.skill.<skl>`、`system.attributes.movement.<mode>`、`system.attributes.ac.bonus`、`system.attributes.hp.tempmax`、`system.attributes.hp.overall`、`system.traits.dr.all`、`system.traits.di.all`、`system.traits.dv.all`、`flags.midi-qol.<...>`
- ⚠ 铁律：切勿用 AE 改 hp.value / hp.max / hp.temp——会当场崩溃。临时 HP 用 tempmax，总血用 overall。

## 激活条件（conditions）

AE 的 changes 或 flags 条件用「运行在」表达式；运算符：== != > >= < <= in（值在集合） in()（集合含值） && || !。变量：workflow、target、actor、token 等。就地函数：`halfHealth`（半血以下）等。示例：
- 只对半血目标：`condition: "target.value.attributes.hp.value <= target.value.attributes.hp.max * 0.5"`（写法见资料原文，细节用 foundry_knowledge topic:conditions 查）
- 不死生物判定、已损血、距离条件等十几例在 data-dict §29 L1042。

## 附魔（enchant）

给物品/行动加附魔键（改物品）：`system.bonuses.<武器缩写>.damage`、`system.attunement`、`system.uses.max`（充能）、`system.range.value`、`system.abilities`、`system.proficient`、`system.weaponProps`、`system.magicBonus` 等；行动：`system.activities.<id>.attack.bonus`、`...save.dc.formula`、`...damage.parts`、`...duration.value`。豁免 DC 计算：flat=固定 / spellcasting=施法者 DC。全部键表 data-dict §28 L1023。

## Optional 全集（optional）

`flags.midi-qol.optional.<id>.<触发>` 触发类型：activation（激活开关）/ force（强制开启）/ count（计数体系 1-9）/ reroll / success / fail / replace。值类型：damage.all|ak|hes|heal、attack.all、save.all、skill.all、check.all 等。详细 data-dict §30 L1092。

## 反应触发 / 触发行动（trigger）

- 反应触发条件：attack hits（被攻击命中）/ melee hit / ranged hit / any hit / ability used / effect applied 等
- 「使用其他行动」= 自己行动的附加效果（如带倒伏的冲撞）；「触发行动」= 条件满足时整行动触发（反击）
- 自动化路由：先判定「谁触发、对谁生效」再选实现层（物品宏 / DAE / OverTime / 光环 / 附魔 / 世界脚本）
