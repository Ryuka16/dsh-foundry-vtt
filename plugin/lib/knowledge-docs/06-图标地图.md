# FVTT 图标路径地图

全量真源 6560 条在 `topic:"icons"`（同目录 `fvtt-icon-paths.txt`，一行一个路径）。

## 怎么用（三步，别猜）

1. **本图定位前缀** —— 看下表的「大类 → 子类」，确定该去哪个目录找。
2. **grep 拿真路径** —— `foundry_knowledge{topic:"icons", query:"halberd"}`，返回最多 40 行含行号的命中。
3. **照抄进文档** —— 把命中的完整路径原样写进 `img` / `icon` 字段。

**禁止凭印象拼路径。** 猜出来的路径 404 会把卡面变成裂图，且错误往往在交付之后才被发现。

---

## ⚠️ 物品 / 效果图标一律用 webp，别用 `icons/svg/`

真源 6560 条 = **webp 6248 / svg 305 / png 6**。`icons/svg/*` 那 118 条是 Foundry 早期留下的**抽象方块图**（`aura.svg`、`circle.svg`），
当物品或效果图标观感很差；`systems/dnd5e/icons/svg/*` 那 237 条是**系统 UI 专用**（活动类型、伤害类型、学派符号），拿它们当物品图标同样不合适。

## 关于 404 的实测说明

旧的坑书记录过一份「失效图标清单」，**其中部分条目经真源核对并不 404**：`icons/svg/trap.svg`、`icons/svg/dice-target.svg` 都在真源 6560 条里，可以直接用。

已确认**确实不存在**的：`icons/svg/status.svg`。

**结论：不要信赖任何记忆里的「某图标不能用」论断，也不要用它去否定。** 以 `topic:"icons"` grep 的实时结果为准 —— 查得到就能用，查不到就换一个。
