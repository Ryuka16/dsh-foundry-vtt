> 本文仅适用于 V12 版本！在 V11 中，您将使用相同的语法，但需要将 `actor.toggleStatusEffect` 替换为 `token.toggleEffect` 。
> 
> （译者注：在v13部分API已被弃用。）



状态效果是您在指示物上右键点击并打开状态效果 HUD 菜单时看到的各类选项。

---

# 如何获取状态效果列表？

你可以通过一个简单的控制台命令获取状态效果列表：

```JavaScript
console.log(CONFIG.statusEffects);
```

我们关注的是每个效果的 `id` 属性。

---

# 切换状态效果

自 V12 版本起，不再能直接在指示物上切换状态效果，需要在角色卡上切换状态效果。

要切换状态效果，可以使用以下命令：

```JavaScript
const effectId = "poisoned"; // 这是一个示范的效果id
const actor = token.actor; // 这是一个指示物的角色卡，在宏中你可以直接操作角色卡，而不需要将其绑定到一个变量
await actor.toggleStatusEffect("poisoned");
```

需要注意的是，此操作将切换状态效果：若为关闭状态则开启状态，若为开启状态则关闭状态。

## 显式设置状态效果

若想无论状态效果的当前状态如何，都能始终移除或添加状态效果，可使用以下命令（译者注：这个方法在v13版本被弃用）：

```JavaScript
const effectId = "poisoned"; // 这是一个示范的效果id
const actor = token.actor; // 这是一个指示物的角色卡，在宏中你可以直接操作角色卡，而不需要将其绑定到一个变量
await actor.setStatusEffect(effectId, , {active: false} ); // 这会移除这个状态效果
```

或

```JavaScript
const effectId = "poisoned"; // 这是一个示范的效果id
const actor = token.actor; // 这是一个指示物的角色卡，在宏中你可以直接操作角色卡，而不需要将其绑定到一个变量
await actor.setStatusEffect(effectId, , {active: true} ); // 这会增加这个状态效果
```

## 将状态效果设置为覆盖层

若希望状态效果图像完全覆盖令牌，类似于“已击败”状态效果，可使用以下命令：

```JavaScript
const effectId = "poisoned"; // 这是一个示范的效果id
const actor = token.actor; // 这是一个指示物的角色卡，在宏中你可以直接操作角色卡，而不需要将其绑定到一个变量
await actor.setStatusEffect(effectId, , {overlay: true}); // 这会增加这个状态效果
```
