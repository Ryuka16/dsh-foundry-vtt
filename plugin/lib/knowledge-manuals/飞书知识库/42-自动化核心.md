# 自动化核心
以下 mod 为 FVTT 的 D&D5e 系统提供了自动化功能，为核心必备。
- Automated Conditions 5e（AC5e）
- Cauldron of Plentiful Resources（CPR）
- Dynamic effects using Active Effects (DAE)
- Gambit's Premades（GPS）
- Midi Quality of Life Improvements（Midi）
- Midi Item Showcase - Community（MISC）
- Times up
# 光环 mod
以下 mod 主要为效果提供了自定义光环，用来实现如圣武士灵光等效应。
- Active Auras
- Aura Effects
# 参数调用
以下 mod 可以让你快速查询调用参数。
- Autocomplete Inline Properties
- Data Inspector
# 补充 mod
以下 mod 增强了自动化。
- Active Token Effects（ATL）
- Advantage Reminder for dnd5e（优势归因）
- Arcane Warding（奥术守御）
- Automated Masteries 5e（武器精通）
- Bugbear's Scripts
- Dnd5e Mirror Image（镜影术）
- Effect Macro
- Rest Recovery 5e（奥术回想，休憩曲等自动化）
- Simple Cover 5e（掩护自动化）
- Wild Magic Surge 5e（狂野魔法）
- More Activities（提供了更多的行动类型）
