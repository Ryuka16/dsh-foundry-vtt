# Docs

> 来源: https://xcnplziulnma.feishu.cn/wiki/ZeLAwD52pijnUkkzHhGcIxpTnnf

macro.actorUpdate 允许你更新角色身上的某个字段，并（可选地）在效果失效时撤销该更新。不过它并不会锁定字段值，而是通过 actor.update 来实现变更。这样你就能编写各种效果，而无需为它们单独创建宏。
# 语法
macro.actorUpdate CUSTOM actorUuid 类型 表达式 目标字段 撤销操作

# 参数说明
actorUuid
字符串，例如 @actorUuid（施法者的UUID）或 @targetUuid（目标的UUID）
类型
number、boolean、string（必须与目标字段的类型匹配）

表达式
掷骰表达式、字符串或布尔值，例如"@attributes.dex.mod * 2 + 10"（必须包含在引号中）。
表达式可以以 +-*/ 开头，表示（角色当前值 + 表达式值）等运算方式

目标字段
字符串，例如system.attributes.hp.temp

撤销操作可选值
未设置/true/restore → 效果失效时恢复目标字段的原始值
remove→ 效果失效时从字段当前值中减去之前增加的值（允许其他来源的修改）
+-*/数值→ 效果失效时对目标字段当前值进行加减乘除运算
数值→ 效果失效时将目标字段设为指定数值
[掷骰数据](https://xcnplziulnma.feishu.cn/wiki/PxmxwHtBniay5LkIH7nce8LunGh)注：数值可以是 （必须包含在引号中）。特殊字符串 "undefined" 会在效果失效时将目标字段设为未定义状态，适用于某些特质等场景。
