# 为什么我下载了汉化 mod 后，XXX还没有汉化？

翻译并没有完全涵盖 FVTT 的全部内容和文本，如果你确保安装了对应的汉化mod且正确，那么没翻译的地方要么是无法被翻译（如mod汉化作者未提供接口），或是还没有被计划翻译（例如DND的一些三方资源）。
