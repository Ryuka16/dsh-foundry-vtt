# 在 V14高版本中恢复旧版用户名下拉选择框

https://www.reddit.com/r/FoundryVTT/comments/1vpgszl/how_to_get_the_login_dropdown_back/

如果你和我一样，非常不喜欢 Foundry 最新更新里新的文本输入式登录方式，可以按照下面的方法把原来的用户名下拉选择框改回来。

找到你的 Foundry 安装目录，然后定位到这个文件：

`foundryvtt/templates/setup/parts/join-form.hbs`

建议先复制一份备份，并将备份文件命名为类似下面这样：

`join-form.hbs-original`

[这里可以查看 Foundry 默认安装路径列表](https://foundryvtt.com/article/user-data/)

编辑 `join-form.hbs`，找到第 7 行：

```Plain Text
<input type="text" name="username" id="join-username" value="{{preselected.name}}">
```

将其替换为：

```Plain Text
{{!-- ORIGINAL v14 text field. To revert: delete the <style> + <select> below and uncomment this.
<input type="text" name="username" id="join-username" value="{{preselected.name}}">
--}}
<style>#autocomplete { display: none !important; }</style>
<select name="username" id="join-username">
  {{#each users.contents as |user|}}
  <option value="{{user.name}}"{{#if (eq user.id ../preselected.id)}} selected{{/if}}>{{user.name}}</option>
  {{/each}}
</select>
```

其中，这段修改会隐藏自动补全组件，并重新使用用户列表作为下拉菜单来选择登录用户名。

> **恢复方法：** 代码注释中保留了原本的 v14 文本输入框。如果之后想恢复新版文本输入方式，只需要删除新增的 `<style>` 和 `<select>` 部分，并取消原始 `<input>` 的注释即可。
