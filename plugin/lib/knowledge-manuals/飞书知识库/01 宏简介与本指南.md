# 这本指南的结构如何

本指南并非JavaScript课程。它旨在帮助你理解如何在 Foundry VTT 中创建和使用脚本宏。虽然本指南中会涵盖基础 JavaScript 概念，但每当引入新概念时，都会提供解释。

本指南是实用的并且包含使用 JavaScript 在 Foundry VTT 中自动化作的示例。每篇文章最终都会赋予你完成特定任务所需的知识。文章按难度组织，按逻辑顺序介绍各种概念。

---

# 什么是宏

宏是 Foundry VTT 中自动化运作的一种方式。FVTT允许你创建自定义脚本，可以通过运行宏，或通过脚本等其他方式激活。

---

## 聊天宏

聊天宏是指在聊天中发布消息的宏。本指南不会涵盖这些内容。

## 脚本宏

脚本宏是运行用 JavaScript 编程语言编写的脚本的宏。这将是本指南的重点。

---

# 如何创建脚本宏

要创建脚本宏，只需点击一个空的快捷栏槽，并将宏类型改为脚本。窗口底部的大文本框将用于编写脚本。

---

# 如何运行脚本宏

要运行脚本宏，只需点击快捷栏中的宏即可。
