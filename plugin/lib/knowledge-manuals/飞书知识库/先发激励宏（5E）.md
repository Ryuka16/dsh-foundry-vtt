# 先发激励宏（5E）

**FVTT版本V12,DND3.X系统已验证。高版本可能需要自行调整api。**

允许执行宏后恢复相应物品的使用次数，需要目标演员具有相应物品（名称完全匹配）。

```JavaScript
const itemName = "诗人激励";

// 获取角色和物品
const actor = token?.actor || game.user?.character;
if (!actor) return ui.notifications.error("请选择角色！");
const channelDivinity = actor.items.getName(itemName);

// 验证物品存在性
if (!channelDivinity) {
  return ui.notifications.error(`找不到 ${itemName} 物品！`);
}

// 获取当前使用次数和最大值
const currentUses = channelDivinity.system.uses?.value || 0;
const maxUses = channelDivinity.system.uses?.max || 0;

// 执行恢复逻辑
if (currentUses >= maxUses) {
  ui.notifications.warn("诗人激励次数已满，无需恢复！");
} else {
  await channelDivinity.update({
    "system.uses.value": Math.min(currentUses + 2, maxUses)
  });
  
  // 发送聊天消息
  ChatMessage.create({
    speaker: ChatMessage.getSpeaker({ actor: actor }),
    content: `${actor.name} 战斗开始恢复了2次吟游诗人激励（当前：${currentUses + 2}/${maxUses}）`
  });
}
```
