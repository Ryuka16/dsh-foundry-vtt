<title>04 访问文档</title>

掌握了如何在 Foundry VTT 中与文档交互后，你现在可以有效地将它们整合进宏中。虽然宏通常直接调用`token`和`actor`对象，但了解如何访问其他文档则会开启更多可能性。

---

# ID 和 UUID

在 Foundry VTT 中，文档通过其 ID 和 UUID 进行区分。

## IDs

ID 是文档中特定的唯一标识符。然而，大多数 ID 需要上下文信息，通常是其容器。

## UUIDs

UUID 作为文档的通用标识符，由 Foundry VTT 自动生成。他们使得文档可以在游戏世界中无关上下文或容器地被识别。

## ID 对比 UUID：一个实用示例

请考虑我们上一篇文章中的`token`。

```JavaScript
console.log(token.document.id); // Output: 'ieHxQxCWYVtY07oi' (这个ID基于你的token是独一无二的)
console.log(token.document.uuid); // Output: 'Scene.xcKEdiLWe09s5Pfl.Token.ieHxQxCWYVtY07oi' 同上
```

在这里，这个指示物在其**场景**中被`ID`唯一标识。与此同时，`UUID` 不仅包含指示物的 ID（`ieHxQxCWYVtY07oi`），还包含它所属的场景（`xcKEdiLWe09s5Pfl`）。一般来说，使用 `UUID` 更可靠。

---

# 查找文档的 ID 或 UUID

要获取文档的 ID 或 UUID（除控制台日志外），请在 FVTT 界面中执行以下步骤：

- 打开文档表（例如，指示物配置、角色卡或场景配置）。
- 在左上角，找到书籍图标。
- `左键点击`复制ID;`右键点击`复制 UUID。

---

# 通过 ID 或 UUID 访问文档

现在你掌握了 ID 或 UUID 知识，可以在宏里面利用他们来访问文档。

## 在宏中通过 UUID 访问文档

```JavaScript
const tokenUUID = "Scene.xcKEdiLWe09s5Pfl.Token.ieHxQxCWYVtY07oi";
const tokenDocument = fromUuidSync(tokenUUID);
console.log(tokenDocument);
```

当文档存在于合集包中时，数据检索需要访问数据库，因此需要`await`数据检索，正如`update`方法所述。

```JavaScript
const tokenUUID = "Scene.xcKEdiLWe09s5Pfl.Token.ieHxQxCWYVtY07oi";
const tokenDocument = await fromUuid(tokenUUID);
console.log(tokenDocument);
```

注意，无论文档是否属于汇编，使用`fromUuid`进行文档检索 ，都需要`await`。

（译者注：`fromUUID`会去获取服务器的数据，是一个异步函数；`fromUUIDsync`则只会加载已经在内存中的内容，如果不介意速度，最好都用前者，不会出错）

## 通过 ID 访问文档

通过 ID 访问文档更为复杂，因为需要知道文档在游戏世界中的位置。在这种情况下，采用 `get` 方法。

```JavaScript
const tokenID = "ieHxQxCWYVtY07oi";// 假设相关token已经在当前场景中
const tokenDocument = canvas.scene.tokens.get(tokenID);
console.log(tokenDocument);
```

例如，通过 ID 访问 某个日志 的 某个页 需要先知道 对应日志 的 ID。

```JavaScript
const pageID = "jKgK9K9gK9gK9K9g";
const journalID = "f3qwfqwfqwfqwfqw";
const journalDocument = game.journal.get(journalID);
const pageDocument = journalDocument.pages.get(pageID);
console.log(pageDocument);
```

## 示例：开关灯

让我们应用知识，创建一个能开关灯的宏。

- 打开灯光配置表。
- 复制光的 UUID。

```JavaScript
const lightUUID = "Scene.xcKEdiLWe09s5Pfl.AmbientLight.jKgK9K9gK9gK9K9g";
const lightDocument = fromUuidSync(lightUUID);
const isLightOff = lightDocument.hidden; 
if (isLightOff) {  
    lightDocument.update({ hidden: false });
} else {  
    lightDocument.update({ hidden: true });
}
```

或者，使用ID来实现：

- 打开灯光配置表。
- 复制灯光ID。
- 打开场景配置表。
- 复制场景ID。

```JavaScript
const lightID = "jKgK9K9gK9gK9K9g";
const sceneID = "xcKEdiLWe09s5Pfl";
const scene = game.scenes.get(sceneID);
const lightDocument = scene.lights.get(lightID);
const isLightOff = lightDocument.hidden; 
if (isLightOff) {  
        lightDocument.update({ hidden: false });
} else {  
    lightDocument.update({ hidden: true });
}
```

有了这样的理解，你就能准备多样化且实用的宏。在下一章中，我们将探讨如何通过其他方式访问文档。
