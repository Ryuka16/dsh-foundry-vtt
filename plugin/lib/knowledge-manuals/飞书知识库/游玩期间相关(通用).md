# 场景的背景图、前景图和预览图是什么？

**背景图：**也就是我们最常使用的，一般是放在底图的。

**前景图：**很少用，主要是覆盖在背景图上面，也会覆盖在 token 上。前景图有个默认的高度，只要 token 高度高于前景图的高度，就可以出现在前景图上面。

**预览图：**场景生成后，可以在场景栏看见的小图（一般自动生成），分辨率很小。

使用最多的是**背景图**，**前景图**看你是否有具体需求再使用，**预览图**一般不用在意。

# 为什么怪物的图裂了？世界包里的地图怎么消失了？

一般是没有索引到对应的图片，你需要查看对应图片链接是否正确，图片是否存在问题。

**检查角色立绘**

打开人物卡，点击`立绘图`（若是`tidy-5e`角色卡，则按`shift+点击`），检查图像是否链接到正确的文件。

![](https://feishu.cn/file/NSOjbZ5BaoreF8xPeeOcjl3mnJg)

**检查角色token图**

点击`指示物（或Token）`，找到`外观`，查看图像路径是否链接到正确的文件。

![](https://feishu.cn/file/BOehbguHPoNlUJx6ZHicp9TOne8)

**检查场景图**

右键侧边栏的场景，点击`配置`，检查`背景图像`和`前景图像`是否链接到正确的文件。

![](https://feishu.cn/file/LlATbBfYXo4H2Hx50nCcuYxxngd)

检查以上图片链接和对应的图片文件，若是不存在，则自己手动重新选择新的文件即可。

# 创建角色卡类型错误了，能不能再调整？

不能，你只能重新建新的角色卡。



# 角色卡数据不同步是怎么回事？

该角色未勾选关联角色数据，点击`指示物（或Token）`，来到`本体`，点击勾选`关联角色数据`。

![](https://feishu.cn/file/UNGXbWsJAo02FixrSpvckPqpnGe)



# 在场景修改了 token 数据，我能同步给其他存在场景的 token 或侧边栏里面的 token 吗？

若是未链接的 token（`指示物（或Token）`未勾选`关联角色数据`），你可以勾选然后再修改令其同步修改侧边栏里面的 token，但场景已经存在的 token 无法同步修改。

![](https://feishu.cn/file/M6yHbFX3LoamiHxdq52c5Aj7n5g)

# 为什么在我掷骰时，DSN 出现了额外的骰子？

![图片展示的是GM Dice So Nice配置界面中“隐藏GM攻击/伤害/豁免的3D掷骰 - 覆写其他设置（仅限合并卡片）”选项。界面中显示“攻击/伤害骰显示为‘dice so nice 隐骰’而非隐藏掷骰（仅限合并卡片）”，并有“保存更改”按钮。该图片与上文“检查midi`GM`配置里，是否启用了如下选项”相关，用于说明在midi`GM`配置中，需检查是否启用了此选项，以解决游玩期间掷骰时DSN出现额外骰子的问题。](https://feishu.cn/file/ZULQbcBWjoevvRx5twwcPcXXnkO)

2.检查Dice so Nice!配置里，是否启用了如下选项。

![图片展示了游戏界面中“动画管理器”相关设置。左侧控件中“动画管理器”选项被勾选。下方有“隐藏GM/盲骰的3D骰子”和“为隐藏的掷骰显示鬼骰”两个设置项，前者已勾选，后者下拉菜单显示“禁用鬼骰”。该图片与文档中“为什么我删除测量板、效果等之后动画还存在？”问题相关，说明需在“Sequencer”配置设定中启用“动画管理器”选项，以解决动画残留问题。](https://feishu.cn/file/RG4kbCwFCoph2yxpvlVcmVFfnke)



# 为什么有些时候消息一闪就消失了？

这是因为你使用了聊天分栏mod（如[Tabbed Whispers](https://gitlab.com/linkedfluuuush/fvtt-tabbed-whispers)），点击聊天栏上方的按钮切换成`掷骰`或`超游`即可看到被分割出来的其他消息。
