有时，仅靠多按钮对话框可能不够用。例如，您可能需要向用户询问一个数字或名称。在这种情况下，我们可以使用输入框。

# HTML 输入框

（译者注：请参考[菜鸟教程-HTML5-Input类型](https://www.runoob.com/html/html-tutorial.html)）

要创建输入框，我们需要学习一些 HTML 知识。HTML 是一种标记语言，用于构建网页的结构。在这里，我们将创建各种类型的输入框。

## text 文本输入框

示例：

```HTML
<input type="text" placeholder="Enter your name" />
```

`type` 属性指定了我们想要创建的输入类型。在本例中，我们需要一个文本输入，因此我们使用 `type="text"` 。 `placeholder` 属性用于向用户提供关于输入内容的提示。

示例 - 设置初始值：

```HTML
<input type="text" value="John Doe" placeholder="Enter your name" />
```

在此示例中，我们将 `value` 属性设置为 `"John Doe"` 。这将在输入字段中显示文本“John Doe”，并且仅当用户清空输入时才会显示 placeholder。

## number 数字输入

示例：

```HTML
<input type="number" placeholder="Enter a number" />
```

`type` 属性设置为 `"number"` 以创建数字输入框。 `placeholder` 属性用于向用户提示输入内容应包含的信息。

示例 - 设置初始值：

```HTML
<input type="number" value="42" placeholder="Enter a number" />
```

示例 - 将输入限制在特定范围内：

```HTML
<input type="number" min="0" max="100" value="50" placeholder="Enter a number between 0 and 100" />
```

在此示例中，我们将 `min` 和 `max` 属性分别设置为 `0` 和 `100` 。这将限制用户输入 0 到 100 之间的数字。 `value` 属性设置为 `50` ，这将在输入框中显示数字 `50` 。

## checkbox 复选框

示例：

```HTML
<input type="checkbox" />
```

`type` 属性设置为 `"checkbox"` 以创建复选框。

示例 - 设置初始值：

```HTML
<input type="checkbox" checked />
```

在此示例中，我们设置了 `checked` 属性。 `checked` 属性用于指示复选框是否被选中。

## select 选择

示例：

```HTML
<select>    
    <option value="1">Option 1</option>    
    <option value="2">Option 2</option>    
    <option value="3">Option 3</option>
</select>
```

`select` 元素用于创建下拉菜单。 `option` 元素用于在下拉菜单中创建选项。

示例 - 设置初始值：

```HTML
<select>    
    <option value="1" selected>Option 1</option>    
    <option value="2">Option 2</option>    
    <option value="3">Option 3</option>
</select>
```

在此示例中，我们设置了 `selected` 属性。 `selected` 属性用于指示复选框是否被选中。

## 创建带标签的输入框

通常，我们会希望在输入字段旁添加一个标签。标签是描述输入字段用途的文本。

示例：

```HTML
<div class="form-group">    
    <label for="name">Name</label>    
    <input type="text" placeholder="Enter your name" />
</div>
```

外层的 `form-group` `div` 元素是 Foundry 特有的，虽然不是必需的，但能为你的输入字段提供默认样式。

## 使用 name 属性

为了后续能够访问输入框的值，最好为其分配一个唯一的名称。

示例：

```HTML
<div class="form-group">    
    <label for="dice">Dice</label>    
    <input type="text" name="dice" placeholder="Enter your dice" />
</div>
```

## 使用表单

如果想让我们的输入框获得美观的 `form-group` 格式，需要将其包裹在 `form` 元素中。

表单元素还能帮助我们稍后轻松地获取数据。

示例：

```HTML
<form>    
    <div class="form-group">        
        <label for="name">Name</label>        
        <input type="text" name="name" placeholder="Enter your name" />    
    </div>
</form>
```

# 在对话框中使用输入框

既然我们已经学会了如何创建输入框，现在可以在对话框中使用它了。

## 从表单中获取数据

为了从表单中获取数据，我们需要使用 `FormDataExtended` 类。虽然还有其他方法可以实现，但这是最可靠且易于使用的方式。

Example: 示例：

```JavaScript
const formData = new FormDataExtended(html[0].querySelector("form")).object;
```

我们来分解一下：

- `html[0].querySelector("form")` 是表单的 HTML 代码。我们可以使用 `querySelector` 方法来获取html中的所有表单元素。
- `new FormDataExtended(html[0].querySelector("form"))` 从表单元素创建一个新的 `FormDataExtended`对象。
- `.object` 获取代表表单数据的对象。

## 示例：投掷用户自定义数量的骰子

在此示例中，我们让用户投掷自定义数量的六面骰子。

```JavaScript
const myDialog = new Dialog({    
    title: "Roll Dice",    
    content: `
                <form>      
                        <div class="form-group">        
                                <label for="dice">How Many Dice?</label>        
                                <input type="number" name="dice" min="1" max="100" value="1" placeholder="Enter the number of dice">      
                        </div>    
                </form>  
        `,    
    buttons: {        
        ok: {            
            label: "OK",            
            callback: async (html) => {
                // 请注意在此回调中我们包含了什么（译者注：原文放在下面了，我感觉是what写成了how） html 参数，它是对话框的 HTML
                // Note how in this callback we are including the html parameter, which is the HTML of the dialog
                const formData = new FormDataExtended(html[0].querySelector("form")).object;
                // 使用此语法，我们使用辅助类从表单中获取所有数据      
                const roll = new Roll(`${formData.dice}d6`); 
                // 我们可以用input的name从form中读取数据
                await roll.evaluate();                
                roll.toMessage();            
            },        
        },    
    },
}); 
myDialog.render(true);
```

## 示例：让用户选择图像

在此示例中，我们让用户选择一张图像，并将其应用到选定的令牌上。

```JavaScript
const myDialog = new Dialog({    
    title: "Choose an Image",    
    content: `    
            <form>      
                    <div class="form-group">        
                            <label for="image">Choose an Image</label>        
                            <select name="image">          
                                    <option value="assets/images/image1.png">Image 1</option>
                                    <option value="assets/images/image2.png">Image 2</option>    
                                    <option value="assets/images/image3.png">Image 3</option>
                            </select>      
                    </div>    
            </form>  
    `,    
    buttons: {        
        ok: {            
            label: "OK",            
            callback: (html) => {                
                const formData = new FormDataExtended(html[0].querySelector("form")).object;                
                const image = formData.image;                
                token.document.update({ "texture.src": image });            
            },        
        },    
    },
}); 
myDialog.render(true);
```

## 示例：多个输入

在此示例中，我们让用户选择要掷哪种骰子以及掷多少个。

```JavaScript
const myDialog = new Dialog({    
    title: "Roll Dice",    
    content: `
            <form>      
                    <div class="form-group">
                            <label for="dice">How Many Dice?</label>
                            <input type="number" name="dice" min="1" max="100" value="1"> 
                    </div>      
                    <div class="form-group">        
                            <label for="sides">Which Dice?</label>        
                            <select name="sides">          
                                    <option value="d4">4-Sided</option>          
                                    <option value="d6">6-Sided</option>          
                                    <option value="d8">8-Sided</option>          
                                    <option value="d10">10-Sided</option>          
                                    <option value="d12">12-Sided</option>          
                                    <option value="d20">20-Sided</option>        
                            </select>      
                    </div>    
            </form>  
    `,    
    buttons: {        
        ok: {            
            label: "OK",            
            callback: async (html) => {                
                const formData = new FormDataExtended(html[0].querySelector("form")).object;                
                const diceNumber = formData.dice;                
                const diceSides = formData.sides;                
                const roll = new Roll(`${diceNumber}${diceSides}`);                
                await roll.evaluate();                
                roll.toMessage();            
            },        
        },    
    },
}); 
myDialog.render(true);
```

# 小心数字！

使用输入时，数值会被读取为字符串。这意味着如果你需要使用数字，就需要将其转换为数字类型。

请注意，虽然 `FormDataExtended` 类会自动为我们进行转换，但了解这一点仍然很有帮助，以防你在宏中遇到奇怪的数字而感到困惑。

**示例（数字的错误用法）：**

```JavaScript
const myDialog = new Dialog({    
    title: "Incorrect Number Handling",    
    content: `    
            <form>      
                    <div class="form-group">        
                            <label for="dice">How Many Dice?</label>        
                            <input type="number" name="dice" min="1" max="100" value="1">    
                    </div>    
            </form>  
    `,    
    buttons: {        
        ok: {            
            label: "OK",            
            callback: async (html) => {                
                const formData = new FormDataExtended(html[0].querySelector("form")).object;                
                const diceNumber = formData.dice; // 范例值 "2"
                const calculatedDiceNumber = 5 + diceNumber; // 这会拼接字符串而不是相加
                console.log(calculatedDiceNumber); // 这会输出52
                const roll = new Roll(`${calculatedDiceNumber}d6`);                
                await roll.evaluate(); // 在这里我们将要掷52个六面骰，而这并非我们想要的。
                roll.toMessage();            
            },        
        },    
    },
}); 
myDialog.render(true);
```

**示例（数字的正确用法）：**

```JavaScript
const myDialog = new Dialog({
  title: "Correct Number Handling",
  content: `
    <form>
      <div class="form-group">
        <label for="dice">How Many Dice?</label>
        <input type="number" name="dice" min="1" max="100" value="1">
      </div>
    </form>
  `,
  buttons: {
    ok: {
      label: "OK",
      callback: async (html) => {
        const formData = new FormDataExtended(html[0].querySelector("form")).object;
        const diceNumber = formData.dice;
        const calculatedDiceNumber = parseInt(diceNumber) + 5; // 将字符串转换为数字并加5
        console.log(calculatedDiceNumber); // 如果输入值为 1，则会输出 6
        const roll = new Roll(`${calculatedDiceNumber}d6`);
        await roll.evaluate();
        roll.toMessage();
      }
    }
  }
});
 
myDialog.render(true);
```
