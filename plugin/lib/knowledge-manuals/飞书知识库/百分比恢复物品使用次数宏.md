# 百分比恢复物品使用次数宏

**FVTT版本V12,DND3.X系统已验证。高版本可能需要自行调整api。**

适合恢复物品使用次数（可以自行配置仅恢复装备，武器，法术或特性等）。

![图片展示的是FVTT系统中“修理光粉”的物品界面。界面显示该物品为普通资源，数量为1，重量0.01，价格150gp，属性有1动作、自身、自身。描述部分显示使用1动作可修复武器25%耐久。界面有“未鉴定”和“已鉴定”开关，当前处于“已鉴定”状态。该图片与文档中介绍适合恢复物品使用次数的宏相关，直观呈现了宏中可恢复物品的物品界面样式。](https://feishu.cn/file/M1KDbfiyroOuhmxjfZEcjfqNneb)

```JavaScript
// 恢复武器使用次数的宏
const RESTORE_PERCENT = 0.25; // 恢复百分比 (25%)

// 获取所选目标
const targets = game.user.targets;

if (targets.size === 0) {
  ui.notifications.warn("请先选择目标角色！");
} else {
  // 遍历所有选中的目标
  for (const token of targets) {
    const actor = token.actor;
    
    if (!actor) {
      ui.notifications.warn(`目标 ${token.name} 没有对应的角色数据！`);
      continue;
    }
    
    // 获取所有武器物品
    const weapons = actor.items.filter(item => item.type === "weapon");
    
    // 筛选出有使用次数的武器
    const weaponsWithUses = weapons.filter(weapon => weapon.system.uses?.max > 0);
    
    if (weaponsWithUses.length === 0) {
      ui.notifications.warn(`${actor.name} 没有找到有使用次数的武器！`);
      continue;
    }
    
    // 准备更新数据
    const updates = [];
    const restoredWeapons = [];
    
    // 遍历所有有使用次数的武器
    for (const weapon of weaponsWithUses) {
      const currentUses = weapon.system.uses.value;
      const maxUses = weapon.system.uses.max;
      
      // 计算恢复量（最大使用次数的百分比，四舍五入）
      const restoreAmount = Math.round(maxUses * RESTORE_PERCENT);
      
      // 计算新的使用次数
      let newUses = currentUses + restoreAmount;
      if (newUses > maxUses) {
        newUses = maxUses;
      }
      
      // 只有当使用次数发生变化时才更新
      if (newUses !== currentUses) {
        updates.push({
          _id: weapon.id,
          "system.uses.value": newUses
        });
        
        restoredWeapons.push({
          name: weapon.name,
          oldValue: currentUses,
          newValue: newUses,
          max: maxUses,
          restoreAmount: restoreAmount
        });
      }
    }
    
    // 执行更新
    if (updates.length > 0) {
      await actor.updateEmbeddedDocuments("Item", updates);
      
      // 发送聊天消息
      let message = `<h2>武器使用次数恢复</h2>`;
      message += `<p>${actor.name} 的以下武器恢复了 ${RESTORE_PERCENT * 100}% 使用次数：</p>`;
      message += `<ul>`;
      
      for (const weapon of restoredWeapons) {
        message += `<li><b>${weapon.name}</b>: ${weapon.oldValue} → ${weapon.newValue}/${weapon.max} (恢复 ${weapon.restoreAmount} 次)</li>`;
      }
      
      message += `</ul>`;
      
      ChatMessage.create({
        speaker: ChatMessage.getSpeaker({ actor: actor }),
        content: message
      });
      
      ui.notifications.info(`成功为 ${actor.name} 恢复了 ${restoredWeapons.length} 件武器的使用次数！`);
    } else {
      ui.notifications.info(`${actor.name} 没有需要恢复使用次数的武器！`);
    }
  }
}
```
