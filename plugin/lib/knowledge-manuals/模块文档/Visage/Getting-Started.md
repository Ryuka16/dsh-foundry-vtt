# Mastering *Visage*

Welcome to the *Visage* tutorial series. It is designed to take you from your very first disguise all the way to building a fully automated, audio-visual setup.

Before you begin, here are a few things to keep in mind:

- **Progressive Learning:** The initial tutorials will walk you through almost every single click and menu needed to create a *Visage*. As you become more familiar with the UI, later tutorials will stop holding your hand and focus purely on the new concepts.
- **Sequential Builds:** These tutorials are designed to be completed in order. Later tutorials might ask you to apply or modify *Visages* that you created in earlier lessons.
- **Hidden Gems:** Pay close attention to the *Tips* sections in each tutorial. These contain useful advice that will help you unlock the true power of the module's system.

   > **Tips:** Tips are formatted like this.

- **Module Dependencies:** While the core features of *Visage* work out-of-the-box, *Part 2* and *Part 3* of this series will require you to use the *Sequencer* module. I also highly recommend having asset modules installed (like *JB2A* for spells/animations, *PSFX* for audio, and *FA Nexus* for token art) so you have assets available to use during the tutorials.
