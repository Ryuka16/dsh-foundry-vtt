# How to contribute animations to the module?

The below video shows how to create a new animation and then export it using a pre-made macro.

https://files.catbox.moe/2szruf.mp4

Once you have followed these steps, you will find the new file inside your Foundry data folder.

![image](https://user-images.githubusercontent.com/32039708/221060164-d2d9af0b-6cde-41df-ac67-9804b11ded2f.png)

You now have a ready to be submitted copy of the Autorecognition File. You can easily make a [Pull Request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request) by going [here](https://github.com/MrVauxs/dnd5e-animations/blob/master/module/autorec.json) and clicking "Edit this File" button in the top right corner.

![image](https://user-images.githubusercontent.com/32039708/221061839-14cc61b8-1cbd-40cb-93a4-4a4597c937b5.png)

There you can copy paste the contents of the files and then create a Pull Request.
