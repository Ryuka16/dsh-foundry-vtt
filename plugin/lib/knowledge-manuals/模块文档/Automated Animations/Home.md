# Welcome to the Automated Animations wiki!
  
**Automated Animations provides an interface to build out simple Sequencer macros, and ties those directly to items. Any animations can be used, but by default the module assumes you have a JB2A module installed (free or Patreon).**

## **Module Overview**  
Automated Animations is separated into two main sections:  
1. Global Automatic Recognition  
2. Custom Item Settings  

### [Automatic Recognition](https://github.com/otigon/automated-jb2a-animations/wiki/Automatic-Recognition)  
The Global Automatic Recognition menu is located in the Module Settings. If you are a new user, this is where you want to start. I have prepopulated the list with approximately 35 Animations based on DnD 5e.  
  
This menu will set the "default" animation for an item based on name recognition. For example: You can set "Sword" in as an Automatic Recognition setting in the Melee menu, then any item with "sword" in the name will utilize that as it's base animation.
  
Then setting "Greatsword" as a name field will capture all weapons with Greatsword in the name (Greatsword +1, Flaming Greatsword, etc)   
  
### [Custom Item Settings](https://github.com/otigon/automated-jb2a-animations/wiki/Custom-Item-Menus)
Each Item can be customized with it's own Animation settings. This menu can be accessed on each item by the "A-A" button on its Title Bar.
