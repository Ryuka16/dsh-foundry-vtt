# **什么是服务端？**

挂在服务器的 FVTT（也包括 COS 桶 / OSS 桶）。服务端上传文件不会消耗流量，下载文件时会消耗下载文件大小的流量。

服务端对性能要求极低，对带宽要求高（至少`12m`），带宽低则无法保证资源及时下载。



# **什么是客户端？**

本地访问 FVTT 的电脑，分为 GM 端和 PL 端。

GM 端对电脑性能要求更高，在安装 mod 时请考虑自己本地电脑的性能配置，尤其关注内存使用情况，请保证至少 `16``GB` 内存以及存储 FVTT 的资源盘至少有 `4g` 存储空间。



# FVTT卡顿如何优化？

当你使用 FVTT 出现卡顿时，请查看是否存在以下情况：

1. 使用非 FLC 浏览器访问 FVTT

<bookmark name="Foundry Lightweight Client" href="https://foundry.ruleplaying.com/flc"></bookmark>

1. 在服务端操控 FVTT（此时如果是云服务器，则一般会提示硬件加速）
2. 浏览器未打开硬件加速/图形加速
3. 电脑未启用独显模式
4. 服务端带宽过低（`12m`及以下）
5. 客户端性能不足，尤其是内存太低
6. 场景持续动画太多（也就是一直播放的动画）
7. 场景的墙体或光源设置太多
8. mod 冲突
9. 其他问题



# FVTT 迁移世界包到最新版本时很慢或者会闪退？

迁移本身会占用服务端的大量内存，所以慢或者闪退是正常的（因为推荐的服务器基本都只有`2g`内存）。

**解决办法：**

1.禁用全部 mod 进行世界包迁移；

2.本地迁移完毕后，再将迁移完成的世界包上传到服务端之中。
