# 聊天日志

所有聊天消息均可通过游戏内的聊天日志侧边栏查看。该侧边栏底部设有文本输入框，供用户输入可被他人查看的消息。按Enter键发送已输入的消息，按`Shift+Enter`键可在消息中换行。按上方向键可调出上一条已输入的消息或命令。



聊天记录的保存不依赖于场景。但如果装了mod“Tabbed Whisper”，切换到新场景聊天记录会重置，切换回旧场景时读取原聊天记录。

# 保存

GM可通过文本输入框上方的`导出聊天日志`按钮（图标为软盘）将聊天日志保存为文件。此操作会将所有可用聊天消息导出为 .txt 文件。

![保存图标](https://feishu.cn/file/Jb2BbZLyJoG6NixtDfUcA6Qcnog)



# 删除

GM 可通过文本输入框上方的`清空聊天日志`按钮（图标为垃圾桶）清除聊天日志。此操作将删除聊天日志中的所有消息。GM 同样可以删除单条消息：每条消息的右上角均有一个垃圾桶图标。



# 掷骰模式

掷骰模式下拉菜单用于配置由游戏系统、模组或宏创建的自动掷骰将执行的骰子掷骰类型。

**请注意：**选定的掷骰模式为自动掷骰提供指导，但使用`/r`命令进行的掷骰总是公开掷骰，详见<cite doc-id="JtcnwpeyJip9rGkAkRBcoGFan0c" file-type="wiki" title="掷骰公式" type="doc"></cite>。



# 弹出式聊天消息

部分游戏系统允许在特定聊天消息发布后，将其弹出至独立窗口以便快速查看。此功能需系统明确支持（比如 DND5e 系统）。若消息支持弹出，右键点击该消息可在上下文菜单中选择`弹出消息`选项；若不支持，则此选项不会出现。

# 聊天命令

> *或许是最有用也或许是最没用的功能，谁会用fvtt的聊天跑文字团啊、*

<callout emoji="❗">
你可以使用[Chat Commander](https://foundryvtt.com/packages/_chatcommands/)来自动补全聊天命令
</callout>

- **角色内发言**

  - **语法：**`/ic {消息}`
  - 使消息以关联角色的身份说出。
  - 当玩家（包括GM）选中一个 Token 时，其发言将自动以该角色的视觉**角色内发言**，无需为每条消息输入此命令。此外，若同时满足以下两个条件，也将自动应用`/ic`命令：
  
    1. 用户在`用户配置`窗口中已分配角色；
    2. 该角色在当前场景中存在 Token。
- **角色外发言**

  - **语法：**`/ooc {消息}`
  - 使消息以角色外（OOC）方式说出。角色外消息会以玩家颜色高亮边框，以便识别。未指定发言者或未选中令牌的玩家将自动进行角色外发言。
- **表情动作**

  - **语法：**`/emote {消息}` 或 `/em {消息}` 或 `/me {消息}`
  - 使消息成为选定角色执行的表情动作。表情动作是玩家通过文字传达的角色内行为，因此需要玩家选中一个 Token（或通过`用户配置`窗口关联一个角色）。例如：控制名为奶龙的角色时输入`/emote 哈气了。`，将发送消息：`奶龙 哈气了。`
- **私信**

  - **语法：**`/whisper {目标} {消息}` 或 `/w {目标} {消息}`
  - 向目标私密发送消息。若发送消息的用户不具备**私信**权限，则无法使用此聊天命令。如果私信的目标是已分配给某用户作为其玩家角色的角色，则该私信将发送给该用户。
  - **注意：**可通过将用户名以逗号分隔列表形式置于方括号内，同时向多名用户发送消息。例如：`/w [Andrew, Tim, Julia] 你们觉得呢？我们是进攻还是潜行？`。此外，使用`gm`和`players`作为目标名可分别向所有 GM 用户或所有非 GM 用户发送私信。
  - GM 用户并无特殊权限查看私信。若他们未被包含在私信的目标中，则无法看到该消息。(如果你对此不满意，请使用[DM Whisper Monitoring](https://foundryvtt.com/packages/dm-whisper-monitor)模组)
- **掷骰**

  - 语法：`/roll`, `/gmroll`, `/blindroll`, `/selfroll`
  - 以聊天消息形式掷骰。在聊天日志中，可点击掷骰结果以展开其工具提示，显示每个独立骰子的数值。再次点击可收起显示。
  - 关于如何在 FVTT 中掷骰的更多详情，请参阅<cite doc-id="JtcnwpeyJip9rGkAkRBcoGFan0c" file-type="wiki" title="掷骰公式" type="doc"></cite>。掷骰完成后，可通过点击掷骰总值来展开查看详细结果。



## 格式

### 行内掷骰

你可以在任何文本中嵌入掷骰，方法是将骰子公式用双括号 `[[]]` 括起来，例如：

```JavaScript
敏捷的棕色狐狸 [[2d10+5]] 跳过了懒惰的狗。
```

当你将此文本发送到聊天时，骰子将会被掷出，结果显示在文本中，如下图所示：

![图片展示的是聊天界面中的一条消息。消息发送者为“Gamemaster”，其头像为一个带有兜帽的神秘人物。消息内容为“敏捷的棕色狐狸 19 跳过了懒惰的狗。”其中“19”以骰子图标突出显示，表明这是一个行内掷骰的结果。该图片与上下文紧密相关，上下文在介绍如何在聊天中嵌入行内掷骰，此图直观呈现了掷骰结果在聊天界面中的显示效果。](https://feishu.cn/file/J39XbvLfcoAFlExXsRNcmho0nfg)

你还可以在行内放置**可点击**掷骰。这将在行内显示骰子公式而不是自动掷骰，点击时才会掷骰。你可以在双括号内包含掷骰命令来实现此功能，例如：

```JavaScript
敏捷的棕色狐狸 [[/r 2d10+5]] 跳过了懒惰的狗。
```

发送到聊天时，它会显示为下图所示：

### 引用

你可以在 FVTT 的任何文本框中引用几乎任何实体，例如：

| **实体类型** | **代码格式** | **备注** |
|-|-|-|
| 角色 | `@Actor[角色名称]` | 注意：必须存在具有该名称的角色实例，而不仅仅是合集包中有条目。 |
| 场景 | `@Scene[场景名称]` |  |
| 物品 | `@Item[物品名称]` | 与角色引用类似，此引用指向物品（见物品侧边栏），而不仅仅是合集包中有条目。 |
| 日志条目 | `@JournalEntry[日志条目名称]` |  |
| 合集包 | `@Compendium[条目名称]` |  |
| 随机表 | `@RollTable[随机表名称]` |  |
| 宏 | `@Macro[宏名称]` | 注意：链接到宏或随机表不会自动掷骰——它将创建一个需要点击才能掷骰的按钮。 |

条目/对象链接是区分大小写的！ 包括类型（`"JournalEntry"`，而非 `"journalEntry"`）和对象的名称（`"Abacus"`，而非 `"abacus"`）。你还可以在某些地方通过拖放对象来创建链接。

对于角色（Actor）、物品（Item）和其他使用 `@[]` 风格的引用，创建的是指向特定对象ID的引用。如果该对象后来被删除，即使创建了同名的新对象，现有链接也不会指向新对象。还需注意，如果存在多个同名选项，则会选择**第一个**对象。如果那个**第一个**对象恰好因权限问题导致玩家不可见，那么即使存在玩家可见的**第二个**对象，点击引用链接也会给他们一个权限错误。

一般来说，我们有更统一的格式以避免指向错误，注意，`@UUID[实体类型.实体ID]{显示名称}`也可以直接引用合集包内文档

```JavaScript
@UUID[实体类型.实体ID]{显示名称}
```

或是引用合集包文档

```JavaScript
@Compendium[包名.项目名.实体ID]{显示名称}
```

### HTML格式

#### 嵌入网页

你可以在 FVTT 中任何有文本编辑器的地方嵌入大多数网页。打开文本编辑器后，点击源代码按钮 (`<>`) 并粘贴以下代码，将 `YOUR_LINK` 替换为你希望嵌入的网站链接（链接中需包含 `https://`）：

```XML
<div style="overflow: hidden; position: relative; min-height: 100%;"><iframe style="border: 0; height: 100%; left: 0; position: absolute; top: 0; width: 100%;" src="YOUR_LINK" width="100%" height="100%" allowfullscreen="true">
</iframe></div>
```

这是嵌入规则参考、SRD（系统参考文档）、视频甚至角色表的有用方法。某些网站因其隐私设置可能无法嵌入，而某些网站要求使用特殊的嵌入链接。

# 聊天气泡

当从已放置 Token 的视角发送角色内消息或表情动作聊天消息时，镜头会移动以聚焦于该角色，且一个聊天气泡将出现在该 Token 上方，在游戏画布上视觉化展示对话。核心游戏设置中有两个开关可配置聊天气泡的行为：

- **聊天气泡：**开关聊天气泡的显示。
- **聚焦发言：**开关镜头平移聚焦于对话发言者。
