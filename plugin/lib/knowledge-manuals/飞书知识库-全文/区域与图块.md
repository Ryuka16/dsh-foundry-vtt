# 区域与图块

区域能实现一些场景的自动化，比如踏入时传送、切换天气、弹出文字等。图块用来展示一些图片或者视频，以及制作屋顶，一般搭配**MATT（Monk's Active Tile Trigger）**使用。



## 区域

切换至区域控件后，用矩形/椭圆/自由绘制可以画出区域。要注意的是，如果要绘制新的区域，需要先选择第一个“选择区域”的子控件，然后在空白处取消选择，再用工具画新的区域，此时会随机一个新颜色。在“区域图例”中删除时，会删除所有同一个颜色的区域。



第五个子控件“创建空洞”，开启后画出的区域将会在已有的区域上挖洞，关闭后恢复正常。

## 图块

切换到图块控件后用第二个子控件画出图块，在“外观中”填入图片或视频的路径。限制光线/天气一般不用。



如果在“位置”处的高度填写1-20之间，则图块将会置于角色token上方。“遮挡模式”选择“渐隐”，即可实现在门外显示屋顶图像，屋内隐去屋顶图像。调整“外观”中的“不透明度”，可以调整图片显示的百分比。



当高度达到20及以上时，将会进入“前景层”，需要点击第四个子控件，才能选择前景层的图块。
