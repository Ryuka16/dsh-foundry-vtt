<title>播放列表和声音</title>

在本文中，我们将探讨如何使用 Foundry API 来操作播放列表和声音，包括为单个或所有用户播放声音，而无需依赖播放列表。

---

# 播放列表

您可能之前使用过播放列表，但或许对如何通过宏来启动和停止它们不太熟悉。宏是在不同环境或场景中自动化声音设置的绝佳方式！

## 启动和停止播放列表

首先，我们需要获取想要操作的播放列表的 UUID。

```JavaScript
const playlist = fromUuidSync("Playlist.h3kmFH5VX3Ih1zHa");
```

现在我们可以开始或停止播放列表。

```JavaScript
playlist.playAll();
```

或

```JavaScript
playlist.stopAll();
```

## 停止所有播放列表

通常，在启动你感兴趣的播放列表之前，你会希望先停止所有播放列表。

```JavaScript
const playlist = fromUuidSync("Playlist.h3kmFH5VX3Ih1zHa"); 
for (const p of game.playlists) {    
    await p.stopAll();
}
playlist.playAll();
```

## 处理单个声音

上述方法适用于顺序播放列表，但如果我们想从音效板播放列表中播放特定音效，或者从特定曲目开始播放列表，该怎么办？

我们可以使用 `playSound` 方法从播放列表中播放音效。

```JavaScript
const playlist = fromUuidSync("Playlist.h3kmFH5VX3Ih1zHa");
const sound = fromUuidSync("Playlist.rzgZiShqThIWPe5y.PlaylistSound.TZsKVnbxL0RGgKM1"); 
await playlist.stopAll(); // Stop all sounds in the playlist; this is optional
await playlist.playSound(sound);
```

同样地，我们可以停止播放列表中的特定音效。

```JavaScript
const playlist = fromUuidSync("Playlist.h3kmFH5VX3Ih1zHa");
const sound = fromUuidSync("Playlist.rzgZiShqThIWPe5y.PlaylistSound.TZsKVnbxL0RGgKM1"); 
await playlist.stopSound(sound);
```

您也可以通过曲目名称来检索音轨。

```JavaScript
const playlist = fromUuidSync("Playlist.h3kmFH5VX3Ih1zHa");
const sound = playlist.sounds.getName("Track Name"); 
await playlist.playSound(sound);
```

## 播放单个音频文件

有时，您可能希望播放不在播放列表中的音频文件。您可以使用 `AudioHelper` 类来实现此功能。

```JavaScript
foundry.audio.AudioHelper.play(
    {        
        src: "sounds/example.mp3",        
        volume: 0.5,        
        loop: false,    
    },    
    true,
);
```

将参数设置为 `true` 会使音频对所有用户播放。将其设置为 `false` 则仅对执行宏的用户播放音频。

## 停止使用 AudioHelper 类播放的声音

使用 `AudioHelper` 类播放的任何声音都会在页面刷新时停止，因为它不是持久化的。虽然有其他方法可以停止使用 `AudioHelper` 类播放的声音，但此处不作介绍，因为这种方法更适合类似短音效板的效果。

## 实践应用：音效板宏

在这个实际示例中，我们将创建一个宏，用于显示带有音效板的对话框。

```JavaScript
// 第一步创建我们的音效列表
const sounds = [    
    {        
        name: "Sound 1",        
        src: "sounds/example.mp3",    
    }, {        
        name: "Sound 2",        
        src: "sounds/example2.mp3",    
    },
]; 

// 现在我们将创建一个复杂的对话框，引入一些新概念
let html = ``;
// 我们在传入对话框之前创建该对话框的 HTML
html += `<div style="display: grid; gap: 1rem; grid-template-columns: repeat(5, 1fr);">`; // 为按钮创建一个网格，将 5 更改为您想要的任何数字
for (const sound of sounds) {    
    // 使用一些css使音效名称居中 
    html += `
<div class="sound-button" 
     style="cursor: pointer; padding: 0.3rem; border: 1px solid; border-radius: 5px; display: flex;align-items: center; justify-content: center; text-align: center; aspect-ratio: 1;" 
        data-src="${sound.src}">
        ${sound.name}
</div>
        `; 
    // 为每个音乐创建一个按钮
}

// 创建对话框
html += `</div>`; 
const dialog = new foundry.applications.api.DialogV2({    
    window: {        
        title: "Soundboard",    
    },    
    content: html,    
    buttons: [{            
        action: "close",            
        icon: "<i class='fas fa-times'></i>",            
        label: "Close",            
        callback: () => { this.close(); },        
    },],
}); 

// 将事件附加到对话框渲染中，以便将点击事件添加到按钮中
sdialog._onRender = function () {    
    const html = this.element;    
    // 给按钮增加点击事件  
    html.querySelectorAll(".sound-button").forEach((button) => {
        button.addEventListener("click", async () => {            
            const sound = button.dataset.src;            
            await foundry.audio.AudioHelper.play(
                {                    
                    src: sound,                    
                    volume: 0.5,                    
                    loop: false,                
                },                
                true,            
            );            
            this.close(); // 可选：播放声音后关闭对话框   
        });    
    });
}; 
// 打开这个对话框
dialog.render(true);
```
