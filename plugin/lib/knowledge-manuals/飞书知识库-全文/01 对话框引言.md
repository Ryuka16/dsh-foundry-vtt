<title>01 对话框引言</title>

对话框是创建多选宏的绝佳方式。例如，我们可以创建一个对话框，让用户选择要为指示物分配哪个图像。在这第一篇文章中，我们将探讨对话框的基础知识。

---

# 创建对话框

FVTT 中的对话框是一个 JavaScript 类。简单来说，类就是创建对象的蓝图。在当前，我们正在创建一个对话框。

**示例基础对话框：**

```JavaScript
const myDialog = new Dialog({  
    title: "My Dialog",  
    content: "This is the content of my dialog",  
    buttons: {    
        one: {      
            icon: "<i class='fas fa-check'></i>",      
            label: "One",      
            callback: () => console.log("One was clicked"),    
        }, 
        two: {      
            icon: "<i class='fas fa-times'></i>",      
            label: "Two",      
            callback: () => console.log("Two was clicked"),    
        },  
    },
}); 
myDialog.render(true);
```

让我们来分解一下。创建对话框的核心过程可以划分为以下几个步骤：

首先，我们创建对话框。

```JavaScript
const myDialog = new Dialog({...dialogData}); // 通过对话框蓝图创建一个对话框 
myDialog.render(true); // 渲染对话框，如果跳过这步，对话框将不会在屏幕中出现。
```

`Dialog` 类拥有许多属性和方法，可让我们用于自定义对话框。主要属性包括：

```JavaScript
Dialog({  
    title: "My Dialog", // 对话框的标题
    content: "This is the content of my dialog", // 对话框的内容
    buttons: {}, // 对话框的按钮
});
```

`title` 和 `content` 的含义不言自明。 `buttons` 是我们定义对话框按钮的地方。按钮被定义为一个具有以下结构的对象：

```JavaScript
{  
    one: {    
        icon: "<i class='fas fa-check'></i>", // 按钮的图标    
        label: "One", // 按钮的标签    
        callback: () => {
            // 对于复杂的逻辑，我们可以使用回调函数的扩展格式，这两种语法是等效的，我们将在以后的示例中使用第二种（译者注：大概是说加不加大括号吧，我猜）
            console.log("One was clicked");      
            // 做点别的事  
        }, // 点击按钮会发生什么
    },
}
```

`label` 的含义不言自明，但我们如何获取这些图标呢？我们可以使用 Font Awesome 网站来获取特殊代码。

- 搜索你想要的图标。
- 点击图标以打开其模态对话框。
- 你会看到一个类似于示例中的代码（如 `<i class="fa-solid fa-heart"></i>` ）；点击它以复制。
- 将其粘贴到按钮的 `icon` 属性中。

`callback` 是按钮被按下时发生的情况。请注意，任何按钮按下都会自动关闭对话框。

`one` 是按钮的名称。这可以是任何你想要的名称，但必须是唯一的。这个值仅在内部使用，不会显示给用户。

# 实践：创建指示物图像选择对话框

现在，让我们将其付诸实践，创建一个对话框，让用户选择为其选定的指示物分配哪个图像。

```JavaScript
const tokenDocument = token.document; // 首先我们获取指示物文档
const myDialog = new Dialog({  
    title: "Choose an image",  
    content: `Choose an image to assign to this token`,  
    buttons: {    
        combat: {      
            icon: "<i class='fas fa-sword'></i>",      
            label: "Combat",      
            callback: () => {        
                tokenDocument.update({
                    "texture.src": "myImages/token/combat.png"
                });      
            },    
        },    
        tavern: {      
            icon: "<i class='fas fa-beer'></i>",      
            label: "Tavern",      
            callback: () => {        
                tokenDocument.update({
                    "texture.src": "myImages/token/tavern.png"
                });      
            },    
        },    
        dead: {      
            icon: "<i class='fas fa-skull'></i>",      
            label: "Dead",      
            callback: () => {        
                tokenDocument.update({
                    "texture.src": "myImages/token/dead.png"
                });      
            },    
        },  
    },
}); 
myDialog.render(true);
```

# 实践：创建快速掷骰对话框

作为第二个示例，我们来创建一个让用户快速掷骰子的对话框。关于掷骰的更多信息，请查阅掷骰页面。

```JavaScript
const myDialog = new Dialog({  
    title: "Roll a die",  
    content: `Choose a die to roll`,  
    buttons: {    
        d4: {      
            icon: "<i class='fas fa-dice-d4'></i>",      
            label: "D4",      
            callback: async () => {        
                const roll = new Roll("1d4");        
                await roll.evaluate();        
                roll.toMessage();      
            },    
        },    
        d6: {      
            icon: "<i class='fas fa-dice-d6'></i>",      
            label: "D6",      
            callback: async () => {        
                const roll = new Roll("1d6");        
                await roll.evaluate();        
                roll.toMessage();      
            },    
        },  
    },
}); 
myDialog.render(true);
```

让我们通过使用数组、循环和对象，使其更加紧凑和复杂。

```JavaScript
const rolls = ["4", "6", "8", "10", "12", "20"]; // 我们希望快速投掷的骰子面数
const buttons = {}; // 创建一个空对象存储按钮
for (const die of rolls) { // 迭代骰子列表的所有选项
    buttons[die] = { // 使用语法object[key] = value为buttons对象分配一个新按钮
        icon: `<i class='fas fa-dice-d${die}'></i>`, // 使用字符串字面量来创建图标
        label: "D" + die, // 使用 + 运算符组合字符串
        callback: async () => {      
            const roll = new Roll(`1d${die}`);      
            await roll.evaluate();      
            roll.toMessage();    
        },  
    };
} 

const myDialog = new Dialog({  
    title: "Roll a die",  
    content: `Choose a die to roll`,  
    buttons,
}); 
myDialog.render(true);
```

# JavaScript 字符串字面量

（译者注：可以参考[菜鸟教程-JavaScript-字符串模板](https://www.runoob.com/js/js-string-templates.html)）

字符串字面量是 JavaScript 中创建字符串的一种方式，其中字符串的某些部分会被变量替换。

要定义字符串字面量，请使用反引号（\`）而非单引号或双引号。

**示例：**

```JavaScript
const myString = `This is a string literal`;
const myOtherString = "This is a regular string";
```

当字符串被反引号包裹时，您可以使用 `${variable}` 语法将变量插入字符串中。

**示例：**

```JavaScript
const myVariable = "Hello World";
const myString = `This is a string literal with a variable: ${myVariable}`;
console.log(myString); // 这会打印"This is a string literal with a variable: Hello World"
```
