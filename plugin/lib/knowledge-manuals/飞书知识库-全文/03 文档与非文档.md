# 文档与非文档

在 FVTT中，理解文件与非文档的概念至关重要。通常，文档是永久存储在游戏世界中的数据结构，而页面重新加载时其他所有内容都会丢失。

---

# 实际操作

在上一篇文章中，我们讨论了作为宏参数，可访问`actor` 对象和 `token` 对象。

- **actor** 是文档
- **token** 是可放置的（非文档）;他们的文档是 TokenDocument。

需要说明的是，当你在宏中访问`token`时，你访问的是场景中的令牌的视觉表现（译者注：不太理解视觉表现是什么意思，但是原文如此，大概只是说访问的token的数据不是持久化数据吧），而不是存储在 TokenDocument 中的实际数据。

要访问指示物的数据，你需要使用 `token.document` 属性来访问 TokenDocument。

示例（将指示物文档记录到控制台）：

```JavaScript
console.log(token.document);
```

# 与文档的互动

如前所述，文档是存储在游戏世界数据库中的数据。改变文档数据会反映在游戏界面里（译者注：即Client端），但不会影响游戏世界数据库（译者注：即服务器端或者GM端）。

## JavaScript 中的赋值

（译者注：可以参考[菜鸟教程-JavaScript变量](https://www.runoob.com/js/js-variables.html)）

在 JavaScript 中，你可以用 `=` 作符为变量赋值。例如：

```JavaScript
let name = "John";
```

变量是存储在内存中以便以后参考的数据。例如：

```JavaScript
let name = "John";
console.log(name);
```

这段代码的输出将是`John`。

JavaScript 中有两种变量：`let` 和 `const`。`let` 关键字声明一个可以重新分配的变量，而` const` 关键字声明一个无法重新分配的变量。（译者注：这里的重新分配指的是`v = "xxx";`这种重新分配，而不是对部分的修改，比如`v.doc = "xxx"`）

```JavaScript
let name = "John";name = "Jane";console.log(name);
```

这段代码的输出将会是 `Jane`.

```JavaScript
const name = "John";name = "Jane";console.log(name);
```

该代码的输出将是错误，因为`name`变量无法重新分配。

## 为文档分配值

虽然你可以在 JavaScript 中为变量赋值，但这种方法对文档不适用。给文档分配值不会改变游戏世界中存储的数据;它只会为你的客户端更改，直到你刷新页面。（译者注：这里要注意区分游戏世界和客户端的数据）

示例（更改令牌名称）：

```JavaScript
token.document.name = "Jane";
```

这行不通，因为游戏世界中代币名称不会改变。

### 更新文档

正确的更新文档方式是使用`update`方法。该方法将一个对象作为参数，并用该对象的值更新文档。

示例（更新令牌名称）：

```JavaScript
token.document.update({ name: "Jane" });
```

这会更新所有用户在游戏世界中的代币名称。

你可以通过传递一个拥有多个属性的对象来同时更新多个属性。

示例（更新令牌名称和大小）：

```JavaScript
token.document.update({  name: "Jane",  width: 2,  height: 2,});
```

### 异步操作

当文档更新时，数据需要通过网络传输到服务器，再返回客户端。因此，游戏世界中的数据不会立即更新。

让我们看看一个异步作的例子：

```JavaScript
console.log(token.document.name); // Output: John
token.document.update({ name: "Jane" });
console.log(token.document.name); // Output: John
```

即使我们更新了标记的名称，游戏世界中的名字仍然是 `John`，因为数据不会立即更新。

等待更新完成后再记录名称，我们会得到正确的输出：

```JavaScript
await token.document.update({ name: "Jane" });
console.log(token.document.name); // Output: Jane
```

`await`关键字用于等待更新完成后再继续运行代码。

请记住，任何与游戏世界数据库交互的动作都是异步的，所以如果你需要与更新后的数据交互，就需要用 `await` 来等待作完成。

## 示例：更改指示物的图像

比如说，我们想改变一个指示物的形象，比如它是一个变形者。

```JavaScript
token.document.update({ "texture.src": "my/new/image.webp" });
```

这会为所有用户改变所选标记在游戏世界中的图像。

# 高级：IF 语句

假设我们想让宏基于当前图片在两张图片之间切换。我们可以利用目前学到的内容和 IF 语句来实现这一点。

```JavaScript
const currentImage = token.document.texture.src;
const humanForm = "assets/images/human.webp";
const shapeshifterForm = "assets/images/shapeshifter.webp"; 
if (currentImage === humanForm) {  
    token.document.update({ "texture.src": shapeshifterForm });
} else {  
    token.document.update({ "texture.src": humanForm });
}
```

这会根据当前图像改变所选标记的图像。

## JavaScript 中的 IF 语句

（译者注：可以参考[菜鸟教程-JavaScript条件语句](https://www.runoob.com/js/js-if-else.html)）

在 JavaScript 中，IF 语句用于执行代码块如果IF条件为真。IF 语句的基本语法如下：

```JavaScript
if (condition) {  // code to execute if the condition is true}
```

以下是 JavaScript 中 IF 语句的一个示例：

```JavaScript
let age = 25; 
if (age >= 18) {  
    console.log("You are an adult");
}
```

如果IF条件为假，`else` 关键字可用于执行另一个代码块：

```JavaScript
let age = 15; 
if (age >= 18) {  
        console.log("You are an adult");
} else {  
        console.log("You are a minor");
}
```
