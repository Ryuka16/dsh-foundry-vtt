# 屏幕正中间动画宏

**高低版本通用，需要sequencer版本最低3.3.0。**

屏幕正中间播放相应动画，覆盖全部窗口，图片，测量版，图块，前后背景层等，自动为所有在线玩家播放。可以与诸如重击效果进行关联实现重击自动播放动画。

![图片展示的是屏幕正中间播放的动画效果，覆盖全部窗口、图片、测量版、图块、前后背景层等，自动为所有在线玩家播放。画面中以古风背景为底，中间有“GREAT ENEMY FELLED”字样，字体为金色，两侧有黑色装饰边框。该动画可与重击效果关联，实现重击自动播放。播放的文件需为webm或mp4格式，且带有alpha通道，否则会带背景糊脸。](https://feishu.cn/file/J0Zjb6oq3oiKckxkvpOcs1D8n9e)

播放的文件可以是webm或mp4格式，视频或图片必须带有alpha通道，否则将会带着背景糊脸。

```JavaScript
// ===== 安全检查 =====
if (!game.modules.get("sequencer")?.active) {
    ui.notifications.error("Sequencer 模块未启用！请先安装并启用该模块。");
    return;
}

// ===== 配置参数 =====
const config = {
    animationPath: "systems/你的视频文件名称.webm",
    soundPath: "systems/你的声音文件名称（可以与上述一致）.webm",
    opacity: 0.9,
    fadeTime: 500,
    speed: 1.0,
    scale: 1.5,
    duration: 3000,
    volume: 0.9,
    effectName: "ScreenMaskEffect",
    verticalPosition: 0.5 // 添加垂直位置配置 (0-1)
};

// ===== 辅助函数 =====
async function getMediaSize(path) {
    return new Promise((resolve, reject) => {
        const video = document.createElement('video');
        video.src = path;
        video.onloadedmetadata = () => {
            resolve({ w: video.videoWidth, h: video.videoHeight });
        };
        video.onerror = reject;
    });
}

function chainCall(obj, method, ...args) {
    return obj[method](...args);
}

// ===== 主执行函数 =====
(async () => {
    try {
        // 创建 Sequencer 序列
        const sequence = new Sequence();
        
        // 创建屏幕空间位置对象
        const screenPosition = {
            x: window.innerWidth / 2,
            y: window.innerHeight * config.verticalPosition
        };
        
        // 获取媒体尺寸
        const { w, h } = await getMediaSize(config.animationPath);
        
        // 计算屏幕尺寸
        const screenW = window.innerWidth;
        const screenH = window.innerHeight;
        
        // 计算覆盖屏幕的尺寸
        let outW, outH;
        if (w > 0 && h > 0) {
            const arMedia = w / h;
            const arScreen = screenW / screenH;
            
            if (arMedia < arScreen) {
                outW = screenW;
                outH = screenW / arMedia;
            } else {
                outH = screenH;
                outW = screenH * arMedia;
            }
        } else {
            outW = screenW;
            outH = screenH;
        }
        
        // 添加视觉效果
        let effect = sequence.effect()
            .file(config.animationPath)
            .screenSpace()
            .atLocation(screenPosition)
            .anchor({ x: 0.5, y: 0.5 })
            .size({ width: outW, height: outH })
            .opacity(config.opacity)
            .name(config.effectName)
            .playbackRate(config.speed)
            .duration(config.duration)
            .fadeIn(config.fadeTime)
            .fadeOut(config.fadeTime);
        
        // 添加音效
        sequence.sound(config.soundPath)
            .volume(config.volume);
        
        // 播放序列
        await sequence.play();
        
        // 计算位置描述
        let positionText = "";
        if (config.verticalPosition <= 0.2) positionText = "顶部";
        else if (config.verticalPosition >= 0.8) positionText = "底部";
        else positionText = "中部";
        
        // 计算时间描述
        const durationSeconds = config.duration / 1000;
        const durationText = `${durationSeconds}秒`;
        
        ui.notifications.info(
            `屏幕遮罩动画与音效已激活！\n位置: ${positionText} | 音量: ${config.volume*100}% | 持续时间: ${durationText}`
        );
        
        // 调试信息
        console.log(`动画位置: x=${screenPosition.x}, y=${screenPosition.y}`);
        console.log(`屏幕尺寸: ${screenW}x${screenH}`);
        console.log(`媒体尺寸: ${w}x${h}`);
        console.log(`计算尺寸: ${outW}x${outH}`);
        console.log(`音效音量: ${config.volume*100}%`);
        
    } catch (err) {
        console.error("Sequencer 错误:", err);
        ui.notifications.error(`屏幕遮罩失败: ${err.message}`);
    }
})();
```
