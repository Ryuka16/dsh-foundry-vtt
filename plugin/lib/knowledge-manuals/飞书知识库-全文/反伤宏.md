# 反伤宏

**FVTT版本V12,DND3.X系统已验证。高版本可能需要自行调整api。**

在触发后自动反伤宏，需要将宏触发条件设置为IsHit。



```JavaScript
if (args[0].macroPass === "isHit") {
    if (workflow.item.system.actionType === "mwak" || workflow.item.system.actionType === "msak") {
        let measuredDistance = MidiQOL.computeDistance(token, workflow.token, { wallsBlock: true, includeCover: true });
        let range = game.gps.convertFromFeet({ range: 5 });
        if (measuredDistance > range) return;
        
        const damageDice = "1d8"; // 可修改伤害骰子
        const damageType = "piercing"; // 可修改伤害类型

        // 创建伤害掷骰
        let damageRoll = await new CONFIG.Dice.DamageRoll(`${damageDice}[${damageType}]`).evaluate();
        
        const itemData = {
            name: "反伤",
            type: "feat",
            img: "icons/magic/defensive/shield-barrier-flaming-diamond-purple-orange.webp" // 可修改图标
        };

        // 使用 DamageOnlyWorkflow 并设置工作流类型为 "other"
        await new MidiQOL.DamageOnlyWorkflow(
            actor, 
            token, 
            damageRoll.total, 
            damageType, 
            [workflow.token], 
            damageRoll, 
            {
                flavor: "反伤伤害",
                itemData: itemData,
                useOther: true, // 关键：设置为使用"other"类型
                workflowOptions: {
                    autoRollDamage: "always", // 自动掷伤害
                    rollDamage: "always" // 总是掷伤害
                }
            }
        );
    }
}
```
