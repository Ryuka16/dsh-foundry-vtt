# 筛选器

过滤器系统在系统中多处使用，用于根据提供的数据定义并求值条件。最常用于主动效果条件。在执行合集浏览器中的筛选时，系统内部也会使用它。



```JSON
{
  "o": "OR",
  "v": [
    {
      "k": "item.type.value",
      "v": "ranged"
    },
    {
      "k": "item.properties",
      "o": "has",
      "v": "thr"
    }
  ]
}
```



## **运算符与比较**



过滤器中的 `o` 属性控制单个过滤器如何求值。它分为两类：比较函数和运算符函数。如果过滤器未提供运算符，则使用 `exact` 比较函数。



### **比较函数**



比较函数决定如何将给定键路径处的数据（由 `k` 指定）与值数据（由 `v` 指定）进行比较，以判断它们是否匹配。可以通过它们全部由小写字母书写来识别。



最常见的运算符是 `exact`，仅当两个值完全相同时才有效（包括字母大小写）。如果未提供其他运算符，则使用该比较。



另一个有用的比较是 `in`，它的行为类似 `exact`，但接受一个值数组。这样可以轻松地同时检查多个值（例如，在检查 `"k": "item.type.value"` 时提供 `"v": ["simpleM", "simpleR"]`，可以同时识别近战简易武器和远程简易武器）。



如果要检查的基础值恰好有多个值，可以使用 \`has\` 比较来查看是否有任一数据与提供的值匹配（例如，使用 \`"v": "mgc"\` 检查 \`"k": "item.properties"\`，可以识别该物品是否具有魔法属性）。\`hasany\` 和 \`hasall\` 比较的行为相同，但与 \`in\` 类似，接受多个值（例如，使用 \`"v": ["fin", "lgt"]\` 检查 \`"k": "item.properties"\`，如果武器具有灵巧或轻型属性，则 \`hasany\` 有效；但只有武器*同时*具有灵巧和轻型属性时，\`hasall\` 才有效）。



| 函数 | 接受的值 | 说明 |
|-|-|-|
| exact | 任意 | 两个值完全匹配。 |
| contains | 文本 | 基础值包含精确的所提供值。 |
| icontains | 文本 | 基础值包含所提供值，忽略大小写。 |
| startswith | 文本 | 基础值以精确的所提供值开头。 |
| istartswith | 文本 | 基础值以所提供值开头，忽略大小写。 |
| endswith | 文本 | 基础值以精确的所提供值结尾。 |
| iendswith | 文本 | 基础值以所提供值结尾，忽略大小写。 |
| has | 任意或过滤器 | 基础值中的一个条目与所提供值精确匹配。如果提供的值是过滤器，则会针对每个条目求值。 |
| hasany | 数组或过滤器 | 基础值中的条目与任一提供的值匹配。 |
| hasall | 数组或过滤器 | 基础值中的条目与所有提供的值匹配。 |
| in | 数组 | 基础值与提供的值之一精确匹配。 |
| gt | 数字 | 基础值大于提供的值。 |
| gte | 数字 | 基础值大于或等于提供的值。 |
| lt | 数字 | 基础值小于提供的值。 |
| lte | 数字 | 基础值小于或等于提供的值。 |



### **运算符函数**



运算符函数会组合一个或多个过滤器的结果，或者修改单个过滤器的结果。这些过滤器不接受键路径（没有 `k`），其值（由 `v` 指定）可以是单个过滤器（用于 `NOT` 运算符），也可以是过滤器数组（用于所有其他运算符）。



最常见的两个运算符是 `AND`（当所有提供的过滤器都有效时有效）和 `OR`（只要有任意一个提供的过滤器有效时有效）。



`NOT` 运算符也可用于反转所提供过滤器的结果。



| 函数 | 接受的值 | 说明 |
|-|-|-|
| AND | 过滤器数组 | 所有提供的过滤器都有效时有效。 |
| NAND | 过滤器数组 | 任一提供的过滤器无效时有效。 |
| OR | 过滤器数组 | 任一提供的过滤器有效时有效。 |
| NOR | 过滤器数组 | 所有提供的过滤器都无效时有效。 |
| XOR | 过滤器数组 | 仅当只有一个提供的过滤器有效时有效。 |
| NOT | 单个过滤器 | 提供的过滤器无效时有效。 |



## **键路径**



过滤器中的 `k` 属性用于指向要比较的特定数据。由于求值时提供的基础数据很可能是掷骰数据，因此可以用<cite doc-id="PxmxwHtBniay5LkIH7nce8LunGh" file-type="wiki" title="掷骰数据" type="doc"></cite>作为该属性可接受值的参考。



## **值**



`v` 属性是用于比较的值。这里应提供什么取决于所使用的函数（请参阅上文“运算符与比较”部分）。



| 类型 | 示例 |
|-|-|
| 文本 | `"v": "str"` |
| 数字 | `"v": 15` |
| 数组 | `"v": ["simpleM", "simpleR"]` |
| 过滤器 | `"v": { "k": "…", "v": "…" }` |



## **示例**



### **仅在浴血时**



仅当角色处于浴血状态时，效果才会应用：



```JSON
{
  "k": "statuses.bloodied",
  "v": 1
}
```



### **仅远程或投掷武器**



在附魔中使用时，这会应用于任何远程武器，或具有投掷属性的武器：



```JSON
{
  "o": "OR",
  "v": [
    {
      "k": "item.type.value",
      "o": "in",
      "v": ["simpleR", "martialR"]
    },
    {
      "k": "item.properties",
      "o": "has",
      "v": "thr"
    }
  ]
}
```
