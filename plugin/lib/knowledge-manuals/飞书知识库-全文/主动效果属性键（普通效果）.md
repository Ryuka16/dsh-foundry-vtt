<title>主动效果属性键（普通效果）</title>

本文档仅涵盖核心 dnd5e 系统可用的主动效果。

# **图例**

`[number]` - 这些方括号表示“请替换为括号内类型的值”。因此这个示例：\`[number]\` 意味着你应输入 \`3\`。如果允许使用掷骰数据，你可以输入任何会*求值*为数字的掷骰数据（不允许使用骰子）。

`[formula]` - 当本文档提到 `formula` 时，表示该值可以填入任意骰子公式。例如，祝福术会添加多个效果值为 `1d4` 的效果。这些字段始终允许使用掷骰数据。

有关可用作掷骰数据的内容，请参阅[角色的掷骰数据](https://github.com/foundryvtt/dnd5e/wiki/Roll-Formulas)文章。

实用示例：

| @attribute | 说明 |
|-|-|
| `@abilities.dex.mod` | 角色的敏捷调整值 |
| `@prof` | 角色的熟练加值 |
| `@details.level` | 角色的总等级 |
| `@details.cr` | 角色的挑战等级 |
| `@classes.barbarian.levels` | 角色的野蛮人职业等级 |

> [!Note]
> 
> 在主动效果值中使用公式时，角色卡上对应被改变值的显示区域不一定会显示求值后的公式，但在掷骰时该公式会被应用。
> 
> 例如，将 `@abilities.cha.mod` 添加到 `system.bonuses.abilities.save` 以模拟圣武士的“守护灵光”时，角色卡不会显示该加值已应用于豁免检定。但在进行豁免检定时，该加值会生效。



| 变更类型 | 说明 |
|-|-|
| Add（添加） | 将提供的值添加到指定属性。对于数值属性，可以通过将添加值指定为 `1` 或 `-1`，来对某个值进行增加或减少。对于物品属性或角色伤害抗性这类集合，可以用来添加或移除条目（例如，`mgc` 添加魔法属性，`-mgc` 移除该属性）。 |
| Subtract（减去） | V14 或更高版本。 从指定属性中减去提供的值。对于物品属性或角色伤害抗性这类集合，可以用来移除条目。 |
| Multiply（乘以） | 将定义的属性值乘以效果值字段中的数值。 |
| Override（覆盖） | 将定义的属性替换为效果值字段中提供的值。如果应用于名称或描述等文本值，可以使用一对花括号 `{}` 在最终输出中包含被覆盖的值。因此，将名称“胸甲”覆盖为 `Arcane Propulsive {}` 会得到最终名称“Arcane Propulsive 胸甲”。 |
| Downgrade（下调） | 仅当该属性的当前值大于效果值字段中指定的值时，才降低该定义的属性。 |
| Upgrade（上调） | 仅当该属性的当前值小于效果值字段中指定的值时，才提高该定义的属性。 |
| Custom（自定义） | 自定义变更类型会应用由游戏系统或附加模块定义的逻辑。dnd5e 系统不使用自定义变更类型 |

## **修改掷骰模式**

系统中的许多位置允许设置掷骰的优势模式，例如 `system.dex.check.roll.mode` 或 `system.rolls.attack.mwak.mode`。在这些情况下，变更类型和值会进行一些特殊处理。

### **变更值**

- `0`：正常
- `1`：优势
- `-1`：劣势

### **变更类型**

- `Add`：添加一层优势（`1`）或劣势（`-1`）
- `Subtract`：移除一层优势或劣势（`-1`）
- `Override`：强制该掷骰具有优势（`1`）、劣势（`-1`）或正常（`0`）
- `Upgrade` 且值为 `0`：阻止该掷骰获得劣势（但仍可获得优势）
- `Downgrade` 且值为 `0`：阻止该掷骰获得优势（但仍可获得劣势）

## **负重**



```Plain Text
system.attributes.encumbrance.multipliers.encumbered
                                         .heavilyEncumbered
                                         .maximum
                                         .overall
                             .bonuses.encumbered
                                     .heavilyEncumbered
                                     .maximum
                                     .overall
```



乘数会将默认负重值乘以相应倍数，加值则会在默认值上增加固定数值。`encumbered`、`heavilyEncumbered` 和 `maximum` 的值分别适用于三个负重阈值，而 `overall` 会同时平等地作用于这三个阈值。这些值都接受数字，并允许使用掷骰数据。

### **指定伤害类型**



可以在骰子公式后的方括号中为加值伤害指定伤害类型。例如，要为近战武器攻击添加 1d8 光耀伤害：



| 属性键 | 变更类型 | 效果值 | 掷骰数据？ |
|-|-|-|-|
| `system.rolls.damage.mwak.bonus` | Add | `1d8[radiant]` | 是 |



这适用于任意伤害类型以及任意攻击伤害加值（mwak、rwak、msak、rsak）。伤害类型需要使用英文并全部小写。示例：

- `1d6[fire]` - 1d6 火焰伤害
- `2d4[cold]` - 2d4 冷冻伤害
