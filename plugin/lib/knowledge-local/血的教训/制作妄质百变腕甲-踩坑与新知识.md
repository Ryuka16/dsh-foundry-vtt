# 妄质百变腕甲 · 踩坑与新知识（本轮汇总，供并入知识库）

> 背景：本轮做「妄质百变腕甲」拉霸物品的全量自动化（玩家法师用，自身本地 + 对敌走 midi）。
> 标注规则：**【坐实】**= 从真实样本/探针验证；**【标准·待实测】**= DAE/midi 通行写法但未在本项目样本中坐实，建议进游戏确认。

---

## 一、本轮新踩的坑（写之前对照）

1. **`completeActivityUse` 会递归触发物品宏。**
   用 `MidiQOL.completeActivityUse(隐藏活动)` 触发本物品自己的活动时，会再次激发**物品级** `flags.midi-qol.onUseMacroName`（`[postActiveEffects]ItemMacro`）→ 整个宏重跑 → 面板被重开、还能再投、子活动又投一次豁免。
   **修法**：宏顶部加守卫——
   ```js
   try{ const an=(typeof workflow!=="undefined"&&workflow?.activity?.name)?workflow.activity.name:""; if(an && !an.includes("拉杆")) return; }catch(e){}
   if(globalThis.__pvPanelOpen){ return; }
   ```
   非主活动（子活动重跑）直接 `return`；伤害/豁免仍由 midi 自己的工作流正常结算（宏只是个 hook，提前 return 不影响 midi 结算）。面板关闭时复位 `globalThis.__pvPanelOpen=false`。

2. **DialogV2 自动关闭要与伤害结算解耦。**
   若 `await completeActivityUse` 之后再关面板，面板会卡到伤害全部结算完才关。正解：**出结果后立刻 `setTimeout` 安排关闭**（普通 3.4s / 大奖 5.2s），与 completeActivityUse 并行；点结果卡也立即关。

3. **DialogV2(v13) 会清洗 content 里的 `<style>`/`<svg>`。**
   content 只放 `<div class="pv-mount"></div>`，渲染后用 JS `innerHTML` 注入面板 HTML（保住 SVG），CSS 用 `document.createElement('style')` 塞进 `document.head`（关闭时按 id 移除）。

4. **纯 changes、无 status 的效应默认不在 token 上显图标。**
   修法：`flags.dae.showIcon:true` + **临时** `duration` + 专属 `img`。带 status 的（prone/blinded/incapacitated…）会自动显状态图标，不必额外设。

5. **效应的 `flags.dae` 必须写全套，不能只写三件。**
   照官方样本（恶言相加）补齐：`disableIncapacitated / selfTarget / selfTargetAlways / dontApply / stackable / showIcon / durationExpression / macroRepeat / specialDuration`。少写 `macroRepeat` 等会显得未配置。

6. **单体目标"打到自己 / 不出骰"。**
   根因：宏里预设了错目标（如想锁最近敌却把自身设成 target），或活动 `affects.choice:false` 且无目标时 completeActivityUse 落到自身。
   **正解照"火把"**：单体活动目标设 `affects:{ type:"creature", count:"1", choice:true }`，让**活动自身弹"选择目标"**；宏**不要**预设目标。（`choice:true` = UI 里"选择目标"勾上。）

7. **活动写了 `range` 不等于会拦超距。**
   超出 `range` 仍能选中——需开 **midi-qol → Workflow → Check Range = `center to center`**（世界设置，物品无法强制）。

8. **轮(round) ≠ 回合(turn)。**
   `duration.rounds:N` 是**轮制**，会把"到你/它下回合结束"拖长一轮（轮1放、轮3才解除）。正解用 DAE **特殊时长**（见下"新知识"§4）。

9. **`MidiQOL.midiFlags` 元素是对象不是字符串。**
   形如 `{name:"flags.midi-qol.disadvantage.attack.all"}`，共 ~1818 条。探针里要 `JSON.stringify(x)` 或取 `x.name` 再匹配，否则 `String(对象)` = `[object Object]` 全落空。

10. **"伤害最大化 / 额外动作 / 瞬移 / 触及+尺 / 解除指定状态 / 复现戏法"无可信自动键。**
    不要乱挂——卡面用官方口吻写清，元信息标"由 DM 手动判定"。文案要 5E 官方化（去掉"恶作剧/打嗝"这类口语，免得 PL 钻空子）。

11. **临时生命别用 AE 写 `hp.temp`。** 用 `actor.applyTempHP(n)`（dnd5e 方法，取高不叠加）。

## 二、本轮坐实/采用的新知识

### 1. 隐藏活动 + `completeActivityUse` 派发模式（对敌/AoE 自动化）
- 物品上放若干 `automationOnly:true` 的隐藏活动（save / damage / utility），宏按**名称**找到并 `await MidiQOL.completeActivityUse(act,{},{},{})`。
- AoE（`template.type:"sphere"` + `affects.type:"enemy"`）→ midi 弹放置模板、自动锁模板下敌人、结算豁免与伤害。
- 单体/多目标（`affects.type:"creature"` + `choice:true` + `count`）→ midi 弹"选择目标"。
- 配合 §一.1 的递归守卫使用。

### 2. save 活动结构 + 活动↔效果引用【坐实：坠星祈唤者 / 恶言相加】
```jsonc
"type":"save",
"save":{"ability":["dex"],"dc":{"calculation":"spellcasting","formula":""}},   // 跟持有者法术DC
"damage":{"onSave":"half"/"none"/"full","parts":[{number,denomination,bonus:"",types:["fire"],custom:{enabled:false},scaling:{number:1}}],"critical":{"allow":false}},
"target":{"affects":{count,type:"enemy"/"creature",choice},"template":{type:"sphere",size,units:"ft"},"prompt":true},
"effects":[{"_id":"<itemEffectId>","onSave":false,"level":{"min":null,"max":null}}]   // onSave:false = 豁免失败才施加
```

### 3. midi 优势/劣势 flag 全树【坐实：midiFlags 探针 + 恶言相加】
- 自身：`flags.midi-qol.advantage|disadvantage.attack.{all,mwak,rwak,msak,rsak,heal,other,save,util,school.<key>}`
- 自身豁免：`flags.midi-qol.advantage|disadvantage.save.{all,str,dex,con,int,wis,cha}` —— **是 `disadvantage.save`，不是 `disadvantage.ability.save`**
- 授予方向（针对该 token 的攻击/豁免）：`flags.midi-qol.grants.(no)?(dis)?advantage.attack|save.*`
- 取消：`noAdvantage` / `noDisadvantage` 同结构。
- **change 用 `mode:2`（ADD），value `"1"`**（恶言相加即如此）。

### 4. DAE 特殊时长 `specialDuration`（解决"一次性 / 回合制"）
- **`1Attack`**【坐实：恶言相加】——攻击一次后失效（"下一次攻击"类）。
- **`isSave`**【标准·待实测】——豁免一次后失效（"下一次豁免"类）。
- **`1Spell`**【标准·待实测】——施法一次后失效（"下一个戏法/法术"类）。
- **`turnEnd`**【标准·待实测】——到**持有者**下一回合结束失效（"到它下回合结束"）。
- **`turnEndSource`**【标准·待实测】——到**来源(施法者)**下一回合结束失效（"到你下回合结束"）。
- 用法：`flags.dae.specialDuration:["1Attack"]`，并保留 `duration.rounds` 作兜底（万一 token 无效不至于变永久）。

### 5. midi 原生位移（击退/拉近）—— **不依赖世界脚本(YGM)**【坐实：字典 §799/800】
- `MidiQOL.moveTokenAwayFromPoint(tokenRef, distFt, point, animate=true, checkCollision=false)` —— 背离某点推开；玩家端可用，midi 自己走 socket。
- `MidiQOL.moveToken(tokenRef, newCenter, animate=true)` —— 移到中心点。
- 爆心：AoE 取 `wf.template.x/y`；单体取施法者 token `.center`。
- 失败者：`wf.failedSaves`（Set，元素是 Token）。
- **补充修正旧坑文件**：对敌操作不一定都要 YGM——midi 的活动效果(`activity.effects`)和上述位移 API 会自动以 GM 权限执行；YGM 仍用于 midi 覆盖不到的场景操作（删场景文档、复杂连招）。

### 6. 自身数值 AE change 键【坐实】
- 法术伤害 += `system.bonuses.spell.damage`（mode2，`"2d6[fire]"` 可带类型）
- 法术 DC += `system.bonuses.spell.dc`（mode2）
- 法术攻击 += `system.bonuses.msak.attack` + `system.bonuses.rsak.attack`（mode2）
- 全局豁免 += `system.bonuses.abilities.save`（mode2，可负）
- 抗性：`system.traits.dr.value`（**mode2 ADD**，value 填伤害类型字符串如 `"fire"`/`"force"` 追加）【标准·待实测数组加值】
- 全速加值：`system.attributes.movement.bonus`（mode2，作用步行/攀爬/飞行/游泳全部）；单 `movement.walk` 只改步行；减半用 `movement.walk` **mode1(乘)** `"0.5"`
- AC += `system.attributes.ac.bonus`（mode2）

### 7. ATL 灯光（临时灯光 AE）【坐实：探针 token.light 字段 + ATL 模块已装】
- `token.light` 字段：`negative, priority, alpha, angle, bright, color, coloration, dim, attenuation, luminosity, saturation, contrast, shadows, animation, darkness`。
- AE change 键：`ATL.light.dim`/`.bright`/`.color`/`.alpha`/`.animation`（animation 填 JSON 串 `{"type":"pulse","speed":2,"intensity":2}`），**mode 5(override)**，配临时 duration 实现"亮一回合后熄灭"。需装 `ATL` 模块。

### 8. 其它【坐实】
- 临时生命：`actor.applyTempHP(n)`（取高不叠加）。
- 伤害/治疗：`actor.applyDamage([{value, type:"fire"}])`；`type:"healing"` = 治疗。
- 最近敌：`MidiQOL.findNearby(-1, token, distFt, {includeIncapacitated:false})`（-1 = 敌对，相对）。
- 状态 id：`prone / blinded / incapacitated / restrained / frightened / grappled / stunned / poisoned / silenced …`（§1）。
- 效应图标字段是 **`img`**（非 `icon`）。
- 每轮一次冷却：物品 `uses.max:"1"` + `recovery:[{period:"turnStart",type:"recoverAll"}]`，主活动 `consumption.targets:[{type:"itemUses",value:"1"}]`。
- 校验宏语法用 **AsyncFunction 构造器**（匹配 FVTT 异步执行环境），别用 `node --check`（会误报顶层 await）。

## 三、本轮用到的参考样本（来源 → 用途）
- **恶言相加 Vicious Mockery** → `specialDuration:["1Attack"]`「一次攻击劣势」+ 完整 dae flags 块 + 劣势 change `mode:2`。
- **火把 Torch** → 单体目标正确配置：`affects{type:creature,count:1,choice:true}` 让活动弹"选择目标"。
- **希瓦 Shiva** → 灯光参数（dim/color/animation 脉冲），灯光设在 `prototypeToken.light`（静态）；本物品改用 ATL AE 做临时灯光。
- **坠星祈唤者** → save 活动完整结构、`midiProperties` 全字段、`affects.type:"enemy"` 模板自动锁敌。
- **奥能科技拳套** → 击退几何（单位向量×格数、遇占用停）；但其执行走 YGM，本物品改用 midi 原生 `moveTokenAwayFromPoint`。
