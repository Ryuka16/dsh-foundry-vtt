### 这个库有 **3 层** flags，都在文档对象上（不在 `system` 里）

| 层 | 位置 | 谁的 | 典型载体 |
|---|---|---|---|
| **顶层** | `doc.flags.<模块>` | 物品/角色文档本身 | `midi-qol` `dnd5e` `chris-premades` `region-attacher` |
| **效果层** | `doc.effects[i].flags.<模块>` | 每一条 ActiveEffect 各有一份 | `dae` `ActiveAuras` `times-up` |
| **活动层** | `doc.system.activities.<key>.flags.<模块>` | 每个 activity 各有一份 | `autoanimations` `region-attacher` `dae` `dnd5e` |

> ⚠️ **三层是互相独立的 flags 空间** —— 同一个包里顶层用 `midi-qol`、效果层用 `dae`、活动层用 `autoanimations`，三者可以完全不同。
> **只扫两层就会漏**（本项目就漏过整层活动层，导致 `region-attacher` 这一整类自动化 5 件法术完全没被发现）。

## 4 · 怎么查（可直接抄）

### 4.1 一次拿全整个库的族（世界宏，不走 relay，不受 35 秒限制）

```js
const C = game.__census = { 族:{}, 已扫:{}, 文档数:0, 包数:0, 完成:false, 错包:[] };
const 记 = (key, 包, id, 名) => {
  let r = C.族[key];
  if (!r) r = C.族[key] = { 键:new Set(), 例:[] };
  r.键.add(包 + '\u0001' + id);
  if (r.例.length < 3) { const s = 包 + ' | ' + 名; if (r.例.indexOf(s) < 0) r.例.push(s); }
};
/* ★ 只扫第一层，绝不递归（递归会把路径数当成件数） */
const 扫族 = (f, 前缀, 包, id, 名) => {
  if (!f || typeof f !== 'object') return;
  for (const k of Object.keys(f)) 记(前缀 + '.' + k, 包, id, 名);
};
const 列表 = game.packs.contents.filter(p => p.documentName === 'Item' || p.documentName === 'Actor');
for (const p of 列表) {
  let docs;
  try { docs = await p.getDocuments(); } catch (e) { C.错包.push(p.collection); continue; }
  const 处理 = (o) => {
    const 名 = o.name || ''; const id = o.id || o._id;
    扫族(o.flags, 'flags', p.collection, id, 名);
    for (const ef of (o.effects || [])) 扫族(ef.flags, 'eff.flags', p.collection, id, 名 + ' > ' + (ef.name || ''));
    const obj = o.toObject ? o.toObject() : o;
    for (const a of Object.values(obj.system?.activities || {})) 扫族(a.flags, 'act.flags', p.collection, id, 名 + ' > ' + (a.name || ''));
    for (const it of (o.items || [])) 处理(it);   // 内嵌物品（Actor 身上的）
  };
  for (const d of docs) 处理(d);
  C.包数++; C.文档数 += docs.length;
  if (C.包数 % 3 === 0) await new Promise(r => setTimeout(r, 20));   // 让出主线程
}
C.完成 = true;
return JSON.stringify({ 包数:C.包数, 文档数:C.文档数, 族数:Object.keys(C.族).length, 错包:C.错包 });
```

### 4.2 读某一个族的实际取值

```js
// 例：查 region-attacher 在 classpack 里到底挂了什么
const pk = game.packs.get('dnd5e_classpack.spell');
const docs = await pk.getDocuments();
const out = [];
for (const d of docs) {
  const o = d.toObject();
  for (const a of Object.values(o.system.activities || {})) {
    if (a.flags && a.flags['region-attacher']) out.push({ 物品:o.name, 活动:a.name, 值:a.flags['region-attacher'] });
  }
}
return JSON.stringify(out);
```

### 4.3 五条读法铁律（踩过的坑）

1. **族 = 第一层键，只扫一层**。递归会把 `flags.midiProperties` 的 29 个子键记 30 次，得出「506,426 件」这种假数字。
2. **取不到值时，先把 `Object.keys(对象)` 打出来再下结论**。我按 `system.script` 读 RegionBehavior 得「脚本长度 0」，差点写成「这些区域行为是空壳」——真字段是 **`system.source`**。
3. **`getIndex()` 的 `e.type` 是文档子类型**（`consumable`/`spell`/`npc`），**文档类型在包级 `p.documentName`**。用 `e.type === 'Item'` 会得 0 包。
4. **`getIndex()` 不索引 flags**（几乎全部为 undefined）⇒ 要读 flags 必须 `getDocuments()`。
5. **`item.system.activities` 的 `contents` 在 `getDocuments()` 返回的文档上恒为空** ⇒ 必须 `toObject()` 再取值。
