它们是 **TCE 的「可选职业特性」**，全部是**纯说明文本**（0 活动、0 效果）：

| 魔契师 | 魔能选项 Eldritch Versatility | `vLBJr3FWtdYzJfcI` | 4,8,12,16,19 |

物品描述原文（游侠那件）：

> 当你的职业等级抵达能让你获得属性值提示职业特性时，你能进行以下一项改变。这种变化代表着你改变了武术训练和练习的重点。用一个本职业可用的战斗风格替换原有的一个战斗风格。如果你通过[战斗大师范型]掌握了战技，你可以将你的一个已知战技替换为一个不同的战技。
> **【自动化无法匹配】重选武术/战斗风格属升级管理器行为，无物品字段。此条为人工确认的已知限制，非 bug。**

**⇒ 官方 dnd5e.classfeatures 包里根本没有这类物品**（实测 `官方替换武术 = 官方包无此物品`）
**⇒ 作者把它们放在 5 个 ASI 等级各授一次，本意是「每次属性提升时提醒一次」，结果卡上堆出 5 个同名条目。**

## 六 · 已执行的修复（全部读回验证）

### A 类修复：同一 advancement 内去重

```js
const 见 = {}; const 新 = [];
for (const x of it) { const u = String(x.uuid); if (见[u]) continue; 见[u] = 1; 新.push(x); }
a.configuration.items = 新;
await d.update({ "system.advancement": adv });
```

**结果（`结社法术`，id 见下）：**
```

L5 14 → 13 件
L7 14 →  9 件  （去掉 5 个多余）
L9 14 →  9 件  （去掉 5 个多余）
合计去掉 12 个多余件
```

### B 类修复：只保留最低等级那次

```js
for (const u of Object.keys(位)) {
  if (位[u].length < 2) continue;
  const 排 = 位[u].slice().sort((x, y) => x.L - y.L);
  for (let i = 1; i < 排.length; i++) {          // 保留 level 最低的那次
    const it = adv[排[i].k].configuration.items;
    const idx = it.findIndex(x => String(x.uuid) === u);
    if (idx >= 0) it.splice(idx, 1);
  }
}
await d.update({ "system.advancement": adv });
```

### 附带清理：删除 24 个空 advancement

去重后 L8/L12/L16/L19 的 ItemGrant 变成空数组（6 职业 ×4 = 24 个），用 `-=` 键删除：

```js
const up = {};
for (const k of 空) up["system.advancement.-=" + k] = null;
await d.update(up);
```

**结果：删 24 个；子职没有空的（它们只删了 1 处，advancement 里还有别的件）。**

## 八 · 可复用判据

### 扫「重复授予」的脚本骨架（分两类）

```js
for (const pk of ["classes-new","subclass","class-abilityphb","extra-ability","racial-traits","feats-all","BackgroundList","races-item"]) {
  const ds = await game.packs.get("dnd5e_classpack." + pk).getDocuments();
  for (const d of ds) {
    const adv = d.toObject().system.advancement || {};
    const 跨 = {};
    for (const k of Object.keys(adv)) {
      if (adv[k].type !== "ItemGrant") continue;
      const it = (adv[k].configuration || {}).items || [];
      const 内 = {};
      for (const x of it) { const u = String(x.uuid); 内[u] = (内[u]||0)+1; 跨[u] = (跨[u]||0)+1; }
      for (const u of Object.keys(内)) if (内[u] > 1) console.log("A类·同一advancement内", pk, d.name, adv[k].level, u, 内[u]);
    }
    for (const u of Object.keys(跨)) if (跨[u] > 1) console.log("B类·跨等级", pk, d.name, u, 跨[u]);
  }
}
```

**两类要分开处理**：
- **A 类（同一 advancement 内）⇒ 无条件去重，是 bug**
- **B 类（跨等级）⇒ 先问「这是不是每次升级各给一次的设计」，再决定**

### 其他要点

1. **`advancement.items` 是数组 ⇒ update 时整段替换**（`a.configuration.items = 新数组` 后 `d.update({"system.advancement": adv})`）
2. **删除 advancement 键用 `-=`**（`"system.advancement.-=" + k`），dnd5e 的 advancement 是 ObjectField
3. **卡上查来源用 `item.getFlag("dnd5e", "advancementOrigin")`** —— 格式 `<classItemId>.<advancementKey>`，能精确定位是哪个等级给的
4. **包能改、卡上物品改不动**（见另一份文档第五节的僵尸物品问题）⇒ 卡要重新拖
5. **官方 dnd5e 包里没有「可选职业特性」这类说明物品** —— 包作者自加的，所以修复时不受官方约束
