## 四 · ★★★★★ 核心机制发现：物品效果的时长从哪来

**实测对照（同一张表读包内原始数据 + 读跑批靶上实测）**：

| 件 | 活动 duration | 物品效果 duration | 跑批实测 |
|---|---|---|---|
| 勇气联结 Emboldening Bond | `{value:"10", units:"minute"}` | 全 null | **600s ✓** |
| 引导神力：征服威压 | `{value:"1", units:"minute"}` | `{rounds:1}` | **「永久」✗** |
| 至圣光轮 Holy Nimbus | `{units:"inst"}`（立即） | `{seconds:10}` | **10s ✗** |
| 上古斗士 Elder Champion | `{units:"inst"}`（立即） | 全 null | **0s ✗** |
| 魔能祈唤:怠惰之枪 | `{value:"1", units:"turn"}` | 只有 `{startTime, combat}` | **1s ✗** |

**⇒ 规则（实测归纳）**：
1. **活动有实际时长 ⇒ 用活动的**（勇气联结 10 minute → 600s ✓）
2. **活动是 `inst`（立即）⇒ 退回用物品效果自己的 duration**（至圣光轮走 `seconds:10`）
3. **物品效果 duration 写了 `rounds`/`turns`，而跑批时 `game.combat` 为 null ⇒ 算不出剩余 ⇒ 显示成「永久」**
   - 依据 Foundry `ActiveEffect#_prepareDuration`：`if ( Number.isNumeric(d.seconds) ) {...} else if ( d.rounds || d.turns ) { const cbt = game.combat; if ( !cbt ) return { type:"turns", _combatTime: undefined }; ... }`
4. **两处都没写 ⇒ 0 秒 ⇒ 挂上立即掉**

**⇒ 修法铁律：两处都要写对**
```
描述「N 分钟」⇒ 活动 {value:"N", units:"minute"}  ∧  物品效果 {seconds: N*60}
描述「1 回合」⇒ 活动 {value:"1", units:"turn"}     ∧  物品效果 {seconds: 6}
描述「专注」  ⇒ 活动 {concentration:true}          ∧  物品效果 flags.dae.specialDuration:["concentration"]
描述「永久」  ⇒ 两处都不写（保持 null）
```
**理由**：非战斗场景要能过期的唯一可靠写法是 `{seconds: N}`（由 `game.time` 驱动，不需要战斗）；`rounds/turns` 型在无战斗的世界里永远不过期。

## 六 · 验收卡重建（本轮前半段）

| 类 | 张数 | 等级 |
|---|---|---|

**属性叉开**：力18(+4) 敏16(+3) 体14(+2) 智12(+1) 感13(+1) 魅9(−1)
**验证**：战士 L20 = 8 件 / HP **164/164**（L1 max10+体2=12；L2-20 avg6+体2=8×19=152）／AC 13（10+敏3）

### 建卡三坑

1. **`HitPoints.apply(L,{}, {initial:true})` L2 起静默不写值** ⇒ HP 恒 0。源码：`if (options.initial) { if ((level===1)&&this.item.isOriginalClass) data[level]="max"; else if (this.value[level-1]==="avg") data[level]="avg"; }` —— L1 写 `"max"` ⇒ L2 判 `value[1]==="avg"` 不成立 ⇒ 之后全不写。
   **修法**：`const d={}; d[L]=(L===1)?"max":"avg"; await adv.apply(L,d,{});`（不带 initial）
2. **无职业 ⇒ 无等级 ⇒ 无 HitPoints advancement ⇒ HP 0/0**，整张卡处于未准备状态，**卡面什么都不显示、资源全空**（用户看到的「战斗大师没有回气、什么都没有」就是这个）。
   **修法**：种族/背景卡一律带 L1 职业。
3. **并发跑批互相拖** ⇒ 一次只跑一个批。
