## 二 · 匹配机制（★ 用户指出的关键）

- **CPR 匹配靠 `flags["chris-premades"].info.identifier`**（预匹配标记，由 `dnd5e_classpack/cpr-mapping.json` 提供）。
- **GPS 匹配靠「英文物品名」** —— GPS 是英文包，用名字对上。
- **两边 identifier 命名风格不同**：
  - CPR / classpack 早期写法：驼峰 `cloudOfDaggers`
  - **GPS：短横线 `cloud-of-daggers`**
  - ⇒ 直接字符串比对必然匹配不上，**必须归一化** `s.toLowerCase().replace(/[^a-z0-9]/g,"")`。

### 实测：classpack `spell` 包的 identifier 风格
```
总数 545 ｜ 驼峰 id 0 ｜ 短横线 id 410 ｜ 空 id 1 ｜ 已带 CPR 壳(flags.info) 158
```
**⇒ 本包 spell 的 identifier 全是短横线风格（410/545），一个驼峰都没有** —— 与 GPS 同风格，与 CPR 宏库的驼峰不同源。
（这不影响 CPR 匹配，因为匹配走 `flags.info.identifier` 精确值，不做风格转换。）

### GPS 的盘子
2014 版法术 3 个包（**2024 版一律不算**，用户明确「我们是 2014 版本的包，不要管 2024」）：
```
gambits-premades.gps-spells           43
gambits-premades.gps-homebrew-spells   1
gambits-premades.gps-3rd-party-spells 23
⇒ 合计 67 条
```

## 六 · 复现脚本（世界内 execute_js）

```js
const norm = s => String(s).toLowerCase().replace(/[^a-z0-9]/g,"");
const en = s => { const m = String(s).match(/[A-Za-z][A-Za-z0-9'’,\-:().\/ ]*$/); return m ? m[0].trim() : String(s).trim(); };
// GPS 2014 版法术名集合
const gpsName = new Set();
for (const pid of ["gambits-premades.gps-spells","gambits-premades.gps-homebrew-spells","gambits-premades.gps-3rd-party-spells"]) {
  const p = game.packs.get(pid); if (!p) continue;
  for (const d of await p.getDocuments()) gpsName.add(norm(d.name));
}
// CPR 宏库（新旧两套合并）
const cp = window.chrisPremades;
const cpr = new Set([...Object.keys(cp.macros||{}), ...Object.keys(cp.legacyMacros||{})].map(norm));
// classpack 逐包比对
const docs = await game.packs.get("dnd5e_classpack.spell").getDocuments();
const 只有GPS = [];
for (const d of docs) {
  const o = d.toObject();
  if (!gpsName.has(norm(en(d.name)))) continue;
  if (!cpr.has(norm(o.system.identifier))) 只有GPS.push({ 名: d.name, id: d.id, ident: o.system.identifier });
}
return JSON.stringify(只有GPS);
```

## 八 · 踩坑
1. **`game.modules` 不是 Map** —— 直接 `for (const [id,m] of game.modules)` 报 `.for is not iterable`，必须 `.values()`。
2. **GPS 匹配靠英文名**，不是 identifier（用户指出）—— 我最初只按 `flags.info.identifier` 扫，**整批漏掉了没有 CPR 壳的件**（匕首之云就是这么漏的）。
3. **英文名要从「中文 英文」里提取** —— 正则 `/[A-Za-z][A-Za-z0-9'’,\-:().\/ ]*$/`。
4. **CPR 官方宏库搜 `dagger` = 0 命中** ⇒ 匕首之云确实不是 CPR 做的，与用户观察一致。
