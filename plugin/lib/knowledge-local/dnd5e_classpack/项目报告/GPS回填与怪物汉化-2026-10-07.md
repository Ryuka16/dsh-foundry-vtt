## 三 · 本轮抓全的 CPR 写法规范（以后不用再猜）

### 3.1 嵌入宏（`embeddedMacros`）—— 三条路径的写法

```js
// 物品级（最常见）
{ name: "宏名", type: "midi-item", pass: "rollFinished", priority: 50, macro: "JS 代码串" }
// 挂在 ActiveEffect 上（combat 类宏的标准位置，trigger.entity = 效果本体）
{ name: "宏名", type: "combat", pass: "turnStartNear", priority: 50, macro: "..." }
// Activity 级（写父 item 的另一个键）
flags.chris-premades.embeddedActivityMacros.<activityId> = [ ... ]
```
**官方写入函数**：`macroUtils.addEmbeddedMacro(doc, { name, type, pass, priority, macro })`
（Activity 会自动写到父 item 的 `embeddedActivityMacros.<id>`）

### 3.2 事件类型 17 类 × 可用 pass（实测 `getAllDocumentPasses`）


### 3.4 配置项（医药箱「配置」页的来源）

宏定义里 `config: [{ value, label, type, default, category, options?, homebrew? }]`
- `type` 只有四种：**checkbox / select / text / file**
- `category`：animation / sound / mechanics / homebrew
- 读取：`itemUtils.getConfig(item, key)`（物品值优先 → 退回宏声明 default）
- 写入：`itemUtils.setConfig(item, key, value)` ⇒ 存 `flags.chris-premades.config.<key>`
- 现成样例：`sneakAttack` 有 `{value:"auto", type:"checkbox", default:false, category:"mechanics"}`，宏里 `if (!getConfig(item,"auto")) await confirm(...)` ⇒ **这就是「可选触发」的标准姿势**

## 五 · 本轮踩坑（已记 foundry_learn）

1. **`CompendiumCollection#getIndex()` 的条目 id 字段是 `_id` 不是 `id`**
   写成 `e.id` ⇒ 全是 `undefined` ⇒ `getDocument(undefined)` 返回 null ⇒ **循环静默全跳过**（22 批 550 次全跑空，0 改动、0 报错）。这正是「跑完了但什么都没发生」的典型。
2. **compendium 上写 `flags` 必须重建文档**
   `d.update({ "flags.midi-qol": {...} })` **无效**（读回空）；`updateDocuments([{_id, flags}])` **也无效**；只有 `pack.documentClass.create(o, {pack, keepId:true})` 有效。
3. **`item.system.activities` 是 `ActivityCollection`**
   `Object.keys(x.system.activities)` **恒为 0** ⇒ 会误判「这件没有活动」。要 `Object.values()` / `.contents` / `.get(key)`。
4. **中英混排名字的拆分用「第一个英文字母位置」**
   正则 `^([\s\S]*?[\u4e00-\u9fa5][\s\S]*?)\s+([A-Za-z]...)$` 对 `敌群环绕Enemies Abound` 这种**中文紧贴英文**的名字会把 `Enemies` 也吃进中文段 ⇒ 生成 `敌群环绕Enemies Enemies Abound`。
   正解：`const i = s.search(/[A-Za-z]/); cn = s.slice(0, i).trim(); en = s.slice(i).trim();`
5. **别对 1000+ 件的 compendium 直接 `getDocuments()`** —— 必 408。用 `getIndex()`（快）建索引，再按 `_id` 分批 `getDocument()`（每批 25~30 件）。
6. **408 后先读回，不要重跑** —— 本轮大包扫描触发一次 408，因为是读操作无副作用，直接换小而分批的路径。
