## 为什么是这 202 件

这些特性的规则在 dnd5e 里**确实没有可写入的字段**，不是漏做。主要卡在哪：

| 卡点 | 例子 |
|---|---|
| **授予一个「动作」而非数值** | 撤离 / 疾走 / 躲藏 / 协助 / 搜索 —— dnd5e 的 action 没有这种语义 |
| **位移与传送** | 30 尺传送、海渊传送、影之殉难、回音代受 |
| **目标在他人身上** | 让盟友重投、让盟友攻击、代替盟友受伤、把攻击转给第三方 |
| **召唤 / 变形他人** | 龙兽伙伴、咒缚幽灵、真菌感染、灵魂投射 |
| **对抗检定（不是豁免）** | 游说 vs 洞悉、欺瞒 vs 洞悉 —— dnd5e 没有「对抗检定」结算 |
| **感知 / 读心 / 特殊视觉** | 神圣感知、察觉魔法、精准之眼、阴暗学识 |
| **环境与情境判定** | 变色后躲藏、集众之运（数盟友）、风暴导向、拟声 |

**已经做完的**：能用字段表达的（抗性 / 免疫 / 速度 / 感官 / 熟练 / 优势劣势 / 伤害骰 / AC / 临时生命 / 次数池 / 法术授予 / 灵光 / 条件式 AC5E）**全部已写进数据** —— 四特性包 1625 件中 **有 fx 603 ｜ 有活动 969 ｜ 死按钮 0**。
