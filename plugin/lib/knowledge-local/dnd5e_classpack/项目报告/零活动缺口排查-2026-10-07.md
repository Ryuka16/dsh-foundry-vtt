## 二 · ★★★ 三条方法纠正（本轮最大收获）

### 2.1 `traits.dr.value` 是 **Set**，`JSON.stringify(Set)` 恒为 `{}`

```js
JSON.stringify(actor.system.traits.dr.value)   // ❌ 永远是 "{}"
Array.from(actor.system.traits.dr.value)       // ✅ ["poison","acid"]
```

**后果**：本轮开始时用错读法，得出「写进去的抗性没生效」的**完全错误结论**，
差点去改一批**本来就对**的数据。此前所有「读 dr/ci 为空 ⇒ 键失效」的判断**全部作废**。

### 2.2 `MidiQOL.computeSkillAdvantage` 的 `advantage` 字段**可能是空对象**

```js
const r = await MidiQOL.computeSkillAdvantage(actor, "ste", {});
r.advantage.active              // ❌ 有时是 undefined（r.advantage = {}）
r.attribution.ADV["skill.ste"]  // ✅ "优势 (隐匿)"  ← 权威判据
```

**正确判据**：`attribution.ADV` / `legacyAttribution`（midi 自己吐的归因）。

### 2.3 DAE 把 flag 写进 `actor.flags` **需要一拍**

装物品后**立即**读 `actor.flags["midi-qol"]` 会读到空；加 `await new Promise(r=>setTimeout(r,300))` 后正常。
⇒ **假阴性来源**，测试必须带延时。

### 2.4 `advancement` 为空 **≠** 缺口

扫描发现 **14 个职业全部没有 `Spellcasting` advancement**，一度判断为致命缺口。
实查：**dnd5e 5.x 用 `class.system.spellcasting` 字段**（本包 14 个职业全部正确，与官方 `dnd5e.classes` 逐字一致）：

```
牧师：{"progression":"full","ability":"wis","preparation":{"formula":"@abilities.wis.mod + @classes.cleric.levels"}}
```

⇒ 若贸然「修」会给 14 个职业加重复施法 advancement，**搞坏整个施法系统**。

## 四 · 可用的「锐判据」（高精度，可复用）

**核心思路：不找「描述里提到了机制」，而找「描述里指定了一个 dnd5e 有字段、且不需要额外选择的机制」。**

六个有效的正则族（对描述逐句切分后匹配，**句子级**而非全文级，乱度骤降）：

```js
["抗性免疫", /(抗性|抗力|免疫)/ + 具体伤害类型名 + 主语「你/自身」+ 排除 /(选一种|由你选择|以下之一|随机)/ + 排除 /(召唤|魔宠|该生物|物件|小珠|器皿)/]
["速度",     /速度(变为|增加|提高|是)|步行速度|尺的(游泳|飞行|攀爬)速度/]
["AC",       /(AC|防御等级)[^。]{0,14}(\+[0-9]|加值|提升)/]
["优势",     /(你|自身)[^。]{0,24}(具有优势|有优势)/]
["属性提升", /(力量|敏捷|体质|智力|感知|魅力)属性(值)?(提升|增加|变为)/]
["免疫状态", /(你|自身)[^。]{0,16}免疫(于)?[^。]{0,12}(中毒|恐慌|魅惑|麻痹|石化)/]
```

**战绩**：抗性免疫 71 命中 → 3 真缺口；速度 20 命中 → 2；AC 43 命中 → **0**（全假阳性）；优势 10 命中 → 2；属性 1 命中 → 0。

**必须同时做的两件事**：
1. **排除「选择型」句子**（"选一种/由你选择/以下之一"）——这些要么做不了，要么要用 `Trait` advancement 的 `pool`
2. **排除主语是他物的句子**（召唤/魔宠/物件/器皿）——这是最大假阳性源

⚠️ **「机制词 → 必备字段」这类判据此前战绩 719 命中/极少真错，不要再用**。

## 五 · 正确的「弹选择获得抗性」写法（供后用）

本包与包内先例（牙鳞之联）已验证：

```js
// 物品（feat / race / class / subclass / background 才有 advancement 字段）
await d.update({ "system.advancement.<16位id>": {
  _id: "<16位id>", type: "Trait", level: 0, title: "", hint: "",
  configuration: { grants: [], mode: "default", allowReplacements: false,
    choices: [{ count: 1, pool: ["dr:acid", "dr:cold", "dr:lightning", "dr:fire", "dr:poison"] }] },
  value: {}, flags: {}
}});
```

- `pool` 语法：`dr:xxx`（伤害抗性）/ `di:xxx` / `dv:xxx` / `ci:xxx` / `skills:xxx` / `languages:xxx` / `tools:xxx`
- **装备类（equipment / consumable / loot）没有 advancement 字段** ⇒ 凡是"选一种"的装备类抗性，**做不到**
