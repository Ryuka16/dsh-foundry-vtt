## 五 · 做不到的 2 处（已查证，非自注猜测）

### 5.1 遮影矢「无法看见其 5 尺之外的任何事物」

- **dnd5e 只有"给感官"字段**（`system.attributes.senses.ranges.*`），**没有"削减正常视觉"字段**
- 它不是 `blinded`（目盲是**完全**看不见，套上去是曲解规则，会额外造成攻击劣势等后果）
- 现状态：效果结构保留、时长已补（6 秒），但 `changes`/`statuses` 为空
- **候选近似**：`flags.midi-qol.disadvantage.attack.all` + 察觉劣势（**行为近似，非精确**）—— 需用户定夺

### 5.2 虚弱矢「武器攻击造成的伤害减半」

- **AC5E 没有倍率字段**（已通读 `模块文档\Automated Conditions 5e (AC5E)\Flags-functionality.md` L100-139）：
  - `damage.bonus` = 加值（固定数/公式/骰）
  - `damage.extraDice` = **加或乘骰数**（`bonus=2` 加 2 颗；`bonus=x2` / `^2` 乘 2）——**无 ×0.5**
  - `damage.diceUpgrade` / `diceDowngrade` / `modifyDenomination` = 改骰面（d8→d6 不等于减半）
  - `damage.typeOverride` = 改类型
  - `damage.modifier` = 加 Foundry roll modifiers（`adv`/`dis` 为伤害优势/劣势）
- 现状态：效果时长已补，`changes`/`statuses` 为空
- **候选近似**：`flags.automated-conditions-5e.damage.modifier = "dis"`（伤害劣势，方向对但不精确）—— 需用户定夺

## 七 · 技术要点（可复用）

1. **活动等级门控**：`activity.visibility.level = {min, max}`，源码判定
   `if ( ((this.visibility?.level?.min ?? -Infinity) > level) || ((this.visibility?.level?.max ?? Infinity) < level) ) return false;`
2. **奥术射击 DC 一律 `save.dc = {calculation:"int", formula:""}`** —— 用 `formula:"8 + @prof + @abilities.dex.mod"`
   写死属性是错的（6 个矢里爆裂矢曾这么写）
3. **活动 `units:"inst"` 时，效果必须自己写 `duration.seconds`** —— 否则 0 秒立即掉
4. **改活动类型**：整段替换活动对象（`up["system.activities."+k] = 新对象`）即可，
   dnd5e 按新 `type` 重新实例化；记得显式 `delete` 旧类型专有字段，否则残留
5. **`consumption.targets` 用完整 uuid**（`Compendium.<pack>.Item.<id>`）——
   与同族 6 个矢保持一致最稳
6. **18 级自动缩放的标准写法**：`(ceil(@classes.fighter.levels/17)*2)d6`
   （L3~17 得 2d6、L18+ 得 4d6；追踪矢因规则是 1d6→2d6 故不带 `*2`）
