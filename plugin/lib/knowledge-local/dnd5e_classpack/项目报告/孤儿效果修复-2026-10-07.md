## 三 · 判据演进（三次修正，每次都靠实测纠错）

### 第 1 版（太松，误报为主）
- 判据：`transfer:false` 且未被任何活动引用 ⇒ 「永不生效」
- 误报来源：把 **0 changes 的空壳效果**也算成问题件
- 结果：一大堆噪声

### 第 2 版（加「有内容」过滤）
- 判据：效果必须有 `changes.length>0` 或 `statuses.length>0` 或含实现的 flags
- 结果：**29 件**（仍含误报）

### 第 3 版（加 `disabled` 过滤 + 排除附魔模板）
- 新增两条：
  - `e.disabled === true` 跳过（**巨人体型药水的 transfer:true 效果就是 disabled:true，实测放进背包后 STR 仍 10，不生效 ⇒ 不是漏洞**）
  - `e.type === "enchantment"` 单独处理（附魔模板，由 enchant 活动引用，是正确设计）
- 结果：**17 件 / 27 个孤儿效果**——真清单

### 关键对照实验（分辨「孤儿」还是「故意不挂」）
**校准方法：找同类正确样本，看它们怎么挂。**
- 扫全库「changes 全是 `flags.midi-qol.optional.*` 的效果」：共 **53 个**，其中 **50 个都已挂上**（transfer:true 或活动引用），只有 3 个是孤儿
- ⇒ 孤儿就是错的，我原先「midi optional 故意不挂」的猜测被数据否定
- 再扫这 50 个里前 8 个的挂法：**8/8 全部 `transfer: true`** ⇒ 抄同构写法

## 四 · dnd5e 源码铁证（`systems/dnd5e/dnd5e.mjs`，3,007,943 字符）
```js
static transformEffectsData(source, options) {
  return source.effects
    .filter(e => !e.transfer && (e.type !== "enchantment") && (e.flags?.dnd5e?.type !== "enchantment"))
    .map(e => ({ _id: e._id }));
}
```
⇒ **`transfer:false` 且非 enchantment 的效果，必须出现在某个 `activity.effects[]` 里才会被施加。**
```js
get applicableEffects() {
  const level = this.relevantLevel;
  return this.effects?.filter(e => e.effect && ((e.level?.min ?? -Infinity) <= level) && (level <= (e.level?.max ?? Infinity)))
```
⇒ 活动只认 `activity.effects[]` 里列出的效果。
```js
get areEffectsSuppressed() {
  const requireEquipped = (this.type !== "consumable") || ["rod", "trinket", "wand"].includes(this.system.type.value);
  if ( requireEquipped && (this.system.equipped === false) ) return true;
  return !this.system.attuned && (this.system.attunement === "required");
}
```
⇒ **consumable 不受「已装备」闸门约束** ⇒ consumable 上的 `transfer:true` 效果会在背包里直接生效。

## 九 · 本轮判据/API 修正（必须记住）
1. **`activity.applicableEffects` 是判断「效果能否被施加」的唯一权威口径**（源码 `get applicableEffects()` 只认 `activity.effects[]`）
2. **`e.disabled === true` 是合法状态**，不是缺陷（巨人体型药水就是靠它避免背包即生效）
3. **`e.type === "enchantment"` + `disabled:true` = 附魔模板**，由 enchant 活动引用，属正确设计；扫「孤儿」时必须排除
4. **`transformEffectsData` 只转换 `!e.transfer` 且非 enchantment 的效果** ⇒ 这两类是分家的
5. **midi optional 效果的挂法 = `transfer: true`**（同类 8/8）
6. **判定「孤儿是不是故意的」用同类校准法**：扫全库同类效果，看多数怎么挂 ⇒ 少数派即异常
