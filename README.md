# dsh-foundry-vtt

**让 AI 直接操控 Foundry VTT 的插件全家桶。**

装好之后，开个新对话说人话就行：

> 「在激活地图上放三只地精」
> 「给这只怪加个啃咬，命中后过体质豁免，失败中毒」
> 「做一把 1d8 的火焰长剑，带动画和音效」
> 「帮我掷 1d20+5，把这场遭遇的先攻也掷了」

AI 会自己查资料、挑工具、动手操作，最后读回数据核对，然后回报结果（uuid + 实际落库的值）。

**第一次用会慢，后面越来越快。**

AI 第一次做某类东西（比如「搓一把带中毒效果的武器」）时，会去翻内置知识库、对字段、写完再读回来验证 —— 这一步要花不少 token 和时间，因为它真的在查资料而不是拍脑袋。

但它**会把踩过的坑和验证过的解法记下来**（`foundry_learn` 工具，存在你本机 `~/.dsh/dsh-foundry-vtt/learned.md`）。同一个坑不会再踩第二次；下次做同类的东西，就是「查一条记录」的事。你还能直接对它说「**把刚才那个坑记下来**」或者「**看看以前记过什么坑**」。

---

## 它是什么

三个部件：

| 部件 | 装在哪 | 作用 |
|---|---|---|
| **FVTT 模块** `foundry-rest-api` | 云端 FVTT 里 | 把世界数据暴露成 HTTP API |
| **relay** | 你的桌机 `:3010` | 模块与 AI 之间的桥 |
| **DSH 插件**（本仓库自研） | DSH 里 | **100 个工具** —— AI 的手 |

数据流：

```
AI  →  DSH 插件  →  relay(:3010)  →  WebSocket  →  你浏览器里的 FVTT 页面  →  世界
```

**关键设计**：模块的 WebSocket 由 **GM 浏览器主动往外拨**。
所以云端 FVTT **不需要开任何端口、不需要公网暴露、不需要安全组改动、不需要内网穿透**。

## 举例

**① 做一把武器** —— AI 会自己查结构、挑图标、配动画和声音、读完再核对

> 你：做一把 1d8 的火焰长剑，命中后过 DC13 体质豁免，失败挂灼烧、每回合 1d4 火焰
>
> AI：查结构模板 → 图标检索挑图 → 建物品 → 配 AA 动画与音效 → `foundry_diff` 读回核对 → 报 uuid 和落库值

**② 找怪并放到地图上**

> 你：把世界包里的僵尸放到激活地图中央
>
> AI：`foundry_search` 搜世界包 → `foundry_import_entity` 导入 → `foundry_get_scene{active:true}` 读激活场景 → `foundry_place_token` 放下去

**③ 批量改**

> 你：把「荒野变形」文件夹里所有怪物的 AC 都改成 18
>
> AI：列文件夹 → 逐条改 → 逐条读回核对 → 报「7/7 成功」

**④ 验证数据到底对不对**（最容易被跳过的一环）

```
foundry_diff(uuid, { "system.damage.base.denomination": 8 })
→ { allMatched: true, matchedCount: 5, mismatched: [] }
```

失配时会告诉你原因：是**键名写错了**（父级路径不存在），还是**被 dnd5e 清洗了**。

**⑤ 出配对码**（换世界/新装时用）

> 你：给我一个配对码
>
> AI：`foundry_mint_pairing_code` → 返回 6 位码，直接在模块里输入

## 安装

完整流程见 **[docs/部署教程.md](docs/部署教程.md)**。一句话版：

1. 云端 FVTT 装模块 `foundry-rest-api`
2. 桌机启动 relay
3. 模块配对（Enter Code）
4. relay 建 API key + 写 `~/.dsh/dsh-foundry-vtt/config.json`
5. DSH 装配 `plugin/`，开新对话说人话

## 一键工具箱

| 双击 | 干什么 |
|---|---|
| `体检.bat` | 全链路状态 + 结论（Node / 插件装配 / relay / 配对数据 / 配置）—— **出问题第一个双击它** |
| `修复装配.bat` | DSH 重启后工具消失就双击它（依赖 + bundles + 链接一次补齐） |
| `升级.bat` | 覆盖式升级：旧目录改名备份 → 拷新版 → 自动校验装配 |
| `安装relay自启.bat` | relay 开机自启 |
| `卸载relay自启.bat` | 取消自启 |

> **为什么别手动覆盖解压**：① DSH 装配记录里存的是**绝对路径**，安装目录名一换（带版本号那种）路径就悬空，插件会「消失」；② 逐文件覆盖遇到「旧的是文件、新的是目录」会直接中断报错。
> 正确做法：**安装目录名固定不带版本号**，升级只换内容不挪窝，走 `升级.bat`。
